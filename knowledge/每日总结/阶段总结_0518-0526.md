### 📅 5月18日 · NLP文本表示基础

| 技术 | 核心思想 | 缺陷 |

| TF-IDF | 词频×逆文档频率 | 仍无语义 |

**里程碑**：第一次完整实现 ClassifyNetwork + Predictor，初识端到端深度学习流程

### 📅 5月20日 · 深度学习核心原理全面补课

**核心主题**：反向传播、激活函数、RNN梯度消失

这一天学习量最大（约10个知识点，3小时编码），建立了深度学习的核心知识框架：

```
感知机 → 多层网络 → 激活函数（非线性）→ BP反向传播 → 梯度消失/爆炸 → LSTM动机
```

**关键顿悟**：
- 多层线性叠加 = 单层线性，堆层无意义 → 必须加激活函数
- BP本质是链式法则：每层只需上游梯度 × 本层局部梯度
- RNN梯度消失根源：BPTT时梯度连乘小于1的值，指数级衰减

### 📅 5月21日 · PyTorch API深入

**核心主题**：掌握PyTorch常用工具API

| API | 核心要点 |
|-----|---------|
| `topk` / `argmax` | topk返回(values, indices)，argmax只返回索引 |
| `requires_grad` / `no_grad` | 前者是张量属性，后者是上下文管理器 |
| `dim` 参数 | dim=N表示第N维被"压缩消失" |

**易错点**：`torch.no_grad()` ≠ `model.eval()`，推理时两者都要加

---

### 📅 5月22日 · 反向传播数学本质

**核心主题**：彻底搞清楚W转置从哪里来

这一天做了最深入的数学推导：

1. **W转置的来源**：从标量链式法则展开，下标翻转 = 矩阵转置（数学必然，不是约定）
2. **PyTorch Linear层W形状**(out, in)：和数学课本一致，批量计算时用 `X @ Wᵀ + b`
3. **XOR实验**：直观验证无激活函数的网络无论多深都无法解决非线性问题

**核心洞察**：VJP（Vector-Jacobian Product）= 深度学习反向传播的理论核心

---

### 📅 5月23日 · 损失函数与工程实践

**核心主题**：交叉熵的信息论根源 + 完整工程流程

- **交叉熵 vs MSE**：BCE梯度 = ŷ - y，不含sigmoid导数，"自信且错误"时仍有强梯度
- **state_dict vs named_parameters**：前者是拷贝（保存用），后者是引用（冻结层用）
- **完整训练五步**：前向 → loss → zero_grad → backward → step（顺序不可错）

---

### 📅 5月24日 · Word2Vec工程实践

- CBOW vs Skip-gram：前者适合高频词，后者对低频词更友好
- 《人民的名义》完整案例：原始文本 → 分词 → Word2Vec训练 → t-SNE可视化

### 📅 5月26日 · RNN序列模型入门

**核心主题**：从FC网络到序列处理的跨越

## 五、需要强化的易错点

1. `CrossEntropyLoss` 输入必须是 raw logits，不能先 softmax
2. `net.eval()` + `torch.no_grad()` 推理时两者都要加，缺一不可
3. W 转置是数学必然，不是约定（从标量展开可推导）
4. `state_dict` 是拷贝，`named_parameters` 是引用
5. `data_load` 不应写进 `nn.Module` 类
