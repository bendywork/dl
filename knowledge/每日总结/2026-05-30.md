# 📅 2026-05-30 每日学习总结

## 今日学习内容

- 知识点 1：LSTM门控机制解决长时依赖（`29_LSTM如何解决长时依赖.md`、`30_LSTM门控机制解决长时依赖.md`）
  - RNN梯度消失根因：h_t = tanh(W·h_{t-1}+...) 是乘法传递，BPTT时梯度连乘指数衰减
  - LSTM核心思路：引入细胞状态C_t，通过**加法传递**代替乘法：C_t = f_t⊙C_{t-1} + i_t⊙C̃_t
  - 三个门：遗忘门f_t（旧信息保留多少）、输入门i_t（新信息写入多少）、输出门o_t（输出多少）
  - 梯度高速公路：C_t通过加法传到C_{t-1}，梯度几乎不衰减，解决了长时依赖

- 知识点 2：为什么需要RNN及RNN的根本局限（`38_为什么需要RNN及其根本局限.md`）
  - FC网络完全不知道token之间的先后关系，同一组W处理每个token，无上下文
  - RNN通过时间步建模顺序，但根本局限：必须顺序计算（无法并行），远处梯度衰减
  - "时间步"本质：既是语义先后，也是计算依赖，这是RNN与Transformer的根本区别

- 知识点 3：ResNet残差网络原理（`39_残差神经网络ResNet原理.md`、`40_ResNet残差网络的设计哲学与思维逻辑.md`）
  - 发现：56层网络训练误差比20层还高（退化问题，不是过拟合）
  - 根因：常规网络很难学出恒等映射F(x)=x
  - 残差解法：y = F(x) + x，网络只需学残差F(x)=H(x)-x，学零比学恒等映射容易得多
  - Skip connection让梯度有直接通路，也解决了深层网络梯度消失

- 知识点 4：梯度消失问题与解决方案全景（`39_梯度消失问题与解决方案全景.md`）
  - 解法1：激活函数改进（ReLU→Leaky ReLU→ELU）
  - 解法2：BatchNorm（规范化每层激活值分布）
  - 解法3：残差连接（Skip Connection）
  - 解法4：梯度裁剪（针对梯度爆炸）
  - 解法5：LSTM/GRU门控机制（专门针对RNN序列场景）

## 核心收获

1. LSTM的精髓不是"三个门"，而是**加法传递**——C_t = f_t⊙C_{t-1} + i_t⊙C̃_t 这个加号让梯度有了高速公路
2. ResNet和LSTM解决梯度消失的思路相同：都是引入加法绕过乘法链——残差是x+F(x)，LSTM是C_{t-1}+写入项
3. 梯度消失不是只有一种解法，而是"激活函数+归一化+残差+门控"多管齐下

## ⚠️ 易错点回顾

1. **LSTM有两条状态线**：C_t（细胞状态，长期记忆）和h_t（隐状态，短期输出），两者都要传递给下一步；GRU只有h_t
2. **ResNet的退化不是过拟合**：训练误差也高——这是优化困难，不是模型容量过大
3. **残差连接要求输入输出维度相同**：维度不同时需要用1×1卷积对shortcut做投影
