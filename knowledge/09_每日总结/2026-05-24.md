## 今日学习内容

- 知识点 1：词向量与 Word2Vec 入门（`12_Word2Vector.py`）
  - jieba 分词基础：`jieba.cut()` 返回生成器，`jieba.lcut()` 返回列表
  - Word2Vec 核心思想：用上下文预测目标词（CBOW）或用目标词预测上下文（Skip-gram），在预测任务中副产品地学到词向量
  - gensim `Word2Vec` 核心参数：`vector_size`（向量维度）、`window`（上下文窗口）、`sg`（0=CBOW/1=Skip-gram）、`min_count`（最低词频）
  - 词向量的本质是余弦相似度的度量空间：语义相近的词在向量空间中距离近

- 知识点 2：CBOW 逻辑验证（`13_CBOW逻辑验证.py`）
  - 经典词向量类比实验：国王 - 男人 + 女人 ≈ 王后；用 `most_similar(positive=["国王","女人"], negative=["男人"])` 验证
  - 类比能力的前提：需要足够多的训练语料重复出现相关语义关联
  - CBOW vs Skip-gram：CBOW 用周围词预测中心词，适合高频词；Skip-gram 用中心词预测周围词，对低频词更友好
  - 相似度计算：`model.wv.similarity(w1, w2)` 本质是两个词向量的余弦相似度

- 知识点 3：真实语料 Word2Vec 训练——《人民的名义》小说案例（`14_CBOW案例2-小说案例.py`）
  - 真实 NLP 流程：原始文本 → jieba 分词（添加自定义词典）→ 分词结果写文件 → Word2Vec 训练
  - `jieba.suggest_freq()` 强制切词，确保专有名词（如"沙瑞金"）不被错误拆分
  - Word2Vec 高级参数：`hs`（0=负采样/1=层次 Softmax）、`negative`（负采样数量）、`sample`（高频词下采样系数）
  - 三种模型持久化方式：`model.save()` 保存完整模型、`save_word2vec_format(binary=True)` 保存二进制词向量、`np.save()` 直接保存矩阵
  - t-SNE 降维可视化：将高维词向量降到 2D，直观展示词语聚类效果；用 matplotlib 标注随机采样的 100 个词

- 知识点 4：Word2Vec 词频下采样原理
  - 公式：删除概率 = max(1 - √(t / freq), 0)，t = sample 参数（默认 0.001）
  - 高频词（如"的"、"是"）被高概率丢弃，低频词保留——缓解低频词训练不足的问题
  - 与 min_count 的区别：min_count 直接删除极低频词；sample 是对已保留词的训练时随机丢弃

## 核心收获

1. Word2Vec 的词向量不是人为设计的，而是神经网络在"预测任务"上训练的副产品——预测越准，词向量越能捕捉语义关系
2. 真实 NLP 项目中分词质量至关重要：专有名词必须手动加词典（`suggest_freq` / `add_word`），否则人名等被错误切分会导致词向量质量下降
3. 负采样（negative sampling）和层次 Softmax（hierarchical softmax）都是为了解决原始 Word2Vec 词汇表过大时 Softmax 计算量爆炸的问题，是工程上的关键优化
4. t-SNE 可视化是验证词向量质量的直观手段：语义相关的词聚在一起说明向量空间编码了有意义的语义结构

## ⚠️ 易错点回顾

1. **"Word2Vec 直接学习词义"** → 不精确。Word2Vec 学的是"分布式语义"——在相同上下文中出现的词向量相似；它捕捉的是统计共现关系，不是人类定义的语义
2. **"window=5 表示左右各5个词"** → 注意：gensim 的 window 参数含义是"上下文半窗口大小"，即中心词左边和右边各 window 个词，总窗口 = 2×window+1
3. **"直接 model.wv['未知词'] 报错了"** → 应先用 `if word in model.wv` 判断，未登录词直接访问会抛 KeyError
4. **加载词向量时用了错误格式**：`model.save()` 和 `save_word2vec_format()` 保存的格式不同，加载时必须用对应的 API（`Word2Vec.load()` vs `KeyedVectors.load_word2vec_format()`）
