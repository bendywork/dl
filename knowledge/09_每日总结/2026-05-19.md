## 核心收获
- 模型持久化有两种主流方式：① JSON 只保存权重参数（跨框架兼容），② joblib/pickle 保存完整对象（含预处理器）
- Word2Vec 训练后得到的词向量矩阵可以直接作为 Embedding 层的初始化权重，迁移到下游任务
- ml-recover-day01 系统梳理了从特征工程 → 模型训练 → 评估 → 持久化的完整机器学习流程

## ⚠️ 易错点回顾
1. joblib 保存的对象包含 sklearn 版本信息，版本不一致时加载可能报错 → 生产环境固定依赖版本
2. JSON 只能存数值（list/dict），numpy array 需先 `.tolist()` 再序列化
