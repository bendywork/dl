# 高等数学与线性代数知识补充

## 📌 核心问题
> 深度学习的"地基"是高等数学（微积分）与线性代数。本文聚焦**深度学习中真正会用到的那部分数学**，把符号、几何含义、与代码/网络结构的对应关系串起来，避免学了一堆"教材公式"却不知如何与张量、梯度、优化挂钩。

---

## 🌱 根源与动机

深度学习的核心训练过程可以归纳为一句话：

> **在高维参数空间里，沿着损失函数的负梯度方向走小步，让损失下降。**

这一句话里几乎每个词都对应到数学：

- **高维参数空间** → 线性代数中的向量空间、矩阵
- **损失函数** → 多元函数 f(θ)，θ ∈ ℝⁿ
- **梯度** → 偏导数组成的向量，方向导数最大方向
- **走小步** → 泰勒一阶展开 + 学习率
- **下降** → 优化、凸性、Hessian 正定性

如果对这些数学工具没有手感，看到 `loss.backward()`、`torch.matmul`、`nn.Linear` 时只能死记 API，遇到数值不稳定、梯度消失、维度不匹配等问题就无法定位根因。本文按"理解神经网络训练"所需的优先级组织内容。

# Part Ⅰ · 高等数学

## 1. 极限、连续、导数与偏导

### 1.1 极限与连续

极限的 ε-δ 定义：

$$
\lim_{x \to x_0} f(x) = L \iff \forall \varepsilon > 0,\ \exists \delta > 0,\ 0 < |x - x_0| < \delta \Rightarrow |f(x) - L| < \varepsilon
$$

直观理解：x 离 x₀ 足够近时，f(x) 离 L 任意近。

函数 f 在 x₀ 处**连续**：`lim f(x) = f(x₀)`。深度学习里几乎所有损失、激活函数都设计为连续的（ReLU 在 0 点连续但不可导），因为只有连续函数才能保证微小输入扰动不会导致输出剧烈跳变——这是基于梯度的优化收敛的前提。

### 1.2 单变量导数

$$
f'(x_0) = \lim_{\Delta x \to 0} \frac{f(x_0 + \Delta x) - f(x_0)}{\Delta x}
$$

几何含义：函数图像在 x₀ 处切线斜率，也就是**输入变化一个单位，输出大概会变化多少**。

可导 ⟹ 连续；反之不一定（ReLU 在 0 点是反例）。

### 1.3 偏导数（多元函数的核心工具）

设 f: ℝⁿ → ℝ，对第 i 个变量的偏导：

$$
\frac{\partial f}{\partial x_i}\bigg|_{\mathbf{x}_0} = \lim_{h \to 0} \frac{f(\mathbf{x}_0 + h\mathbf{e}_i) - f(\mathbf{x}_0)}{h}
$$

含义：**固定其他变量，只让 xᵢ 变动**时，f 对 xᵢ 的变化率。

> 神经网络的损失 L(θ₁, θ₂, …, θₙ) 是关于成千上万个参数的多元函数；反向传播本质上就是高效地一次性算出所有 `∂L/∂θᵢ`。

### 1.4 常见函数的导数速查

| 函数 | 导数 | 在深度学习中的角色 |
|---|---|---|
| `xⁿ` | `n·x^(n-1)` | 多项式回归、正则项 |
| `eˣ` | `eˣ` | softmax、交叉熵 |
| `ln x` | `1/x` | 负对数似然、KL 散度 |
| `sin x / cos x` | `cos x / -sin x` | 位置编码、傅立叶特征 |
| `sigmoid(x)` | `σ(x)(1-σ(x))` | 早期激活、门控（≤0.25，易梯度消失） |
| `tanh(x)` | `1 - tanh²(x)` | RNN 激活 |
| `ReLU(x)` | `1{x>0}` | 现代主流激活，缓解梯度消失 |

## 2. 梯度、方向导数、Jacobian、Hessian

### 2.1 梯度（Gradient）

对 f: ℝⁿ → ℝ，梯度是所有偏导组成的列向量：

$$
\nabla f(\mathbf{x}) = \left[ \frac{\partial f}{\partial x_1},\ \frac{\partial f}{\partial x_2},\ \ldots,\ \frac{\partial f}{\partial x_n} \right]^\top
$$

**几何意义（必背）：**
- 梯度方向是 **f 在该点上升最快的方向**；
- **负梯度方向是下降最快的方向**——这就是梯度下降算法 `θ ← θ - η∇L(θ)` 的全部理论依据；
- 梯度模长 ‖∇f‖ 表示最快上升的"陡峭程度"。

### 2.2 方向导数

沿单位向量 **u** 方向的变化率：

$$
D_{\mathbf{u}} f(\mathbf{x}) = \nabla f(\mathbf{x}) \cdot \mathbf{u} = \|\nabla f\|\cos\theta
$$

由 cosθ ≤ 1 立刻得到："梯度方向是上升最快方向"是方向导数最大值的几何结论。

### 2.3 Jacobian 矩阵（向量值函数的"导数"）

对 **f**: ℝⁿ → ℝᵐ，Jacobian 是 m×n 矩阵：

$$
J_{\mathbf{f}}(\mathbf{x}) = \begin{bmatrix}
\dfrac{\partial f_1}{\partial x_1} & \cdots & \dfrac{\partial f_1}{\partial x_n} \\
\vdots & \ddots & \vdots \\
\dfrac{\partial f_m}{\partial x_1} & \cdots & \dfrac{\partial f_m}{\partial x_n}
\end{bmatrix}
$$

- 当 m = 1，Jacobian 就是梯度的转置（行向量）；
- 神经网络每一层都是一个向量值函数 `y = f(x)`，PyTorch 的 `autograd` 本质是在做 **vector-Jacobian product（VJP）**：`vᵀJ`，而不是显式构造完整 J（构造代价太大）。

### 2.4 Hessian 矩阵（二阶信息）

对 f: ℝⁿ → ℝ，Hessian 是二阶偏导组成的对称矩阵：

$$
H_f(\mathbf{x}) = \begin{bmatrix}
\dfrac{\partial^2 f}{\partial x_1^2} & \cdots & \dfrac{\partial^2 f}{\partial x_1 \partial x_n} \\
\vdots & \ddots & \vdots \\
\dfrac{\partial^2 f}{\partial x_n \partial x_1} & \cdots & \dfrac{\partial^2 f}{\partial x_n^2}
\end{bmatrix}
$$

性质与用途：
- 在临界点（∇f = 0）处，**H 正定 ⇒ 极小值；H 负定 ⇒ 极大值；H 不定 ⇒ 鞍点**（深度学习高维空间里鞍点远多于局部极小）；
- 牛顿法的核心：`θ ← θ - H⁻¹∇f`，比一阶梯度下降收敛更快但 H⁻¹ 计算昂贵；
- Adam / RMSProp 等优化器可视为对 Hessian 对角元素的廉价近似。

## 3. 链式法则与泰勒展开

### 3.1 单变量链式法则

若 `y = f(u)`，`u = g(x)`，则

$$
\frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx}
$$

### 3.2 多变量链式法则（反向传播的数学骨架）

若 `z = f(y₁, …, yₘ)`，每个 `yⱼ = gⱼ(x₁, …, xₙ)`：

$$
\frac{\partial z}{\partial x_i} = \sum_{j=1}^{m} \frac{\partial z}{\partial y_j} \cdot \frac{\partial y_j}{\partial x_i}
$$

用 Jacobian 写法更紧凑：

$$
\nabla_{\mathbf{x}} z = J_{\mathbf{g}}^\top \nabla_{\mathbf{y}} z
$$

> **反向传播（Backpropagation）= 多变量链式法则 + 动态规划**。
> 神经网络是函数复合 `L = ℓ(fₖ(fₖ₋₁(…f₁(x))))`，反向传播从输出端的 `∂L/∂fₖ` 出发，每层右乘当前层的 Jacobian 转置（实际是 VJP），自顶向下传播梯度，复杂度与一次前向传播同阶。

### 3.3 泰勒展开

一元情况，在 x₀ 附近：

$$
f(x_0 + h) = f(x_0) + f'(x_0)h + \frac{1}{2}f''(x_0)h^2 + O(h^3)
$$

多元向量形式：

$$
f(\boldsymbol{\theta}_0 + \mathbf{d}) \approx f(\boldsymbol{\theta}_0) + \nabla f(\boldsymbol{\theta}_0)^\top \mathbf{d} + \frac{1}{2} \mathbf{d}^\top H_f(\boldsymbol{\theta}_0) \mathbf{d}
$$

**在深度学习中的三个关键用法：**

1. **梯度下降的合理性**：取 `d = -η∇f`（η 足够小），一阶项 `-η‖∇f‖² ≤ 0`，所以 f 下降——这就是为什么"沿负梯度走小步"一定（局部）有效。
2. **学习率的上界**：考虑二阶项要求 `η < 2/L`（L 为梯度的 Lipschitz 常数 ≈ Hessian 最大特征值），否则会发散。
3. **牛顿法的推导**：令二阶近似关于 d 求导为零 ⇒ `d = -H⁻¹∇f`。

### 3.4 链式法则的代码视角（PyTorch）

```python
x = torch.tensor(2.0, requires_grad=True)
y = x ** 3            # y = f(x)
z = torch.sin(y)      # z = g(y) = g(f(x))
z.backward()          # 自动用链式法则：dz/dx = cos(x³) · 3x²
print(x.grad)         # tensor(-11.7873)  ≈ cos(8) * 12
```

理解了链式法则，就能预测任何复合函数的梯度——这是调试 `grad is None`、梯度爆炸/消失的根基。

## 4. 积分、期望与级数

### 4.1 定积分与微积分基本定理

$$
\int_a^b f(x)\,dx = F(b) - F(a),\qquad F'(x) = f(x)
$$

含义：曲线下方"加总面积"等于原函数差值。深度学习里很少手算积分，但**理解期望、归一化、概率密度都依赖它**。

### 4.2 与概率/期望的联系

- 连续型随机变量 X 的概率密度 p(x) 满足 `∫p(x)dx = 1`；
- 期望：`E[g(X)] = ∫g(x)p(x)dx`；
- 交叉熵损失本质：`H(p, q) = -∫p(x)log q(x)dx`（连续）或 `-Σp_i log q_i`（离散）；
- **蒙特卡洛**：用样本平均近似积分，`E[g(X)] ≈ (1/N)Σg(xᵢ)`——这是 mini-batch SGD 把"全数据梯度期望"近似为"batch 平均梯度"的合法性来源。

### 4.3 常用积分技巧（够用即可）

| 技巧 | 公式/思想 | DL 场景 |
|---|---|---|
| 换元法 | `∫f(g(x))g'(x)dx = ∫f(u)du` | 重参数化 trick（VAE） |
| 分部积分 | `∫u dv = uv − ∫v du` | KL 散度推导 |
| 高斯积分 | `∫e^(-x²)dx = √π` | 正态分布归一化常数 |

### 4.4 级数与收敛性

- **几何级数**：`Σrⁿ = 1/(1-r)`（|r|<1）——出现在 RNN 梯度爆炸/消失分析、折扣回报、动量法等价形式。
- **泰勒级数**：上节已述，是连接"局部"与"近似"的桥梁。
- **大数定律**：`(1/N)ΣXᵢ → E[X]`——保证 mini-batch 越大，梯度估计越接近真梯度。
- **中心极限定理**：独立随机变量的和趋近于正态分布——网络权重初始化（如 Xavier、Kaiming）的理论基础。

### 4.5 数值视角的提醒

实际训练里我们几乎不算解析积分，但要警惕：
- 浮点 underflow：`exp(-large)` → 0，要用 `log-sum-exp` 技巧；
- 离散求和的顺序敏感：详见同目录 [浮点数精度误差与运算顺序](./浮点数精度误差与运算顺序_03.md)。

# Part Ⅱ · 线性代数

## 5. 向量、内积、范数

### 5.1 向量基本观念

一个 n 维向量 **x** ∈ ℝⁿ 既可看作：
- **代数对象**：n 个数的有序元组；
- **几何对象**：n 维空间中的一个箭头（带方向、长度）；
- **数据对象**：一条样本的特征向量（embedding、token 表示、隐藏状态都是）。

> 在 PyTorch 里，`torch.tensor([1.0, 2.0, 3.0])` 是 shape=(3,) 的一维张量，**不是**列向量也不是行向量；只有 `.unsqueeze(0)` / `.unsqueeze(1)` 才变成 (1,3) 或 (3,1) 的二维矩阵。这点在矩阵乘法报维度错误时经常踩坑。

### 5.2 内积（点积）

$$
\mathbf{x}\cdot\mathbf{y} = \sum_{i=1}^{n}x_i y_i = \|\mathbf{x}\|\|\mathbf{y}\|\cos\theta
$$

含义：投影长度的加权——`x·y > 0` 表示方向相近，`= 0` 表示正交，`< 0` 表示方向相反。

**深度学习中的角色：**
- 神经元的"加权求和"`wᵀx + b` 就是内积；
- 注意力机制的核心 `softmax(QKᵀ/√d)` 中，`QKᵀ` 的每个元素是 query 与 key 的点积——**相似度**；
- 余弦相似度 `cos(x, y) = x·y / (‖x‖‖y‖)` 衡量两个 embedding 的方向一致性。

### 5.3 范数（Norm）

范数把"向量的大小"严格化。常用：

| 范数 | 定义 | 几何 | DL 场景 |
|---|---|---|---|
| L¹ | `‖x‖₁ = Σ|xᵢ|` | 菱形等高线 | Lasso、稀疏正则 |
| L² | `‖x‖₂ = √Σxᵢ²` | 圆/球等高线 | 权重衰减、欧氏距离 |
| L∞ | `‖x‖∞ = max|xᵢ|` | 方形等高线 | 对抗扰动上界 |
| Lᵖ | `(Σ|xᵢ|ᵖ)^(1/p)` | 一般情况 | 较少用 |

**性质**：非负、齐次（`‖cx‖ = |c|·‖x‖`）、三角不等式（`‖x+y‖ ≤ ‖x‖+‖y‖`）。

### 5.4 矩阵范数

- **Frobenius 范数**：`‖A‖_F = √Σᵢⱼ aᵢⱼ²`，把矩阵当作展开向量算 L²，最常见。
- **谱范数（Spectral norm）**：`‖A‖₂ = σ_max(A)`，即最大奇异值，控制 Lipschitz 常数（GAN 的 Spectral Normalization 即此）。

### 5.5 范数与梯度裁剪

`torch.nn.utils.clip_grad_norm_(params, max_norm)` 把所有参数梯度拼成大向量，算 L² 范数，超出 `max_norm` 就整体缩放——这是 RNN/Transformer 训练防梯度爆炸的标配。

## 6. 矩阵运算与特殊矩阵

### 6.1 基本运算

- **加减**：`(A ± B)ᵢⱼ = Aᵢⱼ ± Bᵢⱼ`（同形）；
- **数乘**：`(cA)ᵢⱼ = c·Aᵢⱼ`；
- **乘法**：`A ∈ ℝᵐˣᵏ`, `B ∈ ℝᵏˣⁿ` ⇒ `(AB)ᵢⱼ = Σₚ AᵢₚBₚⱼ`，结果 m×n；
- **转置**：`(Aᵀ)ᵢⱼ = Aⱼᵢ`，规则 `(AB)ᵀ = BᵀAᵀ`；
- **逆**（仅方阵且可逆）：`A·A⁻¹ = I`，`(AB)⁻¹ = B⁻¹A⁻¹`。

> 矩阵乘法**不可交换**：一般 `AB ≠ BA`。这与"是否可乘"无关，是性质本身。

### 6.2 矩阵乘法的三种理解视角（重要）

| 视角 | 解读 | DL 中对应 |
|---|---|---|
| **逐元素**：行 · 列 | 标准定义，便于手算 | 推导公式 |
| **列组合**：`AB` 的第 j 列 = A 的列们以 B 第 j 列为系数的线性组合 | 强调列空间 | 特征/embedding 变换 |
| **线性变换复合**：A、B 是两个线性映射，AB 是它们的复合 | 几何视角 | 多层 Linear 等价于一次大 Linear（无激活时） |

第三个视角解释了为什么**没有非线性激活的多层 MLP 等价于单层**——多个线性变换的复合仍是线性变换。

### 6.3 特殊矩阵速查

| 名字 | 定义 | DL 中的出场 |
|---|---|---|
| 零矩阵 0、单位阵 I | / | 偏置初始化、残差恒等映射 |
| 对角阵 D | 非对角元为 0 | LayerNorm 的缩放、Adam 的 v̂ |
| 对称矩阵 | `A = Aᵀ` | Hessian、协方差阵、Gram 矩阵 `XᵀX` |
| 正交矩阵 Q | `QᵀQ = I`（列两两正交单位） | 保范变换、旋转、Householder/QR、正交初始化 |
| 正定矩阵 | 对称且 `xᵀAx > 0` (∀x≠0) | 严格凸损失的 Hessian、协方差 |
| 半正定（PSD） | `xᵀAx ≥ 0` | 协方差矩阵、核矩阵（必为 PSD） |
| 置换矩阵 P | 单位阵打乱行 | shuffle、attention mask 直观化 |
| 稀疏矩阵 | 大部分元素为 0 | 大规模 embedding、图神经网络邻接矩阵 |
| 三角矩阵 | 上/下三角 | Cholesky 分解、自回归 mask |

### 6.4 关键恒等式（写公式时常用）

- `(A + B)C = AC + BC`，`A(B + C) = AB + AC`
- `trace`：`tr(AB) = tr(BA)`，`tr(ABC) = tr(BCA) = tr(CAB)`（循环不变）
- `(A⁻¹)ᵀ = (Aᵀ)⁻¹`
- 块矩阵乘法：分块形状对齐时可分块算（在写 transformer 多头时常用）

### 6.5 nn.Linear 的数学真面目

`nn.Linear(in=d, out=h)` 实现的就是 **y = xWᵀ + b**：
- `W` shape = `(h, d)`，`b` shape = `(h,)`；
- 输入 `x` shape = `(..., d)`，输出 `(..., h)`；
- 多个样本的批处理 = 一次性算了 batch 个矩阵-向量乘——这就是 GPU 高效的来源。

## 7. 行列式、秩、特征值与特征向量

### 7.1 行列式（det）

- 仅对**方阵**定义；
- 2×2：`det = ad - bc`，n×n 用递归展开/LU 算；
- 几何含义：线性变换对**有向体积**的缩放因子；`det = 0` ⇔ 变换把空间压扁了一维（不可逆）；
- 性质：`det(AB) = det(A)det(B)`，`det(Aᵀ) = det(A)`，`det(A⁻¹) = 1/det(A)`。

> DL 中很少手算 det，但**对数行列式 log|det J|** 在 normalizing flow 中是核心（衡量概率密度的体积变化）。

### 7.2 秩（rank）

矩阵 A 的秩 = **线性无关列（或行）的最大数目** = 列空间维度 = 行空间维度。

- `rank(A) ≤ min(m, n)`；
- **满秩**：方阵满秩 ⇔ 可逆 ⇔ `det(A) ≠ 0`；
- **低秩**：很多自然数据矩阵近似低秩——这是矩阵分解（如推荐系统）、LoRA 等技术的根基。

> **LoRA（Low-Rank Adaptation）**：把大矩阵的更新 ΔW ∈ ℝᵈˣᵏ 约束成 `ΔW = BA`，其中 `B ∈ ℝᵈˣʳ, A ∈ ℝʳˣᵏ`，r ≪ min(d,k)，参数量从 `dk` 降到 `r(d+k)`——直接利用"满秩更新没必要，低秩够用"的假设。

### 7.3 特征值与特征向量

对方阵 A，若存在非零向量 **v** 和标量 λ 满足：

$$
A\mathbf{v} = \lambda \mathbf{v}
$$

则 λ 是**特征值**，**v** 是对应**特征向量**。求解：`det(A - λI) = 0`。

**几何含义**：A 这个变换沿着 v 方向只做了"伸缩"（拉伸因子 λ），没有旋转——所以特征向量是变换的"骨架方向"。

**重要性质：**
- `trace(A) = Σλᵢ`，`det(A) = Πλᵢ`；
- 对称矩阵：所有特征值实数，且可找到一组**正交**特征向量；
- 半正定矩阵：所有特征值 ≥ 0；
- 矩阵的"大小"很大程度由最大特征值/最大奇异值决定。

### 7.4 特征分解（Eigendecomposition）

n 阶方阵 A 若有 n 个线性无关特征向量，可对角化：

$$
A = Q\Lambda Q^{-1}
$$

其中 Q 列为特征向量，Λ 为特征值对角阵。**对称矩阵**情况下 Q 可取正交，于是 `A = QΛQᵀ`（谱定理）。

**应用**：
- 计算矩阵幂：`Aᵏ = QΛᵏQ⁻¹`，把矩阵幂转成对角元素的幂——这是 RNN 沿时间步反复乘 W 导致**梯度爆炸/消失**的核心解释（特征值 >1 爆炸、<1 消失）；
- **PCA**：对样本协方差矩阵做特征分解，最大特征值对应方差最大的方向（主成分）。

### 7.5 PyTorch 速查

```python
A = torch.tensor([[2., 1.], [1., 2.]])
λ, V = torch.linalg.eig(A)       # 一般方阵（可能返回复数）
λ, V = torch.linalg.eigh(A)      # 对称/Hermitian，返回实数且 V 正交
```

## 8. 矩阵分解：SVD / QR / Cholesky

### 8.1 奇异值分解 SVD（最重要的一种）

任意 m×n 矩阵 A 都可分解为：

$$
A = U\Sigma V^\top
$$

- `U`：m×m 正交矩阵，列是 A 的**左奇异向量**（即 AAᵀ 的特征向量）；
- `V`：n×n 正交矩阵，列是 A 的**右奇异向量**（即 AᵀA 的特征向量）；
- `Σ`：m×n 对角阵，对角元 σ₁ ≥ σ₂ ≥ … ≥ 0 为**奇异值**。

**几何理解**：任何线性变换都可分解为「旋转 → 沿坐标轴拉伸 → 再旋转」。

**核心应用：**

1. **低秩近似（Eckart–Young 定理）**：
   取前 k 个奇异值的截断 `Aₖ = U_k Σ_k V_kᵀ`，是所有秩 ≤ k 的矩阵中与 A 最接近（Frobenius/谱范数下）的——图像压缩、推荐系统、LoRA 理论支撑。

2. **PCA 的等价实现**：
   对中心化数据矩阵 X 做 SVD，右奇异向量 V 就是主成分；σᵢ²/(n-1) 就是对应方差。

3. **伪逆**：
   `A⁺ = VΣ⁺Uᵀ`（Σ⁺ 是非零奇异值取倒数），求解最小二乘 `min‖Ax-b‖²` 的解为 `x = A⁺b`。

4. **谱范数与条件数**：
   `‖A‖₂ = σ_max`，条件数 `κ(A) = σ_max/σ_min`，太大说明 A 接近奇异，数值不稳定。

### 8.2 QR 分解

$$
A = QR
$$

- Q 列正交，R 上三角；
- **Gram-Schmidt 正交化**的矩阵版本；
- 用途：求解 `Ax = b`（变为解 `Rx = Qᵀb` 的回代）；
- DL 中：**正交初始化**（RNN 权重初始化为正交矩阵能缓解梯度爆炸/消失）、QR 重正交化。

### 8.3 Cholesky 分解

对**正定对称**矩阵 A：

$$
A = LL^\top
$$

L 为下三角且对角元为正。

- 相当于"对称矩阵的开方"；
- 求解 `Ax = b` 比一般 LU 快约一倍；
- DL/概率中：
  - 多元高斯采样 `x = μ + Lz` （z ~ N(0, I)），L 为协方差的 Cholesky；
  - 高斯过程的核矩阵求逆。

### 8.4 三种分解的选择速查

| 需求 | 用哪个 |
|---|---|
| 任意矩阵的几何理解、低秩压缩 | **SVD** |
| 数值求解 Ax = b（A 一般） | LU 或 QR |
| A 正定对称求逆 / 采样 | **Cholesky** |
| 需要保范、正交基 | **QR** |
| A 对称求特征 | `eigh` |

### 8.5 PyTorch 速查

```python
U, S, Vh = torch.linalg.svd(A, full_matrices=False)    # 注意返回的是 V 的转置
Q, R     = torch.linalg.qr(A)
L        = torch.linalg.cholesky(A)                    # 要求 A 正定
```

# Part Ⅲ · 深度学习中的应用

## 9. 矩阵求导规则

### 9.1 分子布局 vs 分母布局（约定要先讲清楚）

矩阵求导有两套布局，不同教材结果**形状互为转置**。本文采用**分母布局（denominator layout）**，即标量对向量求导得到列向量（与 PyTorch `.grad` 形状一致）：

$$
\frac{\partial f}{\partial \mathbf{x}} \in \mathbb{R}^{n\times 1}\ \ \text{当}\ \mathbf{x} \in \mathbb{R}^n
$$

### 9.2 常用恒等式（记住这些就够 95% 推导）

设 **x** ∈ ℝⁿ，**a** ∈ ℝⁿ，A ∈ ℝⁿˣⁿ：

| 表达式 | 对 x 的导数 |
|---|---|
| `aᵀx` | `a` |
| `xᵀa` | `a` |
| `xᵀx` | `2x` |
| `xᵀAx` | `(A + Aᵀ)x`；A 对称时 = `2Ax` |
| `‖x‖₂²` | `2x` |
| `Ax`（对 x） | `Aᵀ`（Jacobian 转置） |

### 9.3 链式法则（向量/矩阵版）

对复合 `L = f(y), y = Wx + b`：

$$
\frac{\partial L}{\partial W} = \frac{\partial L}{\partial y} \cdot x^\top,\qquad
\frac{\partial L}{\partial x} = W^\top \frac{\partial L}{\partial y}
$$

**这就是 `nn.Linear` 反向传播的全部公式**——所有框架的实现都是这两行。

### 9.4 推导示例：最小二乘的闭式解

目标：`min ‖Xw - y‖²`。

$$
L = (Xw - y)^\top (Xw - y) = w^\top X^\top X w - 2 y^\top X w + y^\top y
$$

对 w 求导并令为零：

$$
\frac{\partial L}{\partial w} = 2X^\top X w - 2 X^\top y = 0 \Rightarrow w^* = (X^\top X)^{-1}X^\top y
$$

数值不稳定时（XᵀX 接近奇异），用 SVD 的伪逆：`w* = X⁺y`。

## 10. 与梯度下降、反向传播、PCA、注意力的对应

### 10.1 梯度下降的数学描述

$$
\boldsymbol{\theta}_{t+1} = \boldsymbol{\theta}_t - \eta \nabla L(\boldsymbol{\theta}_t)
$$

- 合法性：泰勒一阶展开 + 负梯度方向；
- 学习率上界：与 Hessian 最大特征值有关；
- 凸损失 + 适当 η ⇒ 全局最优；非凸（神经网络）⇒ 局部极小/鞍点，但实践中"够好"。

### 10.2 反向传播 = 链式法则 + 计算图

```
x ── Linear ── h₁ ── ReLU ── h₂ ── Linear ── ŷ ── Loss ── L
```

反向：

```
∂L/∂ŷ → ∂L/∂h₂ = Wᵀ(∂L/∂ŷ) → ∂L/∂h₁ = (∂L/∂h₂) ⊙ 𝟙{h₁>0} → ∂L/∂x …
```

PyTorch 的 `autograd` 自动构建计算图、自动应用上述链式法则。

### 10.3 PCA = 协方差矩阵的特征分解（或数据矩阵 SVD）

1. 数据中心化：`X̃ = X - mean`
2. 协方差：`C = (1/(n-1)) X̃ᵀX̃`，对称半正定
3. 特征分解 `C = QΛQᵀ`，按特征值降序取前 k 列得到主成分；
4. 投影：`Z = X̃ Q_k`，维度从 d 降到 k。
5. 等价：直接 `U,S,Vᵀ = svd(X̃)`，主成分 = V 的前 k 列。

### 10.4 注意力机制的线性代数本质

$$
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V
$$

- `QKᵀ`：批量内积，给出 token 两两相似度矩阵；
- `/√d_k`：防止高维内积方差过大导致 softmax 饱和（理论：独立项求和方差线性增长）；
- `softmax(·)V`：用相似度作权重对 V 做加权平均 = **数据驱动的加权矩阵-向量乘**。

### 10.5 常见数学陷阱与排查清单

| 现象 | 数学根因 | 解法 |
|---|---|---|
| 梯度爆炸 | 反向传播中 Jacobian 谱半径 > 1 反复相乘 | grad clipping、正交初始化、残差连接 |
| 梯度消失 | Jacobian 谱半径 < 1、sigmoid/tanh 饱和 | ReLU、归一化、残差、LSTM 门控 |
| Loss NaN | log(0) / 除 0 / softmax 上溢 | log-sum-exp、ε-平滑、AMP loss scaling |
| 维度不匹配 | 矩阵乘内维不一致、batched matmul 误解 | 见 [矩阵乘法与广播机制](./矩阵乘法与广播机制_01.md) |
| Hessian 病态 | κ(H) 巨大，损失"长峡谷" | Adam、归一化、二阶优化、白化 |
| 数值精度异常 | float32 下大数相加 / 累加顺序问题 | float64、Kahan 求和、见 [浮点数精度](./浮点数精度误差与运算顺序_03.md) |

## ✅ 一句话总结

> 高等数学告诉你**怎样沿损失曲面下降**（梯度、泰勒、链式法则），线性代数告诉你**参数住在什么样的空间里以及怎样高效搬运信息**（向量、矩阵、分解）。深度学习就是把这两套语言一起用在 GPU 上的工程实现——把任何模型/优化器看不懂时，回到这两套语言里查一遍，常常豁然开朗。
