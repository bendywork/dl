# 矩阵乘法与广播机制

## 📌 核心问题
> 区分 `@`（matmul）矩阵乘法 与 `* + - /` 等逐元素运算的广播机制，搞清楚 batched 矩阵乘法的规则。

---

## 🌱 根源与动机

深度学习中大量操作需要在一批（batch）样本上同时做矩阵运算。PyTorch / NumPy 提供了两套不同的"形状扩展"规则：

- **矩阵乘法（`@` / `matmul`）**：沿最后两维做线性代数意义上的矩阵相乘，前面的维度视为 batch，结果中间维度（k）会"消掉"。
- **广播（broadcasting）**：逐元素运算（`+ - * /` 等）时，从右往左对齐维度，维度为 1 或缺失的可自动扩展，形状不改变语义，只对齐尺寸。

两者都是为了让代码无需手写 for 循环，但触发规则完全不同，混淆是高频错误来源。

---

## 📐 理论推导

### 两者核心区别

| | Batched 矩阵乘法 | 广播机制 |
|---|---|---|
| 触发条件 | 使用 `@` 或 `torch.matmul` | 使用 `+ - * /` 等逐元素运算 |
| 作用 | 矩阵相乘，**改变形状** | 形状对齐，**逐元素计算** |
| 结果形状 | 中间维度（k）消掉 | 形状扩展到一致，不消维 |

**判断口诀：看运算符。`@` 用矩阵乘法规则，`* + - /` 用广播规则。**

---

### `@` 矩阵乘法规则

精确规则：**看最后两维做矩阵乘法，前面所有维度做 batch 处理。**

```
A: (..., m, k)
B: (..., k, n)
结果: (..., m, n)
```

- 倒数第一维（列数 k）必须一致，结果中 k 消掉
- 倒数第二维 m 保留到结果
- 前面所有维度为 batch 维度

**典型例子：**

```
(5, 128) @ (128, 256)       → (5, 256)
(1, 5, 128) @ (128, 256)    → (1, 5, 256)    # 1 是 batch 维度
(1, 1, 2, 3) @ (3, 2)       → (1, 1, 2, 2)   # 多 batch 维度
```

---

### 广播机制规则

两个形状不同的数组做逐元素运算时，**从右往左对齐维度**，维度为 1 或缺失的可以扩展：

```
规则：
  1. 从右往左对齐，缺失的维度补 1
  2. 每一维上：若两者相等 → 保留；若其中一个为 1 → 扩展到另一个；否则报错

示例：
  (5, 128) + (128,)
  → (128,) 右对齐补齐 → (1, 128)
  → 广播成 (5, 128)
  → 结果 (5, 128)

  (3, 1, 4) + (1, 5, 4)
  → 每维对比：3 vs 1 → 3，1 vs 5 → 5，4 vs 4 → 4
  → 结果 (3, 5, 4)
```

---

### `@` 中 batch 维度不一致时

batch 维度（最后两维之前的所有维度）**同样触发广播**：

```
(2, 1, 3, 4) @ (1, 5, 4, 6)

batch 部分：(2, 1) 和 (1, 5) → 广播成 (2, 5)
矩阵部分：(3, 4) @ (4, 6) = (3, 6)
结果：(2, 5, 3, 6)
```

---

## 💡 关键理解

**类比帮助记忆：**

想象矩阵乘法是"咬合齿轮"——左矩阵的列数必须等于右矩阵的行数，咬合后中间那个维度消失，输出是 m×n 的结果。

广播是"拉伸橡皮筋"——维度为 1 的地方可以被拉伸到对方的尺寸，但不改变运算本质，只是把数据复制铺开。

**核心区分口诀：**

- `@` → 最后两维相乘，k 消掉，batch 可广播
- `*` → 全部维度对齐，逐元素，没有维度消掉

## 🔧 代码实现

```python
import torch

# ============================================================
# 1. 基础矩阵乘法 @
# ============================================================
A = torch.randn(5, 128)
B = torch.randn(128, 256)
C = A @ B
print(f"(5,128) @ (128,256) = {C.shape}")   # torch.Size([5, 256])

# ============================================================
# 2. Batched 矩阵乘法
# ============================================================
A2 = torch.randn(1, 5, 128)
B2 = torch.randn(128, 256)          # 自动广播 batch 维度
C2 = A2 @ B2
print(f"(1,5,128) @ (128,256) = {C2.shape}")  # torch.Size([1, 5, 256])

# ============================================================
# 3. 多 batch 维度 + batch 广播
# ============================================================
E = torch.randn(2, 1, 3, 4)
F = torch.randn(1, 5, 4, 6)
G = E @ F
print(f"(2,1,3,4) @ (1,5,4,6) = {G.shape}")  # torch.Size([2, 5, 3, 6])

# ============================================================
# 4. 广播逐元素运算（不是矩阵乘法）
# ============================================================
X = torch.randn(1, 5, 128)
bias = torch.randn(128)              # 右对齐，扩展成 (1,5,128)
D = X + bias
print(f"(1,5,128) + (128,) = {D.shape}")      # torch.Size([1, 5, 128])

# 3D 广播
P = torch.randn(3, 1, 4)
Q = torch.randn(1, 5, 4)
R = P * Q
print(f"(3,1,4) * (1,5,4) = {R.shape}")       # torch.Size([3, 5, 4])

# ============================================================
# 5. 易错验证：@ 不等于 *
# ============================================================
M = torch.randn(3, 4)
N = torch.randn(3, 4)

# * 是逐元素乘法，形状不变
elem = M * N
print(f"(3,4) * (3,4) = {elem.shape}")        # torch.Size([3, 4])

# @ 是矩阵乘法，需要 M 的列 == N 的行，所以需要转置 N
mat = M @ N.T                                   # N.T shape: (4, 3)
print(f"(3,4) @ (4,3) = {mat.shape}")          # torch.Size([3, 3])
```

---

## ⚠️ 易错点与常见误解

1. **看到形状不同就以为是广播** → 要先看运算符。`@` 走矩阵乘法规则，`*` 才走广播规则。

2. **以为 batched 矩阵乘法要求所有维度一致** → 只需要最后两维满足矩阵乘法规则（k 相等），前面的 batch 维度可以广播。

3. **忘记 `@` 的 batch 维度本身也可以广播** → `(2,1,3,4) @ (1,5,4,6)` 的 batch 部分 `(2,1)` 和 `(1,5)` 会广播成 `(2,5)`，合法。

4. **混淆"维度消掉"和"维度扩展"** → `@` 让 k 维消掉；广播让维度为 1 的地方扩展，不会消维。

5. **`torch.mm` vs `torch.matmul` vs `@`** → `mm` 只支持 2D，`matmul` 和 `@` 支持任意维度 batched，三者对 2D 输入等价。

## 🔗 知识延伸

- **Attention 机制中的矩阵乘法**：`Q @ K.T` 是典型的 batched matmul，Q 形状 `(batch, seq, d_k)`，K.T 形状 `(batch, d_k, seq)`，结果 `(batch, seq, seq)` 是注意力分数矩阵。
- **einsum**：`torch.einsum` 可以用爱因斯坦求和约定精确指定哪些维度相乘、哪些消掉，比 `@` 更灵活，适合复杂的多维运算。
- **广播与内存**：广播在实际执行时不会真的复制数据（惰性扩展），但 `expand` / `repeat` 会真实分配内存，注意区别。
- **NumPy 广播**：与 PyTorch 规则完全一致，掌握一个即可迁移。
