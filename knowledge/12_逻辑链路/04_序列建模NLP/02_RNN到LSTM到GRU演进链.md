# RNN → LSTM → GRU 演进链

## 逻辑链

```
RNN 解决全连接不能处理时序
  → 发现梯度消失/爆炸 → LSTM(引入门控) → GRU(简化门控)
```

## 每一步解决了什么

| 模型 | 核心问题 | 解决方案 | 仍存在的问题 |
|------|---------|---------|------------|
| RNN | 全连接无法处理变长序列 | 隐状态 ht 循环传递 | 梯度消失，长序列忘记开头 |
| LSTM | 长距离依赖丢失 | 引入遗忘门+记忆细胞 Ct | 参数多，计算慢 |
| GRU | LSTM 太重 | 合并门控，去掉 Ct | 极端长序列不如 LSTM |

## 必须理解的核心公式

### RNN
```
ht = tanh(W_h * h_{t-1} + W_x * x_t + b)
```
一个公式。梯度要穿过 tanh 和 W_h 的 t 次方 → 指数衰减/爆炸。

### LSTM
```
三个门：遗忘(f)、输入(i)、输出(o) + 记忆细胞 Ct
关键：Ct = f_t ⊙ C_{t-1} + i_t ⊙ C̃_t（加减法，梯度顺畅）
```
记忆细胞用加法更新 → 梯度不会连乘 → 消失问题大幅缓解。

### GRU
```
两个门：重置(r)、更新(z)
ht = (1-z)⊙h_{t-1} + z⊙h̃_t（加权平均）
```
LSTM 的简化，效果差不多但更快。

## 理解检查点

1. 为什么 RNN 有梯度消失而 LSTM 缓解了？（**关键：Ct 用加法加权，梯度不连乘**）
2. LSTM 的 ht 和 Ct 分别是干嘛的？（ht=输出给上层，Ct=内部长期记忆）
3. GRU 比 LSTM 少了什么？（少了一个门 + 没了 Ct）
