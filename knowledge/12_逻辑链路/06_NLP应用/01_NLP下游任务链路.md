# NLP 下游任务链路

## 逻辑链

```
预训练模型(BERT/GPT) → Fine-tuning → 下游任务
    ├── 分类：文本分类、情感分析、意图识别
    ├── 序列标注：NER、POS
    ├── 关系：关系抽取、知识图谱
    ├── 生成：文本生成、摘要、翻译
    └── 结构化：CRF 辅助序列标注
```

## 下游任务全景

| 任务类型 | 标签粒度 | 典型任务 | BERT 怎么用 |
|---------|---------|---------|-----------|
| 文本分类 | 句子级 | 情感分析、意图识别 | [CLS] → FC → softmax |
| 序列标注 | token级 | NER、词性标注 | 每个 token → FC → softmax |
| 句对关系 | 句对级 | NLI、相似度 | [CLS] → FC |
| 文本生成 | token级自回归 | 摘要、翻译 | GPT/Decoder 自回归 |
| 结构化预测 | token级+转移约束 | NER+CRF | BERT → CRF 层 |
