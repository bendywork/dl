# 数学基石 → 机器学习的桥梁

## 逻辑链

```
高等数学（微积分） → 梯度下降
线性代数（矩阵）   → 数据表示、参数矩阵、变换
概率论（条件概率） → 贝叶斯、损失函数推导
信息论（熵）       → 交叉熵损失、KL散度
```
