# 深度学习核心链路

## 闭合环路

```
前向传播 → 计算 Loss → 反向传播(梯度) → 更新参数 → 前向传播...
   ↑                                                      ↓
   └──────────────── 训练的完整闭环 ──────────────────────┘
```
