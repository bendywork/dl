# 机器学习核心算法链路

## 逻辑链

```
线性回归（最简模型）→ 梯度下降（优化方法）→ 逻辑回归（分类）→ Softmax（多分类）
                                         ↓
            KNN（距离） → 决策树（规则）→ 集成学习（组合）→ SVM（间隔最大化）
                                         ↓
                               朴素贝叶斯（概率） → KMeans（聚类，无监督）
```

## 关键过渡：ML → DL

ML 和 DL 的**流程完全相同**：加载数据 → 特征工程 → 训练 → 评估。

区别在于**特征工程由谁做**：
- ML：人工设计特征（TF-IDF、One-Hot、统计量）
- DL：网络自动学习特征（Embedding、CNN 卷积核、Transformer Attention）

→ 参考：`01_机器学习基础/01_监督学习/17_机器学习与深度学习的核心区别.md`
