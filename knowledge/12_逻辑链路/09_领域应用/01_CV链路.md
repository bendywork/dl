# CV 计算机视觉链路

## 逻辑链

```
图像→像素矩阵 → 卷积(特征提取) → 池化(降维) → 堆叠 → 全连接(分类)
    → 分类/检测/分割 → ResNet(骨干网络) → 多模态(CLIP)
```

## CV 核心任务

| 任务 | 粒度 | 输出 | 典型模型 |
|------|------|------|---------|
| 图像分类 | 图级 | 一个标签 | ResNet, ViT |
| 目标检测 | 框级 | bbox+类别 | YOLO, Faster R-CNN |
| 语义分割 | 像素级 | 每像素类别 | U-Net, DeepLab |
| 实例分割 | 像素级+ID | 每实例 mask | Mask R-CNN |

## 与 NLP 的对称性

```
NLP：文本 → Token Embedding → Attention → 分类/生成
CV ：图像 → Patch Embedding → Attention → 分类/检测  ← ViT
```

CNN 到 ViT 就是 CV 版的 RNN 到 Transformer。
