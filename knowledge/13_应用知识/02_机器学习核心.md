# 机器学习核心自查

---

## 一、机器学习是什么

```
传统编程：  规则 + 数据 → 输出
机器学习：  数据 + 输出 → 规则（模型）
```

核心思想：让模型从数据中自动学习规律，而不是手写规则。

---

## 二、训练框架流程图

```
原始数据
   ↓
数据预处理（归一化 / 分词 / 编码）
   ↓
划分训练集 / 验证集 / 测试集
   ↓
┌─────────────────────────────┐
│         训练循环             │
│                             │
│  初始化模型参数              │
│         ↓                  │
│  取一个 batch 数据           │
│         ↓                  │
│  前向传播 → 计算预测值        │
│         ↓                  │
│  计算损失 loss               │
│         ↓                  │
│  反向传播 → 计算梯度          │
│         ↓                  │
│  更新参数（优化器）           │
│         ↓                  │
│  清零梯度                   │
│         ↓                  │
│  重复直到收敛                │
└─────────────────────────────┘
   ↓
在验证集评估（调超参数）
   ↓
在测试集最终评估（只做一次）
```

## 三、核心概念自查

### 损失函数
- [ ] **损失函数的作用**：衡量预测值和真实值的差距，训练目标是最小化它
- [ ] **MSE**：`(ŷ - y)²` 均值，用于回归任务
- [ ] **交叉熵**：`-Σ y*log(ŷ)`，用于分类任务
- [ ] **reduction 参数**：`none` 返回每个样本的loss，`mean` 取均值，`sum` 求和

### 梯度下降三种形式
- [ ] **BGD**：全部数据算一次梯度，更新一次，梯度最准但慢
- [ ] **SGD**：每条样本算梯度立刻更新，更新频繁但噪声大
- [ ] **Mini-batch**：每个 batch 的梯度取平均再更新，实际中默认用这个
- [ ] **为什么叫"随机"**：随机指的是取数据的方式（随机抽样），不是公式有随机性

### 优化器
- [ ] **SGD**：`w = w - lr * grad`，最基础
- [ ] **Adam**：自适应学习率，综合了动量和 RMSProp，实际中最常用
- [ ] **学习率**：步长，太大震荡不收敛，太小收敛太慢
- [ ] **梯度裁剪**：防止梯度爆炸，把梯度范数限制在阈值内

### 模型评估
- [ ] **过拟合**：训练集好、验证集差，模型记住了训练数据而不是学到规律
- [ ] **欠拟合**：训练集和验证集都差，模型容量不够
- [ ] **正则化**：L1/L2/Dropout，缓解过拟合
- [ ] **train/eval 模式**：`model.train()` 开启 Dropout，`model.eval()` 关闭
- [ ] **准确率 vs 损失**：损失是训练信号，准确率是业务指标，两者都要看
