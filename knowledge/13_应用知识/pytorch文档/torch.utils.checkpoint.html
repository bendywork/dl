torch.utils — 工具模块

torch.utils.checkpoint · 梯度检查点

Trades compute for memory — recomputes activations during backward instead of storing them. torch.utils.checkpoint.checkpoint(fn, *args). Useful for training large models with limited GPU memory.

用计算换内存 —— 反向传播时重新计算激活值而非存储。checkpoint(fn, *args)。GPU 显存有限时训练大模型非常有用。

torch.utils.tensorboard · TensorBoard

Write scalars, images, histograms, embeddings, and model graphs to TensorBoard event files. SummaryWriter.add_scalar('loss', loss, step), .add_image(), .add_graph(), .add_embedding().

将标量、图像、直方图、embedding 和模型图写入 TensorBoard 事件文件。SummaryWriter.add_scalar('loss', loss, step) 添加标量、.add_image() 添加图像、.add_graph() 添加模型图、.add_embedding() 添加 embedding。

torch.utils.benchmark · 性能基准

Precise performance measurements. Timer(stmt='...', setup='...').blocked_autorange() for micro-benchmarks. Fuzzer for parameter exploration.

精确性能测量。Timer 用于微基准测试、Fuzzer 用于参数探索。

torch.utils.cpp_extension · C++/CUDA 扩展

Build C++/CUDA extensions from Python. load(name, sources) with JIT compilation. BuildExtension with setuptools. CUDAExtension for CUDA kernels.

从 Python 构建 C++/CUDA 扩展。load(name, sources) JIT 编译加载、BuildExtension setuptools 集成、CUDAExtension CUDA kernel 支持。
