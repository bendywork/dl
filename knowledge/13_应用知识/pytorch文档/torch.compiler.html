编译与导出 — torch.compiler · export · fx · onnx · package · library

torch.compiler · 图编译加速

torch.compile(model) is the main entry point for JIT-compiling PyTorch models to faster code. Backends: TorchInductor (default, Triton/OpenMP), ONNX Runtime, TensorRT, AOTAutograd.

torch.compile(model) 是 JIT 编译 PyTorch 模型的主入口。后端：TorchInductor（默认，Triton/OpenMP）、ONNX Runtime、TensorRT、AOTAutograd。

model = torch.compile(model, mode='reduce-overhead')  # 或 'max-autotune'
output = model(input)  # 首次运行触发编译，后续直接跑优化后的 kernel

torch.export · 模型导出

PT2 Export — traces model into a graph representation. torch.export.export(model, args) produces an ExportedProgram that can be serialized, run standalone, or converted to other formats.

PT2 导出 —— 将模型追踪为图表示。torch.export.export(model, args) 产生一个 ExportedProgram，可序列化、独立运行或转换为其他格式。

torch.fx · FX 图 IR

Intermediate representation that captures model computation as a graph. Enables graph-level transformations: operator fusion, quantization, shape inference.

以图形式捕获模型计算的中间表示。支持图级变换：算子融合、量化、形状推断。

gm = torch.fx.symbolic_trace(model)  # 生成 FX GraphModule
gm.graph.print_tabular()              # 查看图结构

torch.onnx · ONNX 导出

Export PyTorch models to ONNX (Open Neural Network Exchange) format for inference on other runtimes (ONNX Runtime, TensorRT, OpenVINO).

将 PyTorch 模型导出为 ONNX（开放神经网络交换）格式，用于在其他运行时（ONNX Runtime、TensorRT、OpenVINO）上推理。

torch.onnx.export(model, dummy_input, "model.onnx", input_names=['x'], output_names=['y'])

torch.package · 模型打包

Package format for bundling models, code, and weights into a single archive. Supports versioning, dependency management, and hermetic reproducibility.

将模型、代码和权重打包为单一存档的格式。支持版本管理、依赖管理和封闭的可复现性。

torch.library · 自定义算子

Register custom operators (C++/Python) into PyTorch's dispatcher. Make custom ops work with torch.compile, vmap, autograd, etc.

将自定义算子（C++/Python）注册到 PyTorch 调度器。让自定义算子与 torch.compile、vmap、autograd 等兼容。
