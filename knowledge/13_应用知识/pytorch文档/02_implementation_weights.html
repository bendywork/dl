02 · 实现示例与权重加载 Implementation & Weight Loading

resnet18 Implementation Example 完整示例

The hubconf.py file typically declares a dependencies list and one or more entrypoint functions. Here is the complete resnet18 example:

hubconf.py 文件通常声明一个 dependencies 列表以及一个或多个入口函数。以下是完整的 resnet18 示例：

dependencies = ['torch']
from torchvision.models.resnet import resnet18 as _resnet18

# resnet18 is the name of entrypoint
def resnet18(pretrained=False, **kwargs):
    """ # This docstring shows up in hub.help()
    Resnet18 model
    pretrained (bool): kwargs, load pretrained weights into the model
    """
    # Call the model, load pretrained weights
    model = _resnet18(pretrained=pretrained, **kwargs)
    return model

Key points: dependencies lists packages needed to load (not necessarily train) the model. The function docstring becomes the help message in torch.hub.help(). *args and **kwargs pass through to the underlying model constructor.

关键要点：dependencies 列出加载模型所需的包（不一定是训练所需）。函数文档字符串会成为 torch.hub.help() 中的帮助信息。*args 和 **kwargs 透传给底层的模型构造函数。

Loading Pretrained Weights — Local 本地加载权重

If pretrained weights are stored locally in the GitHub repository alongside the hubconf.py:

如果预训练权重与 hubconf.py 一起存储在 GitHub 仓库中：

if pretrained:
    dirname = os.path.dirname(__file__)
    checkpoint = os.path.join(dirname, <RELATIVE_PATH_TO_CHECKPOINT>)
    state_dict = torch.load(checkpoint)
    model.load_state_dict(state_dict)

__file__ refers to the location of hubconf.py. Replace <RELATIVE_PATH_TO_CHECKPOINT> with the actual relative path to your checkpoint file.

__file__ 指向 hubconf.py 所在位置。将 <RELATIVE_PATH_TO_CHECKPOINT> 替换为检查点文件的实际相对路径。

Loading Pretrained Weights — from URL 远程 URL 加载

Load weights from a remote URL using torch.hub.load_state_dict_from_url():

使用 torch.hub.load_state_dict_from_url() 从远程 URL 加载权重：

checkpoint = 'https://download.pytorch.org/models/resnet18-5c106cde.pth'
model.load_state_dict(torch.hub.load_state_dict_from_url(checkpoint, progress=False))

The progress=False flag suppresses the download progress bar. For files under 2GB, attaching them to a GitHub project release is the recommended approach.

progress=False 参数会隐藏下载进度条。对于小于 2GB 的文件，推荐将其附加到 GitHub 项目 Release 中。
