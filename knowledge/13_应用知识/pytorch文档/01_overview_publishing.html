01 · 概述与模型发布 Overview & Publishing Models

PyTorch Hub is a pre-trained model repository designed to facilitate research reproducibility.

PyTorch Hub 是一个预训练模型仓库，旨在促进研究的可复现性。

Publishing Models 发布模型

Publishing models. PyTorch Hub supports publishing pre-trained models (model definitions and pre-trained weights) to a GitHub repository by adding a simple hubconf.py file.

发布模型。PyTorch Hub 支持通过添加一个简单的 hubconf.py 文件，将预训练模型（模型定义和预训练权重）发布到 GitHub 仓库。

hubconf.py can have multiple entrypoints. Each entrypoint is defined as a Python function.

hubconf.py 可以有多个入口点（entrypoint）。每个入口点定义为一个 Python 函数。

Entrypoint Function Specification 入口函数规范

def entrypoint_name(*args, **kwargs):
    # args & kwargs are optional, for models which take positional/keyword arguments.
    ...

Each entrypoint function should return a model (a nn.Module). The *args and **kwargs are passed through to the real callable function. The docstring of the function works as a help message. It is highly recommended to include examples in the docstring. Pretrained weights can either be stored locally in the GitHub repo, or loadable by torch.hub.load_state_dict_from_url(). For weight files less than 2GB, it's recommended to attach them to a project release. Entrypoints prefixed with underscore are treated as helper functions and won't show up in torch.hub.list(). Entrypoints can also return other types such as tokenizers.

每个入口函数应返回一个模型（nn.Module）。*args 和 **kwargs 会透传给实际的可调用函数。函数的文档字符串（docstring）作为帮助信息，强烈建议在文档字符串中包含示例。预训练权重可以存储在 GitHub 仓库的本地，也可以通过 torch.hub.load_state_dict_from_url() 加载。对于小于 2GB 的权重文件，建议附加到项目 release 中。以下划线开头的入口点被视为辅助函数，不会在 torch.hub.list() 中显示。入口点也可以返回其他类型，如分词器（tokenizer）。

dependencies 依赖声明

dependencies is a list of package names required to load the model. Note these might be slightly different from dependencies required for training a model.

dependencies 是加载模型所需的包名列表。注意这些依赖可能与训练模型所需的依赖略有不同。

Important Notice 重要通知

Published models should be at least in a branch/tag. It can't be a random commit.

已发布的模型应至少位于某个分支（branch）或标签（tag）中，不能是一个随机的提交（commit）。
