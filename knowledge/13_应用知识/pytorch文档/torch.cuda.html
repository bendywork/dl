torch.cpu · CPU 设备

Utility to control CPU thread affinity and streaming. torch.cpu.set_num_threads(n), torch.cpu.get_num_threads().

CPU 线程亲和性和流控制。set_num_threads(n) 设置线程数、get_num_threads() 获取线程数。

CUDA operations: device management, memory stats, streams, events, and synchronization.

CUDA 操作：设备管理、显存统计、流、事件和同步。

torch.mps · Apple Metal

Apple Metal Performance Shaders backend for M-series chips. API mirrors CUDA: torch.mps.is_available(), torch.mps.synchronize(), torch.mps.empty_cache().

Apple M 系列芯片的 Metal 后端。API 镜像 CUDA：is_available()、synchronize()、empty_cache()。

torch.xpu · Intel XPU

Intel GPU backend. torch.xpu.is_available(), torch.xpu.device_count().

Intel GPU 后端。is_available() 检查可用性、device_count() 设备数量。

torch.mtia · MTIA 加速器

Meta Training and Inference Accelerator backend. torch.mtia.is_available(), memory management, graph capture.

Meta 训练推理加速器后端。is_available()、内存管理、图捕获。

torch.accelerator · 通用加速器

Generic accelerator abstraction layer — write once, run on any backend (CUDA, MPS, XPU, MTIA). torch.accelerator.current_accelerator(), torch.accelerator.device_count().

通用加速器抽象层 —— 写一次代码，运行在任意后端（CUDA、MPS、XPU、MTIA）。current_accelerator() 当前加速器、device_count() 设备数。

Meta Device · 元设备

device='meta' tensors have shape/dtype but no data — used for model initialization without actual computation (e.g., loading huge models for distributed training without allocating memory).

device='meta' tensor 有 shape/dtype 但无实际数据 —— 用于无需计算的模型初始化（例如分布式训练中加载巨大模型但不分配显存）。

torch.backends · 后端配置

Backend library configuration: torch.backends.cudnn.benchmark = True (auto-tune conv), torch.backends.cuda.matmul.allow_tf32 = True (TF32 for faster matmul), torch.backends.mkl.is_available() (Intel MKL status).

后端库配置：cudnn.benchmark=True（自动优化卷积算法）、cuda.matmul.allow_tf32=True（TF32 加速矩阵乘）、mkl.is_available()（Intel MKL 状态）。
