torch.Size · 维度大小对象

torch.Size is the subclass of tuple returned by .size(). Supports all tuple operations plus NumPy-style dim access.

torch.Size 是 .size() 返回的 tuple 子类。支持所有 tuple 操作和 NumPy 式维度访问。

x = torch.randn(2, 3, 4)
s = x.size()           # torch.Size([2, 3, 4])
s[0]                   # 2
s[1:]                  # torch.Size([3, 4])
s.numel()              # 24 = 2*3*4

torch.Storage · 底层存储

torch.Storage is a contiguous 1D array of a single data type behind every tensor. Tensors are views onto a storage with shape+strides.

torch.Storage 是每个 tensor 背后的连续 1D 数组（单一数据类型）。Tensor 是 storage 上的 view（通过 shape+strides 映射）。

x = torch.randn(3, 4)
s = x.untyped_storage()  # 底层 storage，1D，含 12 个 float
x[0,0] = 999             # 修改 tensor
s[0]                     # 999 — storage 也变了

torch.UntypedStorage is the untyped base class. torch.FloatStorage, torch.IntStorage etc. are typed variants.

torch.UntypedStorage 是无类型基类。torch.FloatStorage、torch.IntStorage 等是带类型变体。

torch.sparse · 稀疏 Tensor

Sparse tensors store only non-zero elements, saving memory for mostly-zero data. 3 main formats: COO (Coordinate), CSR (Compressed Sparse Row), CSC (Compressed Sparse Column).

稀疏 tensor 仅存储非零元素，对于大部分为零的大矩阵可大幅节省内存。3 种主要格式：COO（坐标格式）、CSR（行压缩）、CSC（列压缩）。

# COO: indices + values
i = torch.tensor([[0, 1, 1], [2, 0, 2]])  # indices
v = torch.tensor([3, 4, 5])                # values
s = torch.sparse_coo_tensor(i, v, (2, 3))   # → [[0,0,3],[4,0,5]]

s.to_dense()  # 转稠密 tensor
# tensor([[0, 0, 3],
#         [4, 0, 5]])

Supported ops include add, mm, mul. Not all dense ops are implemented for sparse tensors.

支持的操作包括 add, mm, mul。并非所有稠密操作都对稀疏 tensor 实现了。
