torch.nn.functional — 函数式 API (F.relu, F.softmax, ...)

nn.functional vs nn.Module · 函数 vs 模块

F.relu(x) is stateless (just a function). nn.ReLU() is a Module with state. For ops without learnable parameters, F.* is more concise. For ops with parameters (like nn.Conv2d), use nn.Module so params are tracked.

F.relu(x) 是无状态的（纯函数）。nn.ReLU() 是带状态的 Module。无参数操作用 F.* 更简洁。含可训练参数的操作（如卷积）必须用 nn.Module 子类，否则参数无法被追踪。

Key Rule of Thumb · 使用原则

Use nn.* when the layer has learnable parameters (conv, linear, bn). Use F.* for stateless ops (relu, max_pool, softmax) — though nn.ReLU() works fine too.

有可训练参数时用 nn.*（conv、linear、batchnorm）。无状态操作用 F.* 更简洁（relu、max_pool、softmax）—— 不过 nn.ReLU() 也能用。
