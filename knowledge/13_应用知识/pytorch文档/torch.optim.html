torch.optim — 优化算法

Overview · 概述

torch.optim is a package implementing various optimization algorithms. Most commonly used methods are already supported, and the interface is general enough to integrate more sophisticated ones in the future.

torch.optim 是实现了多种优化算法的包。最常用的方法均已支持，接口足够通用以集成更复杂的算法。

How to Use · 如何使用

Construct it with an iterable of Parameters (or dicts of parameter groups), then specify optimizer-specific options (lr, weight_decay, etc).

构造时传入可迭代的 Parameter 对象（或参数组字典），再指定优化器相关的选项（学习率、权重衰减等）。

optimizer = optim.SGD(model.parameters(), lr=0.01, momentum=0.9)
optimizer = optim.Adam([var1, var2], lr=0.0001)

Per-Parameter Options · 逐参数配置

Pass an iterable of dicts with a params key to set per-group options:

传入字典可迭代对象，使用 params 键设置分组选项：

optim.SGD([
    {'params': model.base.parameters(), 'lr': 1e-2},
    {'params': model.classifier.parameters()}
], lr=1e-3, momentum=0.9)

model.base gets lr=1e-2, model.classifier uses the default 1e-3, both get momentum 0.9.

model.base 学习率为 1e-2，model.classifier 使用默认值 1e-3，两者都使用 momentum=0.9。

Taking a Step · 执行一步优化

for input, target in dataset:
    optimizer.zero_grad()
    output = model(input)
    loss = loss_fn(output, target)
    loss.backward()
    optimizer.step()

Base Class · 基类

class torch.optim.Optimizer(params, defaults) — Base class for all optimizers.

Parameters need to be specified as collections that have a deterministic ordering consistent between runs.

class torch.optim.Optimizer(params, defaults) — 所有优化器的基类。

参数需以确定性顺序的集合形式指定，保证运行间一致。

Learning Rate Schedulers · 学习率调度器

Apply scheduling after optimizer.step(). Calling before skips the first value of the schedule.

在 optimizer.step() 之后应用调度。在此之前调用会跳过第一个调度值。

optimizer = optim.SGD(model.parameters(), lr=0.01, momentum=0.9)
scheduler = ExponentialLR(optimizer, gamma=0.9)
for epoch in range(20):
    for input, target in dataset:
        ... optimizer.zero_grad(); loss.backward(); optimizer.step()
    scheduler.step()

Weight Averaging (SWA / EMA) · 权重平均

# SWA
swa_model = AveragedModel(model)
swa_scheduler = SWALR(optimizer, swa_lr=0.05)

# EMA
ema_model = AveragedModel(model, multi_avg_fn=get_ema_multi_avg_fn(0.999))
ema_model.update_parameters(model)  # after optimizer.step()

# Update BN stats
torch.optim.swa_utils.update_bn(loader, averaged_model)

SWA averages weights for wider optima and better generalization. EMA uses exponential weights instead of equal weights. Decay should be close to 1.0 (default 0.999).

SWA 平均权重以获得更宽的最优解和更好的泛化。 EMA 使用指数权重而非等权。衰减值应接近 1.0（默认 0.999）。
