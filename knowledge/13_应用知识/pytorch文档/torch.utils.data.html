torch.utils.data — Dataset, DataLoader, Sampler

Dataset · 数据集基类

Abstract class representing a dataset. Subclass and implement __len__ and __getitem__.

表示数据集的抽象类。继承并实现 __len__ 和 __getitem__。

class MyDataset(Dataset):
    def __init__(self, data, labels): self.data, self.labels = data, labels
    def __len__(self): return len(self.data)
    def __getitem__(self, idx): return self.data[idx], self.labels[idx]

DataLoader · 数据加载器

Combines dataset + sampler, provides iterable over batches. Handles batching, shuffling, multiprocessing.

组合 dataset 和 sampler，提供可迭代的批量数据。处理批量化、随机打乱和多进程。

loader = DataLoader(dataset, batch_size=64, shuffle=True, num_workers=4,
                    collate_fn=collate_fn, pin_memory=True, drop_last=True)

Built-in Datasets · 内置数据集

TensorDataset(*tensors) — wraps tensors into a dataset. ConcatDataset([d1, d2]) — concatenates datasets. Subset(dataset, indices) — select subset.

TensorDataset(*tensors) 将多个 tensor 包装为数据集；ConcatDataset([d1,d2]) 拼接数据集；Subset(dataset, indices) 选取子集。
