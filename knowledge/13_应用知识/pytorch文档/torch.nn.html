torch.nn — 神经网络模块

nn.Module · 模块基类

Base class for all neural network modules. Your models should subclass this. Automatically tracks parameters, buffers, and sub-modules.

所有神经网络模块的基类。你的模型应继承此类。自动追踪参数、缓冲区（buffer）和子模块。

class MyModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc = nn.Linear(10, 5)       # 自动注册为子模块
    def forward(self, x):
        return self.fc(x)
