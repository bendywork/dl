torch.distributed · 分布式核心

Core distributed communication. Backend options: NCCL (GPU, default), Gloo (CPU), MPI.

核心分布式通信。后端选项：NCCL（GPU，默认）、Gloo（CPU）、MPI。

torch.distributed.init_process_group(backend='nccl', init_method='env://')
model = nn.parallel.DistributedDataParallel(model)  # DDP
torch.distributed.all_reduce(tensor)                # 集合通信

torch.distributed.fsdp · FSDP 完全分片

Fully Sharded Data Parallel — shards model parameters, gradients, and optimizer states across GPUs. Memory-efficient for large models. fully_shard is FSDP2 with simplified API.

FSDP（完全分片数据并行）—— 将模型参数、梯度和优化器状态分片到多块 GPU。大模型内存高效。fully_shard 是 FSDP2，API 更简洁。

from torch.distributed.fsdp import FullyShardedDataParallel as FSDP
model = FSDP(model)
# FSDP2:
from torch.distributed.fsdp import fully_shard
fully_shard(model)

torch.distributed.tensor.parallel · 张量并行

Splits individual layers across devices — each device holds a portion of the weight matrix. Used in large-scale models (alongside FSDP).

将单个层的权重矩阵拆分到多个设备 —— 每块 GPU 持有一部分权重。大规模模型中使用（配合 FSDP）。

torch.distributed.pipelining · 流水线并行

Splits model layers across devices, passing activations through the pipeline. Reduces idle time with micro-batching.

将模型按层拆分到设备，通过管线传递激活值。使用微批处理减少空闲时间。

torch.distributed.elastic · 弹性训练

Dynamic scaling — nodes can join/leave during training. TorchElastic for fault-tolerant distributed training on preemptible instances.

动态扩缩容 —— 节点可在训练过程中加入/离开。TorchElastic 用于可抢占实例上的容错分布式训练。
