torch.autograd — 自动微分

Overview · 概述

torch.autograd provides classes and functions implementing automatic differentiation of arbitrary scalar valued functions. Tensors needing gradient computation should declare requires_grad=True.

torch.autograd 提供了对任意标量值函数进行自动微分的类和函数。需要梯度计算的 tensor 应声明 requires_grad=True。

Custom Function · 自定义自动微分函数

class Exp(Function):
    @staticmethod
    def forward(ctx, i):
        result = i.exp()
        ctx.save_for_backward(result)
        return result

    @staticmethod
    def backward(ctx, grad_output):
        result, = ctx.saved_tensors
        return grad_output * result

output = Exp.apply(input)

Subclass Function and implement forward() + backward() as static methods. Use via .apply() — do not call forward() directly.

ctx methods: save_for_backward(), mark_dirty(), mark_non_differentiable(), set_materialize_grads().

继承 Function 并实现 forward() + backward() 静态方法。通过 .apply() 使用 —— 不要直接调用 forward()。

ctx 方法：save_for_backward() 保存 tensor 供 backward 使用、mark_dirty() 标记被修改的 tensor、mark_non_differentiable() 标记输出不可导、set_materialize_grads() 设置是否物化梯度。

Profiler · 性能分析器

with torch.autograd.profiler.profile() as prof:
    for _ in range(100):
        y = x ** 2
        y.backward()
print(prof.key_averages().table(sort_by="self_cpu_time_total"))

Three profiler modes: profile (CPU), emit_nvtx (NVIDIA nvprof), emit_itt (Intel VTune). Most users should use torch.profiler instead.

三种分析器模式：profile（CPU）、emit_nvtx（NVIDIA nvprof）、emit_itt（Intel VTune）。大多数用户应使用 torch.profiler。

Anomaly Detection · 异常检测

with torch.autograd.detect_anomaly(check_nan=True):
    loss.backward()  # 如果梯度出现 NaN，会立即报错并显示前向调用栈

Enables backward to print the traceback of the forward operation that created the failing backward function. check_nan=True (default) raises an error if any backward computation produces "nan". Only for debugging — slows down execution.

使反向传播能够打印出创建失败 backward 函数的前向操作调用栈。check_nan=True（默认）在反向传播产生 nan 时立即报错。仅用于调试 —— 会减慢执行速度。

Saved Tensors Hooks · 保存 Tensor 钩子

def pack_hook(x): return x.detach()
def unpack_hook(x): return x
with torch.autograd.graph.saved_tensors_hooks(pack_hook, unpack_hook):
    y = a * b
y.sum().backward()

save_on_cpu: Store saved tensors on CPU during forward, copy back for backward. Useful when model doesn't fit in GPU memory.

save_on_cpu：前向传播时将保存的 tensor 存储在 CPU 上，反向时复制回 GPU。模型超出 GPU 显存时非常有用。

Gradient Layout Best Practice · 梯度布局

Let .grad be None before first backward(), or reset to None each accumulation phase:

让 .grad 在第一次 backward() 之前保持 None，或在每个累积阶段重置为 None：

for param in model.parameters():
    param.grad = None          # 推荐：比 zero_grad() 更安全
loss.backward()
