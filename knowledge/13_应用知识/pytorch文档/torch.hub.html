torch.hub — 预训练模型仓库

Overview · 概述

PyTorch Hub is a pre-trained model repository designed to facilitate research reproducibility.

PyTorch Hub 是一个预训练模型仓库，旨在促进研究的可复现性。

Publishing Models · 发布模型

PyTorch Hub supports publishing pre-trained models (model definitions and pre-trained weights) to a GitHub repository by adding a simple hubconf.py file. hubconf.py can have multiple entrypoints. Each entrypoint is defined as a Python function.

PyTorch Hub 支持通过添加 hubconf.py 文件将预训练模型发布到 GitHub 仓库。每个入口点定义为 Python 函数，可以有多个入口点。

Entrypoint Spec · 入口函数规范

def entrypoint_name(*args, **kwargs):
    # args & kwargs are optional, for models which take positional/keyword arguments.
    ...

Each entrypoint returns a model (nn.Module). Docstring = help message (examples recommended). Functions prefixed with underscore are helper functions, won't show in torch.hub.list(). Published models should be at least in a branch/tag, not a random commit.

每个入口点返回一个模型（nn.Module）。文档字符串 = 帮助信息（建议包含示例）。以下划线开头的函数为辅助函数，不在 torch.hub.list() 中显示。已发布的模型应至少位于分支/标签中，不能是随机 commit。

Implementation Example · 实现示例 (resnet18)

dependencies = ['torch']
    from torchvision.models.resnet import resnet18 as _resnet18

def resnet18(pretrained=False, **kwargs):
    """ # This docstring shows up in hub.help()
    Resnet18 model
    pretrained (bool): load pretrained weights into the model
    """
    model = _resnet18(pretrained=pretrained, **kwargs)
    return model

dependencies = packages needed to load (may differ from training dependencies). *args/**kwargs pass through to the callable.

dependencies = 加载模型所需的包（可能不同于训练所需）。*args/**kwargs 透传给可调用对象。

Loading Pretrained Weights · 加载预训练权重

Local (stored in repo):

本地加载（权重文件在仓库中）：

if pretrained:
    dirname = os.path.dirname(__file__)
    checkpoint = os.path.join(dirname, <RELATIVE_PATH_TO_CHECKPOINT>)
    state_dict = torch.load(checkpoint)
    model.load_state_dict(state_dict)

From URL:

从 URL 加载：

checkpoint = 'https://download.pytorch.org/models/resnet18-5c106cde.pth'
model.load_state_dict(torch.hub.load_state_dict_from_url(checkpoint, progress=False))

For files < 2GB, attaching to a GitHub project release is recommended.

对于小于 2GB 的文件，建议附加到 GitHub 项目 release 中。

Download Location & Caching · 下载位置与缓存

Cache directory priority: ① hub.set_dir(PATH) → ② $TORCH_HOME/hub → ③ $XDG_CACHE_HOME/torch/hub → ④ ~/.cache/torch/hub

缓存目录优先级：① hub.set_dir(PATH) → ② $TORCH_HOME/hub → ③ $XDG_CACHE_HOME/torch/hub → ④ ~/.cache/torch/hub

torch.hub.get_dir()       # Get cache dir → str
torch.hub.set_dir(d)      # Set cache dir → None

Files are not cleaned up by default. force_reload=True deletes cached GitHub folder + weights and re-downloads.

文件默认不清除。force_reload=True 会删除缓存的 GitHub 文件夹和权重并重新下载。

Running a Loaded Model · 运行已加载模型

After loading, use dir(model) to see methods and help(model.foo) to check arguments. Repo owners should include clear help messages and minimal working examples.

加载后使用 dir(model) 查看方法，help(model.foo) 查看参数。仓库作者应提供清晰的帮助信息以及最小可用示例。

Known Limitations · 已知限制

1. Import side effects: Torch Hub imports packages as if installed, adding to sys.modules. Different repos sharing sub-package names (e.g. model) can cause import errors. Workaround: remove the conflicting sub-package from sys.modules.

1. 导入副作用：Torch Hub 以安装方式导入包，添加到 sys.modules。不同仓库共享子包名（如 model）可能导致导入错误。解决方法：从 sys.modules 中移除冲突子包。

2. Same-repo limitation: You CANNOT load two different branches of the same repo in the same Python process. Loading in separate processes works fine.

2. 同一仓库限制：不能在同一 Python 进程中加载同一仓库的两个不同分支。在不同进程中加载则正常工作。
