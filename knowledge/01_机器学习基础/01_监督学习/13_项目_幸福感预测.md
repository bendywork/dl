# 项目：幸福感预测

## 一、业务问题

根据多维度问卷数据（收入、健康、家庭、工作等），预测个人幸福感（回归任务 or 有序多分类）。

## 二、任务流程

```
数据加载 → 数据处理(缺失值+编码) → 多模型对比(逻辑回归/随机森林/XGBoost/LGB)
    → 回归预测 → 指标评估 → 特征重要性
```

## 三、与二分类项目的关键差异

| | 电信流失/金融风控 | 幸福感预测 |
|---|---|---|
| 任务类型 | 二分类 | **回归**或有序多分类 |
| 标签 | 0/1 | 1-5 或 1-10 连续值 |
| 评估指标 | AUC/F1/KS | **MSE/MAE/R²** |
| 模型输出 | 类别概率 | 连续数值 |

## 四、数据处理

- 问卷特征多（几十上百个），需变量筛选
- 有序类别特征（如"非常不满意→非常满意"）按 1-5 编码
- 无序类别特征 One-Hot

## 五、多模型对比策略

用完全相同的训练/测试集+预处理，分别训练多个模型，对比结果选最优：

| 模型 | 特点 |
|------|------|
| 逻辑回归 | 基线，可解释性强 |
| 随机森林 | 非线性，不易过拟合 |
| XGBoost | 树模型 SOTA，需调参 |
| LightGBM | 比 XGBoost 更快，大数据首选 |

## 六、核心要点

回归任务中 MSLE（对数均方误差）有时比 MSE 更好——它惩罚相对误差而非绝对误差，对取值范围大的标签更公平。
