# 项目：金融风控贷款违约预测

## 一、业务问题

根据用户个人信息和信用数据，预测贷款是否会违约（二分类）。核心是**降低坏账率**。

## 二、任务流程

```
数据加载(多表关联) → 数据分析 → 特征工程(衍生+编码)
    → LightGBM训练 → 阈值调优 → 预测与评估
```

## 三、与电信流失项目的关键差异

| | 电信流失 | 金融风控 |
|---|---|---|
| 标签分布 | 20%流失 | 通常 < 5% 违约，极度不平衡 |
| 数据来源 | 单一表格 | 多表关联（用户+信用+交易） |
| 误判代价 | 挽回成本 | 本金损失 |
| 重点指标 | Recall | **AUC + KS**（风控专用） |

## 四、数据分析重点

1. **标签分布**：违约率是否极低 → 确定采样策略
2. **缺失值分析**：缺失多的特征是否业务上合理
3. **异常值检测**：收入为负、年龄 0 岁等
4. **特征分布**：偏移 → 对模型有影响

## 五、特征工程

- 数值特征：分箱（年龄分段）、交叉特征（负债率 = 负债/收入）
- 类别特征：高基数类别用 target encoding 或频率编码
- 时间特征：距离最近一次逾期天数等

## 六、KS 指标（风控专用）

```
KS = max(|TPR - FPR|)
```
- 衡量模型**区分好坏用户**的能力
- KS > 0.3：可用；KS > 0.5：优秀

## 七、阈值调优

不直接用 `predict()`（默认阈值 0.5），而是：
1. 输出概率 `predict_proba()`
2. 根据业务（通过率 vs 坏账率）选最优阈值
3. 阈值越低，通过的越多，坏账也越多——找平衡点
