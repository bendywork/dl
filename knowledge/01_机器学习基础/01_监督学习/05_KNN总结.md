# KNN (K近邻) 总结

## 一、核心思想

**"近朱者赤，近墨者黑"——一个样本的类别由它最近的 K 个邻居投票决定。**

KNN 没有训练过程，是典型的**惰性学习**（lazy learning）：收到训练数据只存储，不训练；预测时才计算。

## 二、算法流程

```
训练阶段：存数据（什么都不学）

预测阶段：
1. 计算新样本与所有训练样本的距离
2. 选出距离最近的 K 个邻居
3. K 个邻居投票，多数类别 = 预测结果
4. 回归任务：K 个邻居的均值/加权均值 = 预测值
```

## 三、距离度量

| 距离 | 公式 | 适用场景 |
|------|------|---------|
| 欧氏距离 | `√Σ(x_i - y_i)²` | 最常用，直线距离 |
| 曼哈顿距离 | `Σ|x_i - y_i|` | 网格状数据 |
| 闵可夫斯基距离 | `(Σ|x_i - y_i|^p)^(1/p)` | p=2=欧氏, p=1=曼哈顿 |

**欧氏距离最常用，但前提是特征已标准化。** 否则量纲大的特征会主导距离计算。

## 四、K 值选择（关键超参数）

| K 太小 | K 太大 |
|--------|--------|
| 对噪声敏感，易过拟合 | 决策边界过于平滑，易欠拟合 |
| K=1 → 最近邻就是预测结果 | K=N → 永远预测多数类 |

**经验**：K 取奇数+交叉验证选最优。一般从 `√(样本数)` 附近试。

## 五、思考链路

```
1. 特征标准化（必须！不同量纲会扭曲距离）
2. 选距离度量（默认欧氏）
3. 选 K 值（交叉验证）
4. 对新样本：算距离 → 找 K 近邻 → 投票/平均 → 输出
```

## 六、手动实现 vs sklearn

**手动实现核心代码**：
```python
distances = np.sqrt(np.sum((X_train - x_test)**2, axis=1))
nearest = np.argsort(distances)[:K]
top_k_labels = y_train[nearest]
pred = Counter(top_k_labels).most_common(1)[0][0]
```

**sklearn**：`KNeighborsClassifier(n_neighbors=K).fit(X, y)`

## 七、优点与局限

| 优点 | 局限 |
|------|------|
| 无需训练，模型简单 | 预测慢（每次要算所有距离） |
| 天然支持多分类 | 维度灾难（高维时距离失效） |
| 无假设（非参数方法） | 需存所有训练数据，内存大 |
