# 机器学习 vs 深度学习：流程相同，特征工程不同

## 📌 核心问题
> 机器学习和深度学习的流程有什么相同和不同？核心区别到底在哪里？

## 🌱 根源与动机

很多人以为深度学习是机器学习的"升级版"，用更复杂的模型替代简单模型。但真正的核心区别不在于模型复杂度，而在于**特征谁来提取**——是人工设计，还是模型自动学习。

## 📐 流程框架：两者相同

不管是 ML 还是 DL，流程框架基本一致：

```
数据准备 → 划分 train/val/test → 训练 → 评估 → 部署
```

| 步骤 | ML | DL | 是否相同 |
|------|----|----|---------|
| 数据准备 | 需要 | 需要 | ✅ 相同 |
| 数据划分 | train/val/test | train/val/test | ✅ 相同 |
| 训练 | 优化参数 | 优化参数 | ✅ 相同 |
| 评估 | 准确率/F1/混淆矩阵 | 准确率/F1/混淆矩阵 | ✅ 相同 |
| 部署 | 保存模型 → 推理 | 保存模型 → 推理 | ✅ 相同 |

**流程完全一样，评估指标也通用。**

## 💡 核心区别：特征工程

### 关键概念区分：特征 ≠ 参数

| | 特征 (Feature) | 参数 (Parameter) |
|---|---|---|
| 是什么 | 输入数据的表示 | 模型内部的权重 |
| 例子 | "是否有涨字"、"文本长度" | SVM 权重 w、神经网络权重 |
| ML 中 | 人设计 | 数据学 |
| DL 中 | 模型学 | 数据学 |

**参数在 ML 和 DL 中都是从数据学出来的——这点相同。差别只在特征。**

### 传统机器学习：人工特征工程

特征工程的完整流程：

```
第1步：设定特征含义 + 创建字段
  has_rise:    标题是否含"涨"字
  has_fall:    标题是否含"跌"字
  text_length: 标题长度
  has_negation:是否含否定词

第2步：设计值域
  has_rise:     {0, 1}
  has_fall:     {0, 1}
  text_length:  {1, 79}
  has_negation: {0, 1}

第3步：根据数据样本赋值
  "下周看涨"   → [1, 0, 4, 0]
  "暴跌完了"   → [0, 1, 4, 0]
  "不看好后市" → [0, 0, 5, 1]

第4步：这就是输入 X → 喂给模型 → 训练得到参数 W
```

人定特征含义、定值域、写代码算特征值，构造出特征矩阵作为输入。**参数（SVM 权重）依然是从数据学的。**

### 深度学习：模型自动学特征

```
"下周看涨" → 字转id
  ↓ Embedding（参数，学的）
  ↓ Transformer（参数，学的，同时提取特征）
  ↓ 分类头（参数，学的）
结果
```

不需要人设计特征，模型通过 Embedding + 网络层**自己学出"看涨=利好"这种表示**。特征和参数都是学的。

### 对比表

| | 传统 ML | 深度学习 |
|---|---|---|
| **特征** | 人设计（固定） | 模型学（动态） |
| **参数** | 模型学 | 模型学 |
| **输入** | 提取好的特征向量 | 原始数据（文本/图像/音频） |
| **模型职责** | 只做分类/回归 | 既提特征又做分类 |
| **人干什么** | 设计好特征 | 只给原始数据 |

## 🔧 这个区别解释了一切

| 现象 | 原因 |
|------|------|
| DL 需要大量数据 | 模型要自己学特征，数据少学不好 |
| DL 需要大算力 | 学特征比直接用人工特征计算量大得多 |
| 预训练有用 | 在大数据上先学好"通用特征"，小数据微调就行 |
| RNN/Transformer 都在做"编码" | 它们本质是"自动特征提取器" |
| 特征工程强的人用 ML 能打 DL | 数据少时，好特征 > 自动学特征 |
| 数据量大时 DL 碾压 ML | 自动学特征的优势发挥，手工设计追不上 |

### 深度学习的神经网络 = 自动特征提取器

你之前学的 RNN 的 h_t、Transformer 的 Self-Attention，本质上都是在"自动提取特征"：
- RNN：h_t 累积 token 信息 → 编码后的特征
- Transformer：Self-Attention 让每个位置融合相关信息 → 编码后的特征

**神经网络把人工设计特征的工作，交给了模型去学。**

## ⚠️ 易错点与常见误解

1. **以为 ML 参数是人选的，DL 参数是数据学的** → ML 参数也是数据学的，差别在特征不在参数
2. **混淆特征和参数** → 特征是输入表示，参数是模型权重，完全不同
3. **以为 DL 是 ML 的"升级版"只是模型更复杂** → 核心区别是特征提取方式，不是模型复杂度
4. **以为特征工程没用** → 数据少时，好的人工特征能碾压 DL；DL 不是万能的
5. **以为 DL 不需要特征** → DL 自己学特征，但人仍要设计"模型结构"（用什么网络、多少层），这也是一种领域知识的体现
