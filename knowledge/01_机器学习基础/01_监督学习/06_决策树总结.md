# 决策树总结

## 一、核心思想

**通过不断问"是/否"问题，把数据一层层分开，直到每个叶子节点的样本尽可能"纯"（同一类）。**

类比：猜动物游戏——"有脊椎吗？→ 是 → 哺乳动物吗？→ 是 → 四条腿吗？→ ..."

## 二、构建过程

```
根节点：所有数据
  ↓ 选最佳特征+切分点（使"不纯度"下降最多）
左子节点（小于切分点）  右子节点（大于等于切分点）
  ↓ 继续递归分裂...
直到：节点纯 / 样本太少 / 深度达到上限
```

## 三、不纯度指标（核心数学）

**"不纯度"衡量一个节点的混乱程度。分裂目标是让不纯度下降最多。**

### 信息熵（Entropy）
```
H(S) = -Σ p_i · log₂(p_i)
```
- p_i = 第 i 类占比
- 全部同一类 → H=0（最纯）
- 均匀分布 → H=log₂(K)（最混乱）

### 基尼系数（Gini）
```
Gini(S) = 1 - Σ p_i²
```
- 计算比熵快（没有 log），效果差不多
- CART 树的默认指标

### 信息增益
```
Gain = H(父节点) - Σ (|S_child|/|S_parent|) · H(子节点)
```
信息增益大 = 分裂效果好。但**偏向取值多的特征**（如"ID 编号"信息增益最大但没意义）。

### 信息增益率（C4.5 的改进）
```
Gain_ratio = Gain / SplitInfo
SplitInfo = -Σ (|S_child|/|S_parent|) · log₂(|S_child|/|S_parent|)
```
除以"分裂信息"惩罚取值多的特征。

## 四、预剪枝 vs 后剪枝

| 方式 | 做法 | 特点 |
|------|------|------|
| 预剪枝 | 建树时限制深度/最小样本数 | 快，可能欠拟合 |
| 后剪枝 | 先建完整树，再回删 | 效果好，计算量大 |

## 五、任务流程

```
加载数据 → 编码类别特征 → 决策树分类器(max_depth=?)
    → fit 训练 → 可视化树结构 → 预测评估
```

## 六、关键超参数

| 参数 | 作用 |
|------|------|
| `max_depth` | 树深度上限，防过拟合 |
| `min_samples_split` | 节点最少样本数，低于不分 |
| `min_samples_leaf` | 叶子最少样本数 |
| `criterion` | `gini`（默认）或 `entropy` |

## 七、优点与局限

| 优点 | 局限 |
|------|------|
| 可解释性强（能看到规则） | 容易过拟合（单棵树） |
| 无需特征标准化 | 不稳定（数据微变树大改） |
| 能处理混合类型特征 | 对线性关系表达差 |
