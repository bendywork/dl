# 朴素贝叶斯总结

## 一、核心思想

**基于贝叶斯定理 + "特征独立"的朴素假设，计算样本属于每个类别的概率，选最大概率的类别。**

## 二、贝叶斯定理（核心数学）

```
P(C|X) = P(X|C) · P(C) / P(X)

P(C|X)：后验概率（看到特征X后，属于类别C的概率）← 我们要算的
P(X|C)：似然（类别C中出现特征X的概率）
P(C)：先验概率（类别C本来就有的概率）
P(X)：证据（特征X出现的概率，对所有类别相同，可忽略）
```

**分类决策**：`argmax_C P(C|X) = argmax_C P(X|C) · P(C)`

## 三、"朴素"在哪

假设**所有特征在给定类别下相互独立**：
```
P(X|C) = P(x₁|C) · P(x₂|C) · ... · P(x_n|C)
```

这显然是简化（现实中特征之间有依赖），但**效果出奇地好**，尤其在文本分类。

## 四、三种常见变体

| | 高斯朴素贝叶斯 | 多项式朴素贝叶斯 | 伯努利朴素贝叶斯 |
|---|---|---|---|
| 特征假设 | 服从高斯分布 | 计数/频率 | 0/1 二值 |
| P(x|C) | 用 μ 和 σ 算概率密度 | 词频占比 | 出现/不出现 |
| 适用 | 连续特征（身高、年龄） | **文本分类**（词频） | 短文本（是否出现） |

## 五、文本分类流程（多项式NB）

```
文本 → Tokenize → CountVectorizer（统计词频）
    → MultinomialNB.fit(word_counts, labels)
        → 训练 = 统计每个类别下每个词的频率
    → 预测 = 算 P(类别|词向量)，选最大概率的
```

## 六、拉普拉斯平滑

**问题**：训练集中某类别从未出现某词 → `P(word|class) = 0` → 连乘后整个概率归零。

**解决**：
```
P(w|C) = (count(w, C) + α) / (total_words(C) + α·|V|)
α=1（默认），|V|=词汇表大小
```
给每个词一个"保底计数"，防止概率为 0。

## 七、优点与局限

| 优点 | 局限 |
|------|------|
| 训练快（只统计频率） | 特征独立假设在现实中很少成立 |
| 小数据效果好 | 对输入数据分布有要求 |
| 天然可解释（看每个词在各类的概率） | 特征多且相关时效果差 |
