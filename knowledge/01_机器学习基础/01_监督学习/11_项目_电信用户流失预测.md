# 项目：电信用户流失预测

## 一、业务问题

预测用户是否会流失（二分类），提前识别高风险用户以便进行客户挽留。

## 二、任务流程

```
数据加载 → 探索性分析(EDA) → 数据清洗 → 特征工程
    → 模型训练(多模型对比) → 评估 → 特征重要性分析
```

## 三、数据处理关键步骤

### 1. 探索性分析
- 查看流失分布（通常不平衡，流失用户 10-20%）
- 分析数值特征与流失的相关性
- 分析类别特征与流失的关系

### 2. 数据清洗
- 处理缺失值：填充或删除
- 处理类别特征：One-Hot / Label Encoding
- 处理不平衡：SMOTE 过采样 / 类别权重（class_weight='balanced'）

### 3. 特征工程
- 衍生特征（如总消费 = 月费 × 在网月数）
- 特征选择（方差过滤 / 相关系数 / 模型系数）

## 四、常用模型

逻辑回归 → 随机森林 → XGBoost → LightGBM 对比，选最优。

## 五、核心评估指标

| 指标 | 重要性 |
|------|--------|
| Recall（召回率） | **最重要**——漏掉流失用户代价大 |
| F1 | 平衡精确率和召回率 |
| AUC-ROC | 模型区分能力综合评估 |

> 流失预测场景：宁可多标记几个"可能流失"，也不要漏掉真正会流失的。

## 六、特征重要性分析

训练完 XGBoost/LightGBM 后，`feature_importances_` 看哪些特征对预测流失贡献最大 → 指导业务策略。
