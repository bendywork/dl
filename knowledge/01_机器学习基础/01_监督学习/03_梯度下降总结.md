# 梯度下降总结

## 一、核心思想

**沿着负梯度方向走，每一步让函数值下降最快，最终走到极小值点。**

类比：蒙眼下山，每一步都朝脚下最陡的方向迈一步。

## 二、数学推导

**更新公式**：`θ_new = θ_old - α · ∇J(θ)`

- `α`：学习率，控制步长
- `∇J(θ)`：损失函数 J 对 θ 的梯度（导数），指向函数上升最快的方向
- 负号让参数朝着损失**下降**最快的方向更新

**停止条件**：
1. 损失变化 < 阈值（如 1e-10）→ 已经收敛
2. 迭代次数达到上限 → 防止死循环

## 三、三种变体

| 类型 | 每步用的数据 | 特点 |
|------|------------|------|
| BGD（批量） | 全量数据 | 最稳定，但慢 |
| SGD（随机） | 1 个样本 | 最快，但震荡大 |
| MBGD（小批量） | N 个样本（如 32） | **折中，最常用** |

## 四、学习率的影响

| α 太大 | α 太小 |
|--------|--------|
| 震荡不收敛，甚至发散 | 收敛太慢，需要很多迭代 |
| loss 曲线剧烈抖动 | loss 曲线平缓但是几乎不动 |

**经验**：从 0.1, 0.01, 0.001 顺序试。

## 五、一维 vs 多维梯度下降

### 一维
```python
x = x - alpha * h(x)   # h(x) 是 f 的导函数
```

### 多维
```python
x1 = x1 - alpha * hx1(x1, x2)   # 偏导数
x2 = x2 - alpha * hx2(x1, x2)
```

**核心**：多维时梯度是偏导数组成的向量，每个参数独立更新。

## 六、思考链路

```
1. 定义损失函数 J(θ)
2. 计算 J 对各参数的偏导 ∇J(θ)
3. 初始化参数（随机或指定）
4. 循环：θ = θ - α·∇J(θ)
5. 直到收敛 → 得到最优 θ
```

**关键认知**：梯度下降不是求解公式，而是逐步逼近——和线性回归的解析解 `θ = (XᵀX)⁻¹Xᵀy` 是两种不同思路。解析解一步到位，梯度下降慢慢逼近。数据大时解析解算不动，梯度下降就是唯一选择。
