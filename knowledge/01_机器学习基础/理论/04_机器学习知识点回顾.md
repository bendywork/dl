# 复习 · 机器学习知识点

## 1. 为什么线性回归引入 Sigmoid 函数？

### 核心问题
线性回归输出范围是 $(-\infty, +\infty)$，而二分类问题需要的是概率 $P(y=1|x) \in [0, 1]$。需要一个函数将线性输出映射到概率空间。

### 推导链路（从对数几率出发）

**第一步：定义几率（Odds）**
$$odds = \frac{p}{1-p}$$
几率表示正例与反例概率的比值，范围 $(0, +\infty)$。

**第二步：取对数几率（Logit 变换）**
$$logit(p) = \ln\frac{p}{1-p}$$
对数几率范围 $(-\infty, +\infty)$，正好与线性回归输出范围一致。

**第三步：令对数几率等于线性组合**
$$\ln\frac{p}{1-p} = w^Tx + b$$

**第四步：反解 p**
$$\frac{p}{1-p} = e^{w^Tx+b}$$
$$p = e^{w^Tx+b}(1-p)$$
$$p = e^{w^Tx+b} - p \cdot e^{w^Tx+b}$$
$$p(1 + e^{w^Tx+b}) = e^{w^Tx+b}$$
$$p = \frac{e^{w^Tx+b}}{1 + e^{w^Tx+b}} = \frac{1}{1 + e^{-(w^Tx+b)}}$$

这就是 **Sigmoid 函数**：$\sigma(z) = \frac{1}{1+e^{-z}}$

### Sigmoid 不是"拍脑袋选的"，而是数学推导的自然结果

从 GLM（广义线性模型）框架看：
- 伯努利分布属于指数族分布
- 指数族分布的**规范链接函数（canonical link）**由分布本身决定
- 伯努利分布的规范链接函数就是 logit link
- logit 的反函数就是 sigmoid
- **Sigmoid 是伯努利分布下"最自然"的映射函数，不是任意选择**

### Sigmoid 的关键数学性质

| 性质 | 公式 | 意义 |
|------|------|------|
| 输出范围 | $(0, 1)$ | 天然可解释为概率 |
| 导数简洁 | $\sigma'(z) = \sigma(z)(1-\sigma(z))$ | 求梯度时计算高效 |
| 对称性 | $\sigma(-z) = 1 - \sigma(z)$ | 正负样本对称 |
| 与对数似然的关系 | 交叉熵损失下梯度与线性回归形式一致 | 优化性质好 |

### 除了 Sigmoid 还能用哪些函数？

| 函数 | 公式 | 对应模型 | 适用场景 |
|------|------|---------|---------|
| **Probit**（标准正态 CDF 的逆） | $p = \Phi(w^Tx+b)$ | Probit 回归 | 潜变量服从正态分布时 |
| **Log-log** | $p = 1 - e^{-e^{w^Tx+b}}$ | Complementary log-log 模型 | 不对称概率、极端事件 |
| **Tanh** | $p = \frac{\tanh(z)+1}{2}$ | — | 需要零中心输出时（隐藏层更常见） |
| **Softmax** | $p_i = \frac{e^{z_i}}{\sum_j e^{z_j}}$ | Softmax 回归 | Sigmoid 的多分类推广 |

### 为什么实践中主要用 Sigmoid 而不是其他？

1. **数学推导自然**：从 logit 出发唯一推导出 sigmoid，不需额外假设
2. **计算友好**：导数 $\sigma(1-\sigma)$ 极其简洁，反向传播高效
3. **概率解释清晰**：输出直接就是 $P(y=1|x)$
4. **与交叉熵损失配合完美**：梯度形式 $\hat{y} - y$ 与线性回归 MSE 梯度形式一致，优化稳定
5. **Probit 对比**：Probit 没有解析解的导数，需要数值计算正态 CDF，实际效果与 Sigmoid 几乎相同但计算更贵

### 一句话总结
> Sigmoid 不是人为挑选的激活函数，而是"线性回归 → 对数几率 → 反解概率"这条推导链路的**必然结果**。它是伯努利分布在 GLM 框架下的规范链接函数的反函数，具有最优的数学性质。

## 2. 从线性回归到分类：一条完整的演变链路

### 第一阶段：线性回归的本质——解决回归问题

**线性回归要解决什么问题？**

给定一组输入特征 $x = (x_1, x_2, ..., x_n)$，预测一个**连续值**输出 $y$。

$$\hat{y} = w_1x_1 + w_2x_2 + \cdots + w_nx_n + b = w^Tx + b$$

核心假设：**输入与输出之间存在线性关系**。

**典型应用场景：**
- 房价预测（面积、地段 → 价格）
- 销量预测（广告投入、季节 → 销售额）
- 温度预测（湿度、气压 → 温度）

**损失函数**：均方误差 MSE
$$L = \frac{1}{N}\sum_{i=1}^{N}(y_i - \hat{y}_i)^2$$

线性回归的输出 $\hat{y} \in (-\infty, +\infty)$，对回归问题来说这恰好合适——房价可以是任意正数，温度可以是负数。

---

### 第二阶段：遇到了分类问题——最朴素的做法

现实中很多问题不是预测一个数值，而是判断**属于哪个类别**：
- 邮件是否是垃圾邮件？
- 肿瘤是否是恶性？
- 客户是否会违约？

**最朴素的想法：直接用线性回归硬做分类。**

设定一个阈值，比如 0.5：
- $\hat{y} \geq 0.5$ → 预测为正类
- $\hat{y} < 0.5$ → 预测为负类

**这个做法有三个致命问题：**

#### 问题一：输出不是概率，无法解释

线性回归输出可以是 $-100$ 或 $500$，这些值不能解释为概率。你说"这封邮件是垃圾邮件的概率是 -50%"，毫无意义。

#### 问题二：离群点会严重破坏决策边界

```
举例：6个样本，特征 x，标签 y ∈ {0, 1}

正常情况（无离群点）：
  x:   1    2    3    4    5    6
  y:   0    0    0    1    1    1
  线性回归拟合：ŷ = 0.24x - 0.14
  阈值0.5处 → x ≈ 2.67，决策边界合理

加入一个极端离群点后：
  x:   1    2    3    4    5    6    15
  y:   0    0    0    1    1    1     1
  线性回归拟合：ŷ = 0.06x + 0.18
  阈值0.5处 → x ≈ 5.33，决策边界被严重拉偏！

  原本 x=3,4 的样本现在都预测为负类，分类错误！
```

**根本原因**：MSE 损失对偏差大的点施加二次惩罚，离群点会"拽走"整条回归线。

#### 问题三：模型假设不匹配

线性回归假设 $y$ 是连续值且误差服从高斯分布。但分类问题 $y \in \{0, 1\}$，服从的是**伯努利分布**，不是高斯分布。用错误的分布假设去建模，在统计上就是错的。

---

### 第三阶段：正确思路——从概率出发重新建模

既然分类标签 $y \in \{0, 1\}$ 服从伯努利分布，我们应该直接用伯努利分布来建模：

$$P(y=1|x) = p, \quad P(y=0|x) = 1-p$$

关键问题变成：**如何让 $p$ 依赖于特征 $x$？**

约束条件：$p$ 必须在 $(0, 1)$ 之间。

如果直接写 $p = w^Tx + b$，$p$ 可能超出 $[0,1]$，回到朴素的错误做法。

**需要找一个映射，把 $w^Tx+b \in (-\infty, +\infty)$ 变换到 $p \in (0, 1)$。**

---

### 第四阶段：几率（Odds）——连接回归与分类的桥梁

统计学中有一个概念叫**几率（Odds）**：

$$Odds = \frac{p}{1-p} = \frac{\text{正例概率}}{\text{反例概率}}$$

几率的含义：
- $Odds = 1$：正反各半（$p=0.5$）
- $Odds = 4$：正例是反例的4倍（$p=0.8$）
- $Odds \to \infty$：几乎确定是正例（$p \to 1$）
- $Odds \to 0$：几乎确定是反例（$p \to 0$）

几率范围是 $(0, +\infty)$，还是正数，不能直接和线性回归的 $(-\infty, +\infty)$ 对应。

**再取一次对数：**

$$\ln(Odds) = \ln\frac{p}{1-p} = \text{logit}(p)$$

对数几率范围 $(-\infty, +\infty)$！**终于和线性回归的输出范围对上了！**

---

### 第五阶段：逻辑回归的诞生

令对数几率等于线性组合：

$$\ln\frac{p}{1-p} = w^Tx + b$$

**这一步的含义**：我们假设"特征对对数几率的贡献是线性的"——这是一个合理的、可解释的假设。

反解 $p$（同知识点1的推导）：

$$p = \frac{1}{1 + e^{-(w^Tx+b)}} = \sigma(w^Tx+b)$$

**逻辑回归 = 线性回归对 logit 空间建模 + Sigmoid 反变换回概率空间。**

| 对比 | 线性回归 | 逻辑回归 |
|------|---------|---------|
| 建模目标 | $E[y|x] = w^Tx+b$ | $P(y=1|x) = \sigma(w^Tx+b)$ |
| 输出含义 | 连续值预测 | 概率 |
| y 的分布假设 | 高斯分布 | 伯努利分布 |
| 损失函数 | MSE | 交叉熵 |
| 输出范围 | $(-\infty, +\infty)$ | $(0, 1)$ |

---

### 第六阶段：为什么不用直接映射而要绕道 logit？

可能有人问：为什么不直接找一个函数把 $(-\infty, +\infty)$ 映射到 $(0,1)$ 就行了？

**因为 logit 变换保证了模型的概率一致性：**

1. **可加性**：对数几率空间中，特征的贡献是可加的（$\ln\frac{p}{1-p} = w_1x_1 + w_2x_2 + b$），这和多因素独立影响概率的直觉一致
2. **极大似然估计有优良性质**：交叉熵损失是凸函数，保证全局最优
3. **统计推断可行**：可以做假设检验、置信区间等
4. **GLM 框架的规范链接**：logit 是伯努利分布的 canonical link，理论最优

如果只是随意选一个 $S$ 形函数映射，这些数学性质无法保证。

---

### 第七阶段：广义线性模型（GLM）——统一的框架

1972 年 Nelder 和 Wedderburn 提出 GLM，统一了线性回归、逻辑回归、泊松回归等：

$$g(E[y|x]) = w^Tx + b$$

其中 $g$ 是链接函数，由 $y$ 的分布决定：

| y 的分布 | 链接函数 $g$ | 反链接函数 | 模型名称 |
|---------|-------------|-----------|---------|
| 高斯分布 | 恒等 $g(\mu)=\mu$ | 恒等 | **线性回归** |
| 伯努利分布 | Logit $g(\mu)=\ln\frac{\mu}{1-\mu}$ | Sigmoid | **逻辑回归** |
| 泊松分布 | Log $g(\mu)=\ln\mu$ | 指数 | **泊松回归** |
| 伽马分布 | 倒数 $g(\mu)=1/\mu$ | 倒数 | **伽马回归** |

**本质**：线性回归是 GLM 在高斯分布下的特例，逻辑回归是 GLM 在伯努利分布下的特例。它们共享"线性组合建模链接函数值"这一核心思想，区别仅在于 $y$ 的分布不同，导致链接函数不同。

---

### 完整演变链路图

```
回归问题（连续值预测）
  │
  ▼
线性回归：ŷ = wᵀx + b
  损失：MSE，分布假设：高斯
  │
  │ 遇到分类问题（离散标签 y∈{0,1}）
  ▼
朴素做法：线性回归 + 阈值硬切
  ❌ 输出不是概率
  ❌ 离群点破坏边界
  ❌ 分布假设错误（高斯 vs 伯努利）
  │
  │ 重新思考：分类标签服从伯努利分布
  ▼
概率建模：P(y=1|x) = p
  约束：p ∈ (0,1)，而 wᵀx+b ∈ (-∞,+∞)
  │
  │ 引入几率 Odds = p/(1-p)
  ▼
Odds ∈ (0, +∞)，仍不能直接等于线性组合
  │
  │ 取对数：logit(p) = ln(p/(1-p))
  ▼
logit(p) ∈ (-∞, +∞)，与线性回归输出一致！
  │
  │ 令 logit(p) = wᵀx + b，反解 p
  ▼
逻辑回归：p = σ(wᵀx+b)
  损失：交叉熵，分布假设：伯努利
  │
  │ 进一步统一
  ▼
广义线性模型 GLM：g(E[y|x]) = wᵀx + b
  分布决定链接函数 → 线性回归/逻辑回归/泊松回归统一框架
```

### 一句话总结
> 线性回归解决的是回归问题，逻辑回归解决的是分类问题。但从线性回归到逻辑回归不是"换个函数"，而是**从高斯分布假设切换到伯努利分布假设，通过 logit 变换重新建立特征与概率之间的线性关系**。这条链路的每一步都有明确的数学动机，不是拍脑袋拼凑。

## 3. 为什么需要损失函数？从 MAE 到 MSE 的递进

### 为什么需要损失函数？

模型预测值 $\hat{y}$ 和真实值 $y$ 之间一定有偏差。**损失函数就是量化这个偏差的标尺。**

没有损失函数 → 模型不知道自己"错得多厉害" → 无法知道往哪个方向调整参数 → 无法学习。

损失函数的三个作用：
1. **衡量好坏**：把"预测准不准"变成一个可计算的数
2. **指引方向**：通过梯度告诉参数该往哪调
3. **优化目标**：训练 = 最小化损失函数，没有它就没有优化目标

---

### 第一阶段：最直观的衡量——绝对误差 MAE

$$L_{MAE} = \frac{1}{N}\sum_{i=1}^{N}|y_i - \hat{y}_i|$$

**直觉**：我差了多少就是多少，不夸大也不缩小。

**MAE 的问题：**

1. **在零点不可导**：$|x|$ 在 $x=0$ 处左导数为 -1，右导数为 1，导数不连续。梯度下降时在零点附近会"抖动"，优化不稳定。

2. **梯度恒定**：无论偏差大小，梯度始终是 $\pm 1$（偏差大和偏差小得到同样的修正力度）。这意味着：
   - 离群点和平常点获得同等对待
   - 收敛速度慢——接近最优时步长不会缩小，容易在最优点附近震荡

3. **不方便数学分析**：绝对值函数不光滑，无法用泰勒展开等工具做理论分析。

---

### 第二阶段：自然改进——平方误差 MSE

$$L_{MSE} = \frac{1}{N}\sum_{i=1}^{N}(y_i - \hat{y}_i)^2$$

**直觉**：误差取平方，大误差惩罚更重。

**MSE 相对 MAE 的改进：**

| 对比项 | MAE | MSE |
|-------|-----|-----|
| 可导性 | 零点不可导 | 处处可导，光滑 |
| 梯度 | 恒定 $\pm 1$ | 与误差成正比 $\propto (y-\hat{y})$ |
| 对大误差的态度 | 线性惩罚 | 二次惩罚，更重 |
| 收敛行为 | 接近最优时仍大步震荡 | 误差小→梯度小→步长自动缩小，自然收敛 |
| 数学分析 | 不便 | 可微、可泰勒展开、有解析解 |

**关键改进：梯度与误差成正比**

$$\frac{\partial L}{\partial \hat{y}} = -2(y - \hat{y})$$

- 误差大 → 梯度大 → 参数修正幅度大（快速逼近）
- 误差小 → 梯度小 → 参数修正幅度小（精细调整）

这就是**自适应步长**，MAE 做不到这一点。

---

### 第三阶段：MSE 为什么不是终点？MSE 的代价

MSE 对大误差施加二次惩罚，这意味着：

**离群点的影响被放大了。**

```
正常样本误差 = 1   → MSE贡献 = 1² = 1
离群样本误差 = 10  → MSE贡献 = 10² = 100

离群点一个顶100个正常点！
```

MAE 下：$10/1 = 10$ 倍影响
MSE 下：$100/1 = 100$ 倍影响

所以：**数据干净 → MSE 更好（收敛快、光滑）；数据有离群点 → MAE 更鲁棒。**

这也是 Huber Loss 出现的原因：

$$L_{Huber} = \begin{cases} \frac{1}{2}(y-\hat{y})^2 & |y-\hat{y}| \leq \delta \\ \delta|y-\hat{y}| - \frac{1}{2}\delta^2 & |y-\hat{y}| > \delta \end{cases}$$

- 小误差区域：等于 MSE（光滑、自适应步长）
- 大误差区域：等于 MAE（线性惩罚，不被离群点主导）
- $\delta$ 控制切换阈值，兼顾两者优势

---

### 第四阶段：MSE 的概率根源——为什么"恰好"是平方？

MSE 不是随便选的，它有深刻的概率论根基。

**假设误差服从高斯分布 $N(0, \sigma^2)$：**

$$P(y|x,w) = \frac{1}{\sqrt{2\pi}\sigma}\exp\left(-\frac{(y-\hat{y})^2}{2\sigma^2}\right)$$

**极大似然估计（MLE）**：找让观测数据出现概率最大的 $w$

$$\max_w \prod_{i=1}^{N} P(y_i|x_i,w)$$

取对数：

$$\max_w \sum_{i=1}^{N} \ln P(y_i|x_i,w) = \max_w \sum_{i=1}^{N} \left[-\frac{(y_i-\hat{y}_i)^2}{2\sigma^2} + \text{常数}\right]$$

等价于：

$$\min_w \sum_{i=1}^{N}(y_i-\hat{y}_i)^2$$

**MSE = 高斯噪声假设下的极大似然估计。平方不是拍脑袋选的，是高斯分布的概率密度函数里自带的。**

同理，MAE 对应的是拉普拉斯分布（双指数分布）假设下的 MLE。

---

### 损失函数选择的完整逻辑链

```
需要量化预测偏差
  │
  ▼
MAE：|y - ŷ|，最直观
  │ 问题：不可导、梯度恒定、收敛慢
  ▼
MSE：(y - ŷ)²，处处可导、自适应步长
  │ 问题：离群点影响被放大
  ▼
Huber Loss：小误差用MSE，大误差用MAE，兼顾两者
  │
  │ 更深一层：MSE 的概率根源
  ▼
MSE = 高斯噪声假设下的 MLE
MAE = 拉普拉斯噪声假设下的 MLE
交叉熵 = 伯努利/分类分布下的 MLE
  │
  ▼
结论：损失函数的选择本质上是**对数据噪声分布的假设**
  你假设噪声服从什么分布 → MLE 推导出什么损失函数
```

### 一句话总结
> 损失函数是模型学习的"指挥棒"，没有它模型无法优化。从 MAE 到 MSE 的递进是"不可导 → 可导 + 自适应步长"的改进，而 MSE 用平方不是随意选择，是高斯噪声假设下极大似然估计的必然结果。损失函数的选择本质是对数据噪声分布的假设。

## 4. 损失函数的概率根源：从噪声假设到 MLE 推导

### 核心思想

**损失函数不是人为设计的惩罚规则，而是对数据噪声分布做假设后，极大似然估计（MLE）推导出的必然结果。**

通用推导框架：
```
假设噪声服从某分布 → 写出似然函数 → 取对数 → 去掉与参数无关的项 → 得到损失函数
```

---

### 一、MSE = 高斯噪声假设下的 MLE

#### 场景建模

假设真实关系为 $y = w^Tx + b + \epsilon$，其中 $\epsilon$ 是噪声。

**关键假设：$\epsilon \sim N(0, \sigma^2)$（高斯分布）**

这意味着给定 $x$ 和参数 $w$，$y$ 的分布为：

$$y|x,w \sim N(w^Tx + b, \sigma^2)$$

#### MLE 推导

**第一步：写出单个样本的似然**

高斯分布的概率密度函数：

$$P(y_i|x_i,w) = \frac{1}{\sqrt{2\pi}\sigma}\exp\left(-\frac{(y_i - \hat{y}_i)^2}{2\sigma^2}\right)$$

其中 $\hat{y}_i = w^Tx_i + b$。

**第二步：写出全部样本的联合似然**

样本独立，联合似然 = 各样本似然之积：

$$L(w) = \prod_{i=1}^{N} P(y_i|x_i,w) = \prod_{i=1}^{N} \frac{1}{\sqrt{2\pi}\sigma}\exp\left(-\frac{(y_i - \hat{y}_i)^2}{2\sigma^2}\right)$$

**第三步：取对数似然**

$$\ln L(w) = \sum_{i=1}^{N}\left[-\frac{(y_i-\hat{y}_i)^2}{2\sigma^2} - \ln(\sqrt{2\pi}\sigma)\right]$$

**第四步：极大化对数似然 ⟺ 极小化负对数似然**

去掉与 $w$ 无关的常数项 $-\ln(\sqrt{2\pi}\sigma)$：

$$\max_w \ln L(w) \iff \min_w \sum_{i=1}^{N}\frac{(y_i-\hat{y}_i)^2}{2\sigma^2} \iff \min_w \sum_{i=1}^{N}(y_i-\hat{y}_i)^2$$

**结果：MSE。**

#### 物理直觉

高斯分布的特点：
- 小误差出现概率高（概率密度集中在均值附近）
- 大误差出现概率指数衰减
- $(y-\hat{y})^2$ 恰好是高斯密度函数中指数部分的负值

**MSE 惩罚大误差 → 高斯分布天然认为大误差"不太可能出现" → 遇到大误差就要大力修正。**

#### 在深度学习中的应用

| 应用 | 说明 |
|------|------|
| 回归任务 | 房价预测、温度预测、销量预测等连续值输出 |
| 神经网络输出层 | 线性输出（无激活），配合 MSE 损失 |
| 自编码器重建 | 输入与重建输出之间的 MSE |
| 扩散模型噪声预测 | 预测添加的高斯噪声，MSE 衡量预测精度 |

---

### 二、MAE = 拉普拉斯噪声假设下的 MLE

#### 场景建模

同样 $y = w^Tx + b + \epsilon$，但这次**假设 $\epsilon \sim \text{Laplace}(0, b)$（拉普拉斯分布）**

拉普拉斯分布概率密度：

$$P(\epsilon) = \frac{1}{2b}\exp\left(-\frac{|\epsilon|}{b}\right)$$

形状特点：比高斯分布更"尖"，尾部更厚。

$$y|x,w \sim \text{Laplace}(w^Tx + b', b)$$

#### MLE 推导

**第一步：写出似然**

$$P(y_i|x_i,w) = \frac{1}{2b}\exp\left(-\frac{|y_i - \hat{y}_i|}{b}\right)$$

**第二步：取对数似然**

$$\ln L(w) = \sum_{i=1}^{N}\left[-\frac{|y_i-\hat{y}_i|}{b} - \ln(2b)\right]$$

**第三步：去掉常数，取负**

$$\max_w \ln L(w) \iff \min_w \sum_{i=1}^{N}|y_i-\hat{y}_i|$$

**结果：MAE。**

#### 高斯 vs 拉普拉斯——为什么噪声分布的选择决定了损失函数

```
高斯分布：P(ε) ∝ exp(-ε²/2σ²)  →  对数似然含 ε²  →  MSE
拉普拉斯分布：P(ε) ∝ exp(-|ε|/b)  →  对数似然含 |ε|  →  MAE
```

**分布的指数部分决定了损失函数的形式。**

#### 拉普拉斯分布的尾部特性——为什么 MAE 对离群点更鲁棒

```
高斯尾部：P(|ε|>t) ∝ exp(-t²/2σ²)    → 衰减极快，大误差"几乎不可能"
拉普拉斯尾部：P(|ε|>t) ∝ exp(-t/b)   → 衰减较慢，大误差"仍有一定概率"

含义：
高斯假设下 → 大误差不应该出现 → 出现了就要狠狠惩罚（二次）
拉普拉斯假设下 → 大误差也有可能 → 不需要特别重罚（线性）
```

**MAE 对离群点更鲁棒的本质原因：拉普拉斯分布允许大误差存在，不像高斯那样"震惊"。**

#### 在深度学习中的应用

| 应用 | 说明 |
|------|------|
| 鲁棒回归 | 数据含离群点时，MAE 比 MSE 稳定 |
| 图像超分辨率 | L1 Loss 比 L2 Loss 产生的图像更清晰、少模糊 |
| GAN 的判别器 | LSGAN 用 MSE 替代，WGAN-GP 某些变体用 MAE |
| 中位数回归 | MAE 回归预测的是条件中位数，MSE 回归预测的是条件均值 |

---

### 三、交叉熵 = 伯努利/分类分布下的 MLE

#### 场景建模

分类问题，$y \in \{0, 1\}$（二分类）或 $y \in \{1, 2, ..., K\}$（多分类）。

**关键假设：$y$ 服从伯努利分布（二分类）或分类分布（多分类）**

#### 二分类：伯努利分布 → 二元交叉熵（BCE）

**第一步：写出似然**

伯努利分布：

$$P(y_i|x_i,w) = p_i^{y_i}(1-p_i)^{1-y_i}$$

其中 $p_i = \sigma(w^Tx_i+b)$ 是模型预测的 $P(y=1|x)$。

- $y_i=1$ 时：$P = p_i$（预测对正类的概率）
- $y_i=0$ 时：$P = 1-p_i$（预测对负类的概率）

**第二步：取对数似然**

$$\ln L(w) = \sum_{i=1}^{N}[y_i\ln p_i + (1-y_i)\ln(1-p_i)]$$

**第三步：取负**

$$L_{BCE} = -\sum_{i=1}^{N}[y_i\ln p_i + (1-y_i)\ln(1-p_i)]$$

**结果：二元交叉熵。**

#### 多分类：分类分布（Categorical）→ 多类交叉熵

**第一步：写出似然**

分类分布：

$$P(y_i|x_i,w) = \prod_{k=1}^{K} p_{ik}^{[y_i=k]}$$

其中 $p_{ik} = \text{softmax}(z_i)_k$，$[y_i=k]$ 是指示函数。

**第二步：取对数似然**

$$\ln L(w) = \sum_{i=1}^{N}\sum_{k=1}^{K}[y_i=k]\ln p_{ik} = \sum_{i=1}^{N}\ln p_{i,y_i}$$

**第三步：取负**

$$L_{CE} = -\sum_{i=1}^{N}\ln p_{i,y_i}$$

**结果：多类交叉熵。**

#### 为什么分类必须用交叉熵而不能用 MSE？

**原因一：概率空间的 MSE 不是 MLE 推导出来的**

如果对分类问题用 MSE：

$$L_{MSE} = \sum_{i}(y_i - p_i)^2$$

这里 $y_i \in \{0,1\}$，$p_i \in (0,1)$，形式上可以算，但它不对应任何合理的噪声分布假设，不是 MLE 的结果。

**原因二：梯度消失问题**

MSE 对 $p$ 的梯度：

$$\frac{\partial}{\partial z}\left[(y-\sigma(z))^2\right] = -2(y-\sigma(z))\cdot\sigma(z)(1-\sigma(z))$$

当 $\sigma(z)$ 接近 0 或 1 时，$\sigma(1-\sigma) \to 0$，**梯度消失**——即使预测完全错误（$y=1, \sigma(z)\approx 0$），梯度也接近零，模型学不动。

交叉熵对 $z$ 的梯度：

$$\frac{\partial}{\partial z}[-y\ln\sigma(z)-(1-y)\ln(1-\sigma(z))] = \sigma(z) - y$$

**没有 $\sigma(1-\sigma)$ 项！** 预测错就有一个正比于误差的梯度，永远不会消失。

```
MSE梯度：  -2(y-σ)·σ(1-σ)    → 预测极端错误时 σ(1-σ)≈0，梯度消失 ❌
BCE梯度：  σ - y              → 预测极端错误时 σ-y 很大，梯度强劲 ✅
```

**原因三：交叉熵是凸函数，MSE + Sigmoid 不是**

BCE 损失对 $w$ 是凸的，保证全局最优；MSE + Sigmoid 组合是非凸的，可能陷入局部最优。

#### 在深度学习中的应用

| 应用 | 损失函数 | 输出层 |
|------|---------|--------|
| 二分类（垃圾邮件检测） | BCE | Sigmoid |
| 多分类（ImageNet 1000类） | CrossEntropy | Softmax |
| 多标签（一篇文档多个标签） | BCE per label | Sigmoid per label |
| 语言模型（GPT） | CrossEntropy over vocabulary | Linear → Softmax |

### 四、Huber Loss——高斯与拉普拉斯的融合

#### 动机

- MSE：光滑、自适应步长，但离群点影响太大
- MAE：鲁棒，但零点不可导、收敛慢

**能不能兼得？**

#### 定义

$$L_{\delta}(r) = \begin{cases} \frac{1}{2}r^2 & |r| \leq \delta \\ \delta|r| - \frac{1}{2}\delta^2 & |r| > \delta \end{cases}$$

其中 $r = y - \hat{y}$，$\delta$ 是阈值超参数。

#### 几何直觉

```
损失值
  │        /  MAE（直线）
  │       /
  │      / Huber（|r|>δ 段，与MAE平行但下移δ²/2）
  │     /
  │    ·  ← δ处衔接
  │   ╱
  │  ╱  Huber（|r|≤δ 段 = MSE，抛物线）
  │ ╱
  │╱
  └──────────────→ |r|
  0    δ
```

- $|r| \leq \delta$：二次函数（和 MSE 一样光滑、自适应梯度）
- $|r| > \delta$：线性函数（和 MAE 一样对大误差线性惩罚，不被离群点主导）
- 在 $|r|=\delta$ 处**值和一阶导数都连续**（光滑拼接）

#### 梯度特性

$$\frac{\partial L_{\delta}}{\partial r} = \begin{cases} r & |r| \leq \delta \\ \delta \cdot \text{sign}(r) & |r| > \delta \end{cases}$$

- 小误差：梯度 $=r$（与误差成正比，自适应）
- 大误差：梯度 $=\delta$（截断，离群点最多施加 $\delta$ 的修正力度，不会被拽走）

#### 与概率分布的关系

Huber Loss 对应的噪声分布是**高斯与拉普拉斯的混合**：
- 中心区域（$|r| \leq \delta$）服从高斯分布
- 尾部区域（$|r| > \delta$）服从拉普拉斯分布

这等价于假设：大部分数据噪声较小（高斯），但偶尔出现较大的离群噪声（拉普拉斯厚尾）。

#### $\delta$ 的选择

| $\delta$ | 行为 |
|----------|------|
| $\delta \to \infty$ | 退化为 MSE |
| $\delta \to 0$ | 退化为 MAE |
| 实践中 | 通常取 $\delta = 1.0$ 或通过交叉验证调优 |

#### 在深度学习中的应用

| 应用 | 说明 |
|------|------|
| 目标检测边界框回归 | Faster R-CNN 系列用 Smooth L1（即 $\delta=1$ 的 Huber） |
| 鲁棒回归 | 替代 MSE，对标注噪声更鲁棒 |
| 强化学习 | 某些算法中对价值函数的回归使用 Huber |
| 机器人控制 | 传感器数据含离群值时的连续控制回归 |

---

### 四大损失函数的统一视角

| 损失函数 | 噪声分布假设 | 分布特点 | MLE推导结果 | 对大误差态度 |
|---------|------------|---------|------------|------------|
| **MSE** | 高斯 $N(0,\sigma^2)$ | 尾部衰减快 $e^{-r^2}$ | $\sum r^2$ | 重惩罚（二次） |
| **MAE** | 拉普拉斯 $L(0,b)$ | 尾部衰减慢 $e^{-|r|}$ | $\sum |r|$ | 轻惩罚（线性） |
| **交叉熵** | 伯努利/分类 | 离散分布 | $-\sum y\ln p$ | 概率空间无离群点概念 |
| **Huber** | 高斯中心+拉普拉斯尾 | 混合 | $r \leq \delta: \frac{r^2}{2}$; $r > \delta: \delta|r|-\frac{\delta^2}{2}$ | 截断惩罚 |

**底层逻辑**：
```
你对数据的噪声怎么理解 → 假设什么分布 → MLE 推导 → 得到什么损失函数

噪声主要小、偶尔大 → 高斯 → MSE
噪声经常大、离群多 → 拉普拉斯 → MAE
噪声中心小、尾部厚 → 混合 → Huber
标签是离散类别 → 伯努利/分类 → 交叉熵
```

### 一句话总结
> 损失函数不是人设计的，而是噪声分布假设 + MLE 推导的产物。MSE 对应高斯、MAE 对应拉普拉斯、交叉熵对应伯努利/分类分布、Huber 对应混合分布。选择损失函数的本质是选择你对数据噪声的假设。

## 5. 二分类与多分类：损失函数的选择与分析

### 一、二分类的完整图景

#### 1.1 二分类问题定义

输入特征 $x$，输出标签 $y \in \{0, 1\}$（或 $\{-1, +1\}$）。

- $y=1$：正类（患病、垃圾邮件、违约）
- $y=0$：负类（健康、正常邮件、守信）

模型需要输出：$P(y=1|x) \in (0,1)$

#### 1.2 二分类损失函数族

##### （1）二元交叉熵 BCE——最主流

$$L_{BCE} = -[y\ln p + (1-y)\ln(1-p)]$$

展开看每个样本的损失：

| 真实标签 | 预测 $p$ | 损失 | 含义 |
|---------|---------|------|------|
| $y=1$ | $p=0.99$ | $-\ln(0.99) \approx 0.01$ | 预测对，损失小 |
| $y=1$ | $p=0.01$ | $-\ln(0.01) \approx 4.6$ | 预测错，损失大 |
| $y=1$ | $p=0.001$ | $-\ln(0.001) \approx 6.9$ | 预测严重错，损失很大 |
| $y=0$ | $p=0.01$ | $-\ln(0.99) \approx 0.01$ | 预测对，损失小 |
| $y=0$ | $p=0.99$ | $-\ln(0.01) \approx 4.6$ | 预测错，损失大 |

**核心特性：对自信的错误预测施加无限增长的惩罚。**

$$y=1, p \to 0: L = -\ln(p) \to +\infty$$
$$y=0, p \to 1: L = -\ln(1-p) \to +\infty$$

模型越自信地犯错，惩罚越重——这迫使模型"不确定的时候就别装确定"。

##### （2）Hinge Loss——SVM 的选择

$$L_{Hinge} = \max(0, 1 - y \cdot f(x))$$

其中 $y \in \{-1, +1\}$，$f(x)$ 是原始输出（不经过 Sigmoid）。

| 预测 $f(x)$ | 标签 $y$ | $y \cdot f(x)$ | 损失 | 状态 |
|------------|---------|---------------|------|------|
| 2.0 | +1 | 2.0 | 0 | 正确且超出边界，无损失 |
| 0.5 | +1 | 0.5 | 0.5 | 在间隔内，有损失 |
| -1.0 | +1 | -1.0 | 2.0 | 预测反了，大损失 |

**Hinge Loss 的特点**：
- 只要分类正确且置信度超过间隔（$yf(x) \geq 1$），损失就为 0
- 不要求概率输出，只要求"分得够开"
- 产出的模型是稀疏的（只有支持向量起作用）

##### （3）Focal Loss——解决类别不平衡

$$L_{Focal} = -\alpha_t(1-p_t)^\gamma \ln(p_t)$$

其中 $p_t = p$（当$y=1$）或 $1-p$（当$y=0$），$\gamma \geq 0$ 是聚焦参数。

**与 BCE 的区别**：加了 $(1-p_t)^\gamma$ 这个调制因子。

| 预测 $p_t$ | BCE损失 | Focal损失($\gamma=2$) | 倍数 |
|-----------|---------|----------------------|------|
| 0.9（易分类） | 0.105 | $0.1^2 \times 0.105 = 0.00105$ | 1/100 |
| 0.5（不确定） | 0.693 | $0.5^2 \times 0.693 = 0.173$ | 1/4 |
| 0.1（难分类） | 2.302 | $0.9^2 \times 2.302 = 1.865$ | ~1/1.2 |

**Focal Loss 做了什么**：
- $\gamma=0$：退化为 BCE
- $\gamma>0$：自动压制"容易分类的样本"的损失，让模型聚焦于"难分类的样本"
- 典型场景：目标检测中背景样本占 99%，正样本占 1%，BCE 被海量易分类的负样本主导，Focal Loss 让模型关注那 1% 的难样本

##### （4）为什么不用 MSE 做二分类？（回顾+深入）

MSE 用于分类的三个硬伤：

**硬伤1：梯度消失**

$$\frac{\partial L_{MSE}}{\partial z} = -2(y - \sigma(z)) \cdot \sigma(z)(1-\sigma(z))$$

当模型自信但错误时（如 $y=1, \sigma(z)=0.01$）：
- $(y-\sigma) = 0.99$（误差大）
- $\sigma(1-\sigma) = 0.01 \times 0.99 \approx 0.01$（Sigmoid饱和）
- 梯度 $\approx 0.02$（极小，几乎不学习！）

BCE 的梯度：$\sigma(z) - y = 0.01 - 1 = -0.99$（梯度强劲，快速修正）

**硬伤2：非凸**

MSE + Sigmoid 的损失曲面有多个局部极小值，优化可能卡住。

BCE + Sigmoid 的损失曲面是凸的，保证全局最优。

**硬伤3：概率含义错位**

MSE 衡量的是"距离"，但概率空间中 0.1 和 0.2 的距离 ≠ 0.8 和 0.9 的距离。概率从 0.01 到 0.02（2倍变化）比从 0.50 到 0.51（几乎没变）的信息量差异大得多。交叉熵通过 $\ln$ 自然地捕捉了这种对数尺度的差异。

### 二、多分类的完整图景

#### 2.1 多分类问题定义

输入特征 $x$，输出标签 $y \in \{1, 2, ..., K\}$，$K \geq 3$。

模型需要输出：$[p_1, p_2, ..., p_K]$，满足 $\sum_{k=1}^{K}p_k = 1$，$p_k \geq 0$。

#### 2.2 从 Sigmoid 到 Softmax——二分类到多分类的推广

**二分类**：1个 Sigmoid 输出 $p$，另一个类概率 $= 1-p$

**多分类**：$K$ 个原始输出 $z_1, z_2, ..., z_K$，通过 Softmax 归一化：

$$p_k = \frac{e^{z_k}}{\sum_{j=1}^{K}e^{z_j}}$$

**Softmax 与 Sigmoid 的关系**：

当 $K=2$ 时：

$$p_1 = \frac{e^{z_1}}{e^{z_1}+e^{z_2}} = \frac{1}{1+e^{z_2-z_1}} = \sigma(z_1 - z_2)$$

**Sigmoid 是 Softmax 在 K=2 时的特例。**

#### 2.3 多分类交叉熵

$$L_{CE} = -\sum_{k=1}^{K}[y=k]\ln p_k = -\ln p_{y}$$

每个样本只有真实类别那一项贡献损失，其他类别 $[y=k]=0$。

**直觉**：模型给真实类别分配的概率越高，损失越小。

| 真实类别 | 模型给真实类别的概率 | 损失 |
|---------|-------------------|------|
| 猫 | 0.9 | $-\ln 0.9 = 0.105$ |
| 猫 | 0.5 | $-\ln 0.5 = 0.693$ |
| 猫 | 0.01 | $-\ln 0.01 = 4.605$ |
| 猫 | 0.001 | $-\ln 0.001 = 6.908$ |

**Softmax + CrossEntropy 的梯度推导**（非常优美）：

$$\frac{\partial L}{\partial z_k} = p_k - [y=k]$$

- 对真实类别 $k=y$：梯度 $= p_y - 1$（概率不够1就要增大）
- 对非真实类别 $k \neq y$：梯度 $= p_k$（不该有的概率就要减小）
- 所有梯度之和 $= \sum p_k - 1 = 0$（梯度守恒）

**这与 BCE 的梯度 $\sigma(z)-y$ 形式完全一致，是统一的。**

#### 2.4 多分类的特殊变体

##### （1）Label Smoothing——防止过度自信

标准交叉熵鼓励模型给真实类别 $p=1$，这会导致过度自信、泛化差。

Label Smoothing 将硬标签 $[0, 0, 1, 0]$ 变成软标签：

$$y_k^{smooth} = \begin{cases} 1 - \epsilon + \frac{\epsilon}{K} & k = y \\ \frac{\epsilon}{K} & k \neq y \end{cases}$$

例如 $K=4, \epsilon=0.1$，真实类别为3：
- 原始：$[0, 0, 1, 0]$
- 平滑：$[0.025, 0.025, 0.925, 0.025]$

**效果**：模型不再被推向 $p=1$ 的极端，泛化性更好。BERT、GPT、ViT 等大模型训练几乎都用了 Label Smoothing。

##### （2）Focal Loss 多分类版

$$L = -\alpha_y(1-p_y)^\gamma \ln p_y$$

与二分类版同理，压制易分类样本、聚焦难样本。

##### （3）多标签分类——不是互斥的多分类

场景：一张图可能同时包含"猫"+"草地"+"晴天"，标签不互斥。

**做法**：每个标签独立做二分类，$K$ 个 Sigmoid + $K$ 个 BCE。

$$L = -\sum_{k=1}^{K}[y_k\ln\sigma(z_k) + (1-y_k)\ln(1-\sigma(z_k))]$$

**注意**：这里不能用 Softmax！Softmax 假设类别互斥（概率和=1），多标签场景类别不互斥。

#### 2.5 互斥 vs 不互斥——损失函数选择的分水岭

| 场景 | 类别关系 | 输出层 | 损失函数 | 例子 |
|------|---------|--------|---------|------|
| 单标签多分类 | **互斥**（只能属于一个） | Softmax | CrossEntropy | 手写数字识别、ImageNet |
| 多标签分类 | **不互斥**（可属于多个） | K个Sigmoid | K个BCE | 文档标签、医学多病种 |
| 二分类 | 互斥（2类） | 1个Sigmoid | BCE | 垃圾邮件检测 |

**选错的后果**：
- 多标签用 Softmax → 概率和强制为1，多个标签共存时互相抢概率，学不好
- 单标签用 Sigmoid → 各类概率独立，不保证和为1，可能出现"同时属于猫和狗概率都很高"的矛盾输出

### 三、二分类 vs 多分类损失函数选择决策树

```
分类任务
  │
  ├── 标签是连续值概率？→ BCE/KL散度（知识蒸馏场景）
  │
  ├── 二分类？
  │     ├── 类别平衡 → BCE
  │     ├── 类别严重不平衡 → Focal Loss 或 加权BCE
  │     └── 需要最大间隔 → Hinge Loss (SVM风格)
  │
  ├── 多分类（类别互斥）？
  │     ├── 标准场景 → Softmax + CrossEntropy
  │     ├── 防过拟合/过度自信 → + Label Smoothing
  │     ├── 类别不平衡 → Focal Loss 多分类版
  │     └── 类别数极多（如词汇表10万）→ Sampled Softmax
  │
  └── 多标签（类别不互斥）？
        └── K个Sigmoid + K个BCE
```

### 四、类别不平衡问题的完整应对

这是二分类和多分类都面临的实际问题，损失函数的选择直接影响效果。

#### 问题本质

```
正样本100个，负样本9900个
BCE下：9900个负样本的损失主导梯度 → 模型偏向预测"全部负类"
准确率99%但正类一个都找不出来 → 模型没学到有用的东西
```

#### 应对方案对比

| 方案 | 做法 | 优点 | 缺点 |
|------|------|------|------|
| **加权BCE** | $L = -[\alpha y\ln p + \beta(1-y)\ln(1-p)]$，$\alpha:\beta = $ 负:正样本比 | 简单有效 | 权重需要调 |
| **Focal Loss** | 自动降权易分类样本 | 不需要手动设权重 | $\gamma$ 需要调 |
| **过采样** | 复制少数类样本 | 简单 | 可能过拟合 |
| **欠采样** | 丢弃多数类样本 | 快 | 丢信息 |
| **SMOTE** | 合成少数类样本 | 较平衡 | 生成数据可能不真实 |

加权BCE 的权重计算经验法则：

$$\alpha_{pos} = \frac{N_{total}}{2 \cdot N_{pos}}, \quad \alpha_{neg} = \frac{N_{total}}{2 \cdot N_{neg}}$$

### 一句话总结
> 二分类用 BCE，多分类互斥用 Softmax+CrossEntropy，多标签不互斥用 K个Sigmoid+K个BCE——选择的核心依据是标签的分布假设（伯努利 vs 分类分布）和类别间的关系（互斥 vs 不互斥）。类别不平衡时用加权BCE或Focal Loss，防止过度自信用Label Smoothing。
