# SVM（支持向量机）总结

## 一、核心思想

**找一条"最宽"的分割线（超平面），不仅把两类分开，而且让两边的"缓冲带"尽可能宽。离分割线最近的几个样本点叫"支持向量"，它们决定了分割线的位置。**

## 二、从感知机到 SVM

### 感知机
找一条线把两类分开就行——不限位置，有无数条。

### SVM
不仅分开，还要**最大化分类间隔（margin）**——只有一条最优的。

```
支持向量的作用：决定了超平面位置，其他样本对模型没有影响。
删除非支持向量的数据 → 模型不变。
```

## 三、硬间隔 vs 软间隔

### 硬间隔
要求所有样本必须正确分类且在间隔外 → 对异常值敏感，线性不可分时不可用。

### 软间隔（常用）
允许少量点"犯错"（越界），引入**松弛变量 ξ**：
- ξ=0：正确分类且在间隔外
- 0<ξ<1：正确分类但在间隔内
- ξ>1：分类错误

**惩罚参数 C**：失衡学习器复杂度与误差的关系
- C 大 → 不允许犯错 → 间隔窄，易过拟合
- C 小 → 容忍错误 → 间隔宽，易欠拟合

## 四、核函数（处理非线性问题）

**核心 idea**：低维空间中线性不可分的数据，映射到高维空间后可能线性可分。

```
核函数 K(x, z) = φ(x)·φ(z)  ← 在高维做内积，但不显式计算 φ

常用核：
- 线性核：K(x,z) = x·z          ← 线性可分时用
- 多项式核：K(x,z) = (x·z + c)^d
- RBF核：K(x,z) = exp(-γ||x-z||²)  ← 最常用，γ控制影响范围
```

**γ（gamma）的影响**：
- γ 大 → 每个支持向量影响范围小 → 决策边界复杂 → 易过拟合
- γ 小 → 影响范围大 → 边界平滑 → 易欠拟合

## 五、调参口诀

| 参数 | 影响 |
|------|------|
| C 大 | 偏精确分类，可能过拟合 |
| C 小 | 偏宽间隔，可能欠拟合 |
| γ 大 | 复杂边界，可能过拟合 |
| γ 小 | 平滑边界，可能欠拟合 |

## 六、任务流程

```
加载数据 → 标准化（SVM 对尺度敏感！）
    → SVM(kernel='rbf', C=1, gamma='scale')
    → fit 训练 → predict 预测 → 评估
```

**SVM 必须先标准化**：尺度不同会扭曲距离，RBF 核完全失效。

## 七、多分类

SVM 原生的二分类器。多分类用一对多（OvR）或一对一（OvO）策略组合多个二分类 SVM。
