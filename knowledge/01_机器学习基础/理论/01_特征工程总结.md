# 特征工程总结

## 一、标准化与归一化

### 核心问题
不同特征的量纲不同（如身高 cm vs 体重 kg），直接建模会导致量纲大的特征主导梯度更新。需要统一尺度。

### 归一化（MinMaxScaler）

**公式**：`X' = (X - X_min) / (X_max - X_min)`

- 将数据映射到 [0, 1]（或指定区间）
- **依赖最大值最小值，对异常值敏感**
- 适用场景：数据边界已知、无极端异常值

**思考链路**：先 fit（计算 min/max）→ transform（缩放）。必须用训练集的 min/max 去 transform 测试集，防止数据泄露。

### 标准化（StandardScaler）

**公式**：`X' = (X - μ) / σ`

- 将数据变成均值为 0、方差为 1 的分布
- **对异常值不敏感**（相比归一化）
- 适用场景：大多数 ML 模型（SVM、逻辑回归、神经网络等）

**思考链路**：fit 计算 μ 和 σ → transform 时 `(x - μ) / σ`。结果服从标准正态分布。

### 对比

| | 归一化 | 标准化 |
|---|---|---|
| 公式 | `(x-min)/(max-min)` | `(x-μ)/σ` |
| 结果范围 | [0, 1] | 均值 0，方差 1 |
| 异常值影响 | 大 | 小 |
| 适用 | 数据有明确边界 | 通用 |

## 二、特征选择

### 意义
从 N 个特征中选出 K 个最有用的，降维 + 去噪 + 减少过拟合。

### Filter（过滤法）
- **方差选择**：低方差的特征（几乎所有样本取值一样）几乎没有信息量，直接删除
- **相关系数法**：算每个特征与标签的相关系数（F 检验），选相关性最强的 K 个
- **卡方检验**：衡量特征与标签的独立性，值越大→越相关。**要求特征非负**

### Wrapper（包裹法）- RFE
用模型（如逻辑回归）反复训练，每轮删除权重最小的特征，直到剩下 K 个。计算量大但效果好。

### Embedded（嵌入法）
训练过程中自动做特征选择：
- **L1 正则化**：产生稀疏权重，不重要特征权重直接为 0
- **基于模型系数**：`SelectFromModel` 设置阈值，删掉系数绝对值低于阈值的特征

## 三、PCA 降维

### 核心思想
将高维数据投影到方差最大的方向（主成分），用少数主成分代替原始特征，**保留最大信息量的同时降维**。

### 数学本质
1. 计算协方差矩阵（表示特征之间的线性相关关系）
2. 求协方差矩阵的特征值和特征向量
3. 取最大的 K 个特征值对应的特征向量组成投影矩阵
4. 原数据 × 投影矩阵 = 降维后的数据

**特征值越大 = 该方向的方差越大 = 信息量越多。** PCA 本质上是在"保留方差最大的投影方向"。

### 参数
- `n_components`：保留的主成分个数 / 保留的信息比例（如 0.9 = 保留 90% 方差）
- `whiten`：是否对降维后的特征做标准化（使各维度独立 + 方差为 1）

## 四、TF-IDF（文本特征提取）

### 任务流程
```
文本列表 → CountVectorizer(词袋法) → TF 矩阵(词频)
                                  → TfidfTransformer → TF-IDF 矩阵
或一步到位: TfidfVectorizer
```

### TF-IDF 公式
```
TF-IDF(w) = TF(w) × IDF(w)

TF(w)  = 词 w 在文档中出现次数 / 文档总词数        （局部权重）
IDF(w) = log(总文档数 / 包含词 w 的文档数 + 1)      （全局稀有度）
```

### 直觉
- 一个词在本文档出现越多 → TF 越大 → 越重要
- 一个词在所有文档都出现 → IDF 越小 → 越不重要（如"的""是"）
- **TF-IDF = 既常见于本文档，又在全局稀有 → 该文档的关键词**

## 五、二值化与哑编码

**二值化**：设定阈值，大于阈值=1，小于阈值=0（将连续值转离散）

**哑编码（One-Hot Encoding）**：把类别属性变成 N 位 01 向量。如颜色 [红,蓝,绿] → 红=[1,0,0]，蓝=[0,1,0]，绿=[0,0,1]。
