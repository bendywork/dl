# NLP 分词操作总结

## 一、核心认知

**分词 = 把连续文本切成有意义的词语单元，是中文 NLP 的第一步（英文天然空格分隔，无需此步）。**

"我今天吃了苹果" → ["我", "今天", "吃", "了", "苹果"]

## 二、分词工具对比

| 工具 | 特点 | 适用 |
|------|------|------|
| **jieba** | 轻量、快、中文默认选择 | 通用中文分词 |
| **HanLP** | 功能全（分词+词性+NER+依存分析） | 学术/企业级应用 |

### jieba 三种模式

| 模式 | 特点 | 例子 |
|------|------|------|
| 精确模式 | 最准确，适合文本分析 | "我/今天/吃/苹果" |
| 全模式 | 所有可能词都切出来，有冗余 | "我/今天/今天吃/吃/苹果" |
| 搜索引擎模式 | 在精确模式上再切长词 | "我/今天/今天/吃/苹果" |

### jieba 核心功能
- **分词**：`jieba.cut(text)`
- **添加自定义词**：`jieba.add_word("新词")` — 专业术语/新词
- **词性标注**：`jieba.posseg.cut(text)` → (词, 词性)
- **关键词提取**：基于 TF-IDF 或 TextRank

## 三、Gensim 操作

Gensim 是 NLP 工具库，核心功能是**训练和使用词向量**。

### 核心功能链

```
分词后的文本 → 构建词典(corpora.Dictionary) → 转BOW向量(doc2bow)
    → 训练模型(Word2Vec / LDA / TF-IDF)
    → 相似度查询 / 主题分析 / 向量运算
```

### Word2Vec 训练
```python
model = Word2Vec(sentences, vector_size=100, window=5, min_count=1)
model.wv.most_similar('苹果')     # 找相似词
model.wv['苹果']                  # 取词向量
model.wv.similarity('苹果', '香蕉')  # 算相似度
```

### Char2Vec（字向量）
- Word2Vec 以词为单位 → Char2Vec 以**字**为单位
- 不依赖分词结果，对分词误差鲁棒
- 中文场景下有优势：字粒度比词粒度更稳定

## 四、文档相似度计算流程

```
语料 → 分词 → 词典 → BOW向量 → TF-IDF模型 → LSI/LDA降维
    → 新文档也走同样 pipeline → similarity查询
```

**关键**：训练时的词典决定了向量维度，新文档必须用同一个词典转 BOW。

## 五、思考链路

### 文本处理通用流程
```
原始文本 → 清洗(去标点/停用词) → 分词(jieba/HanLP)
    → 构建词典 → 文本向量化(BOW/TF-IDF/Word2Vec)
    → 下游任务(分类/聚类/相似度)
```
