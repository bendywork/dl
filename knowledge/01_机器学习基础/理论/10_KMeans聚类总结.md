# K-Means 聚类总结

## 一、核心思想

**把数据分成 K 组，组内样本越近越好，组间越远越好。**

与 KNN 的区别：KNN 是有监督分类（需要标签），K-Means 是无监督聚类（不需要标签）。

## 二、算法流程

```
1. 随机选 K 个点作为初始聚类中心（centroids）
2. 分配：每个样本归到最近的中心 → 形成 K 个簇
3. 更新：每个簇的均值 → 新的聚类中心
4. 重复 2-3，直到中心不再变化（或达到最大迭代次数）
```

## 三、"距离"怎么算

默认欧氏距离：`||x - centroid||²`。**必须先标准化**，否则量纲大的特征主导聚类结果。

## 四、K 值选择：肘方法

```
画图：K 值(横轴) vs 簇内误差平方和 SSE(纵轴)

SSE
 | \
 |  \___
 |      \_________  ← 拐点（肘部）= 最优 K
 └────────────────── K
```

**原理**：K 增大 SSE 必然减小，但过拐点后收益骤降——再增加 K 只是把自然簇硬拆。

## 五、核心局限

| 问题 | 说明 |
|------|------|
| **K 需预先指定** | 肘方法可辅助 |
| **对初始值敏感** | 不同初始中心可能得到不同结果 → 用 KMeans++ 优化初始化 |
| **假设簇是球形** | 非球形数据效果差 |
| **对异常值敏感** | 均值受极端值影响大 |

## 六、KMeans++（初始化优化）

不再是随便选 K 个初始点，而是：
1. 随机选第一个中心
2. 算每个点到最近中心的距离 D
3. 以 D² 为概率选下一个中心（距离越远被选中概率越大）
4. 重复 2-3 直到选够 K 个

→ 初始中心分散开，收敛更快更稳定。

## 七、思考链路

```
原始数据 → 标准化（必须！） → 肘方法选 K
    → KMeans(k=K) → fit → 拿到 labels_ + cluster_centers_
    → 可视化（散点图 + 中心标记）
```

## 八、应用场景

- 用户分群
- 文档聚类
- 图像色彩量化（把 N 种颜色压缩到 K 种）
- 异常检测（离所有中心都远的点 = 异常）
