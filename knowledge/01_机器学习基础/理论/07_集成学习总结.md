# 集成学习总结

## 一、核心思想

**"三个臭皮匠顶个诸葛亮"——组合多个弱学习器，得到一个强学习器。**

单个决策树容易过拟合 → 用多棵树投票/平均 → 方差降低，泛化能力强。

## 二、三大流派

### Bagging（并行训练 · 降方差）

```
原始数据 → Bootstrap 采样 → N 份子数据集
    → 并行训练 N 个模型（独立，互不依赖）
    → 分类：投票 | 回归：平均
```

**核心**：每个模型用不同的数据子集训练 → 模型多样性 → 平均后噪声抵消。

**代表**：随机森林 = Bagging + 决策树 + 特征随机采样（每个节点分裂时只考虑部分特征）

**随机森林的双重随机**：
1. 样本随机：Bootstrap 采样（每棵树用 ~63% 的数据）
2. 特征随机：每个节点只考虑 K 个随机特征（默认 K=√总特征数）

### Boosting（串行训练 · 降偏差）

```
第1轮：训练弱模型 → 看哪些样本错了
第2轮：加大错样本的权重 → 训练下一个弱模型
第3轮：继续调整权重...
最终：加权组合所有弱模型
```

**核心**：后一个模型**专门弥补前一个模型的短板**，逐步降低偏差。

### Stacking（多层组合）

用不同模型（如 RF + XGBoost + LR）的预测结果作为新特征，再训一个元模型。

## 三、三种 Boosting 对比

| | AdaBoost | GBDT | XGBoost/LightGBM |
|---|---|---|---|
| 关注点 | 调整**样本权重** | 拟合**残差** | GBDT 的工程优化版 |
| 损失 | 指数损失 | 任意可导损失 | 同上 + 正则化 |
| 速度 | 一般 | 一般 | 快（并行+缓存优化） |

### GBDT 核心公式
```
伪残差 r_i = -∂L/∂F(x_i)   ← 损失函数对当前预测值求负梯度

训练新树去拟合 r_i（残差）

F_new(x) = F_old(x) + α · h(x)   ← 用学习率 α 更新
```
**GBDT 把每一轮的负梯度当作"残差"，新树学习这个残差来修正前人错误。**

## 四、随机森林 vs GBDT

| | 随机森林 | GBDT |
|---|---|---|
| 训练方式 | 并行，树之间独立 | 串行，后树依赖前树 |
| 主要目标 | 降方差（防过拟合） | 降偏差（提高准确度） |
| 基学习器 | 深树（发挥单树能力） | 浅树（弱学习器） |
| 过拟合风险 | 低 | 需调参控制 |
| 代表 | RandomForest | XGBoost / LightGBM |

## 五、任务流程

```
加载数据 → 编码/标准化 → 定义模型(RF/AdaBoost/GBDT)
    → 交叉验证选参数 → 训练 → 预测 → 评估
```
