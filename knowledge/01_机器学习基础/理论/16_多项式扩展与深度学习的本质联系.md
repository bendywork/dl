# 多项式扩展与深度学习的本质联系

## 一、多项式扩展：从低维到高维的映射

### 原始数据
```
特征: x1, x2, x3
LR:   p = sigmoid(w1·x1 + w2·x2 + w3·x3 + b)
```

### 二阶多项式扩展
```
新特征:
  x1, x2, x3, x1·x2, x1·x3, x2·x3, x1², x2², x3²

LR: p = sigmoid(
       w1·x1 + w2·x2 + w3·x3 +           ← 一阶
       w4·x1·x2 + w5·x1·x3 + w6·x2·x3 +  ← 交互项
       w7·x1² + w8·x2² + w9·x3²          ← 平方项
       + b
     )
```

### 本质理解

**多项式扩展 = 坐标变换 = 低维到高维的映射。**

每一项就是一个"映射函数"（理解成神经元的功能）：

```
z1 = f1(x1,x2,x3) = x1
z2 = f2(x1,x2,x3) = x2
z3 = f3(x1,x2,x3) = x3
z4 = f4(x1,x2,x3) = x1·x2
z5 = f5(x1,x2,x3) = x1·x3
z6 = f6(x1,x2,x3) = x2·x3
z7 = f7(x1,x2,x3) = x1²
z8 = f8(x1,x2,x3) = x2²
z9 = f9(x1,x2,x3) = x3²
```

原始 3 维空间中线性不可分的数据，映射到 9 维空间后可能就线性可分了。

```
示例：(1, 5, 3) → (1, 5, 3, 5, 3, 15, 1, 25, 9)
```

## 二、深度学习 = 线性变换 + 激活函数的堆叠

### 多项式扩展 vs 深度学习

| | 多项式扩展 | 深度学习 |
|------|-----------|---------|
| 映射函数 | 人工指定（x1², x1·x2 等） | **参数学习出来的** |
| 谁决定映射 | 人 | 数据 + 损失函数 |
| 灵活性 | 固定公式 | 任意非线性组合 |

### 深度学习的神经元

```
原始数据: x1, x2

隐层神经元:
  z1 = tanh(-1.2·x1 - 0.13·x2 - 2.0)
  z2 = tanh(-0.58·x1 - 1.3·x2 + 3.0)
  z3 = tanh(0.82·x1 - 1.1·x2 - 3.0)

输出:
  p = sigmoid(-1.7·z1 + 1.8·z2 + -1.8·z3 + 0.0)
```

**每个神经元 = 一组参数 = 从某个角度提取特征。**

- 神经元 1 参数 `[-1.2, -0.13, -2.0]` → 提取某种特征
- 神经元 2 参数 `[-0.58, -1.3, 3.0]` → 提取另一种特征
- 每个神经元提取什么特征由**参数**决定
- 参数由**训练数据的损失最小化**决定

## 三、为什么激活函数不能省略（数学证明）

**没有激活函数 → 不管多少层都 = 单层线性模型。**

### 证明

```python
# 两层"线性"网络
z1 = W1·x + b1          # 第一层
z2 = W2·z1 + b2         # 第二层

# 代入展开
z2 = W2·(W1·x + b1) + b2
   = (W2·W1)·x + (W2·b1 + b2)
   = W'·x + b'          # ← 还是一个线性模型！
```

具体数值验证：
```
z1 = -1.2x1 - 0.13x2 - 2.0
z2 = -0.58x1 - 1.3x2 + 3.0
z3 = 0.82x1 - 1.1x2 - 3.0

输出: sigmoid(-1.7·z1 + 1.8·z2 + -1.8·z3 + 0.0)

展开:
  = sigmoid(
      -1.7(-1.2x1-0.13x2-2.0) +
      1.8(-0.58x1-1.3x2+3.0) +
      -1.8(0.82x1-1.1x2-3.0)
    )
  = sigmoid(-0.48x1 - 0.139x2 + 14.2)

→ 堆了三层，结果等价于一个 Linear(x1,x2)！
```

**激活函数的价值**：打破线性链，让每一层不再是上一层的线性组合。`tanh`、`ReLU` 的不可叠加性让多层网络 ≠ 单层网络。

## 四、核心三句话

| 概念 | 一句话 |
|------|--------|
| 多项式扩展 | 人工指定映射函数，把数据从低维搬到高维，让非线性问题变成线性可分 |
| 深度学习 | 用数据学习映射函数，神经元参数 = 映射规则，训练过程 = 找最优映射 |
| 激活函数 | 如果没有它，100 层网络等价于 1 层线性模型——激活函数是"层"存在的意义 |

## 五、演进逻辑

```
多项式扩展（人手动选特征）
  → 人工指定映射函数 z_i = f_i(x)

感知机 / LR（单层线性）
  → 只学最后一层的权重

深度学习（多层 + 激活函数）
  → 连映射函数（神经元参数）也一起学
  → 损失函数反向传播决定每层参数
  → 每层学到的 z_i 是什么 → 由数据决定，不由人决定
```
