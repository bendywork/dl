# 线性回归总结

## 一、核心思想

用一条直线（或超平面）拟合数据，使得预测值与真实值之间误差最小。

**公式**：`y = θ₀ + θ₁x₁ + θ₂x₂ + ...` 即 `y = Xθ`

## 二、解析解（正规方程）

**公式**：`θ = (XᵀX)⁻¹Xᵀy`

### 推导思路
```
目标：min J(θ) = (1/2m) Σ(y_pred - y_true)²
    → 对 θ 求导，令导数为 0
    → ∂J/∂θ = XᵀXθ - Xᵀy = 0
    → θ = (XᵀX)⁻¹Xᵀy
```

**代码实现**：`theta = (X.T * X).I * X.T * Y`

### 任务流程
```
1. 构造数据（X + 偏置列 1）
2. 转 numpy 矩阵（np.mat）
3. 套公式求 θ
4. X_test * θ 得预测值
5. 画图验证
```

### 解析解的局限
- `XᵀX` 必须可逆（特征数 > 样本数时不可逆）
- 时间复杂度 O(n³)，大数据不适用

## 三、多项式扩展

线性回归 + 特征多项式组合 → 拟合非线性关系。

```
原始：y = θ₀ + θ₁x
扩展：y = θ₀ + θ₁x + θ₂x² + θ₃x³  ← 仍是 θ 的线性函数！
```

**关键**：多项式回归本质仍是线性回归——对 θ 线性，对 x 非线性。

## 四、评估指标

| 指标 | 公式 | 含义 |
|------|------|------|
| MSE | `(1/n)Σ(y_pred - y_true)²` | 均方误差，越小越好 |
| MAE | `(1/n)Σ|y_pred - y_true|` | 平均绝对误差，对异常值不敏感 |
| R² | `1 - SS_res/SS_tot` | 拟合优度，越接近 1 越好 |

## 五、波士顿房价预测流程

```
加载数据 → 划分训练/测试集 → 创建 LinearRegression 模型
    → fit 训练 → predict 预测 → MSE/R² 评估
```
