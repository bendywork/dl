# 逻辑回归与 Softmax 总结

## 一、核心思想

**逻辑回归 = 线性回归 + Sigmoid，把回归变成分类。**

线性回归输出实数值 `y = Xθ` → Sigmoid 把它压到 (0,1) → 解释为"属于正类的概率"。

## 二、Sigmoid 函数（核心数学）

```
σ(z) = 1 / (1 + e^(-z))

z = Xθ（线性回归的输出）

P(y=1) = σ(z)  → 预测为正类的概率
P(y=0) = 1 - σ(z)
```

**Sigmoid 的性质**：
- 输入 → +∞，输出 → 1
- 输入 → -∞，输出 → 0
- 输入 = 0，输出 = 0.5（决策边界）
- **导函数**：`σ'(z) = σ(z)(1-σ(z))` ← 这个性质让反向传播计算极简

## 三、损失函数：交叉熵

### 为什么不能用 MSE
Sigmoid + MSE → 梯度中有 `σ'(z)` 因子，当 σ 接近 0 或 1 时导数趋近 0 → **梯度消失，学不动**。

### 交叉熵公式
```
J(θ) = -(1/m) Σ [y·log(ŷ) + (1-y)·log(1-ŷ)]

ŷ = σ(Xθ)
```

交叉熵的梯度不含 `σ'(z)` 的扁平区问题 → 梯度健康，学得快。

**直觉**：当 y=1 时只剩 `-log(ŷ)`，ŷ 越接近 1 损失越小；ŷ 越接近 0 损失越大（惩罚很重）。

### 梯度推导（重点）
```
∂J/∂θ = (1/m) Xᵀ(ŷ - y)
```
**形式跟线性回归的梯度一模一样！** 区别仅在于 ŷ 经过了 sigmoid。

## 四、从二分类到多分类：Softmax

### Softmax 公式
```
P(y=k|X) = e^(z_k) / Σ e^(z_j)

z_k = X·θ_k  （第 k 类的线性输出）
```

- 把 K 个实数值变成 K 个概率，和为 1
- **指数**保证非负，分母归一化保证和为 1
- Sigmoid 是 Softmax 在 K=2 时的特例

### 多分类损失：交叉熵
```
J = -(1/m) Σ Σ y_ik · log(P_ik)
```
y_ik 是 one-hot 编码，只有真实类别那个位置为 1 → 只惩罚真实类别被低估的部分。

## 五、乳腺癌分类流程

```
加载数据 → 划分训练/测试集 → LogisticRegression(solver='liblinear')
    → fit 训练 → predict 预测 → accuracy + 混淆矩阵评估
```

## 六、逻辑回归 vs 线性回归

| | 线性回归 | 逻辑回归 |
|---|---|---|
| 输出范围 | (-∞, +∞) | (0, 1) |
| 任务 | 回归（预测数值） | 分类（预测类别概率） |
| 损失函数 | MSE | 交叉熵 |
| 激活函数 | 无 | Sigmoid |
