# 激活函数总结

## 📌 核心问题
> 为什么神经网络一定要"非线性"激活？激活函数到底在选什么？怎样在梯度消失/死神经元/输出范围之间权衡？

---

## 🌱 根源与动机

如果每层都只做 `y = Wx + b`，**多层等价于单层**（线性变换的复合仍是线性变换），无论多深都只能拟合线性函数。
要让神经网络成为"万能逼近器"，必须在层与层之间插入**非线性**——这就是激活函数的全部存在意义。

但激活函数的"好坏"远不止"是否非线性"，关键还看：

| 指标 | 解释 | 影响 |
|---|---|---|
| **梯度范围** | f'(x) 是否有大范围接近 0 的区域 | 梯度消失 |
| **梯度上界** | f'(x) 最大值能否远大于 1 | 梯度爆炸 |
| **输出零均值** | 输出是否关于 0 对称 | 优化收敛速度 |
| **计算成本** | 是否含 exp / 二次幂 | 推理速度 |
| **饱和区** | 是否在大 / 小输入下"卡死" | 死神经元 |
| **可导性** | 是否处处可导 | 优化稳定性 |

---

## 🗺️ 激活函数分类

```
激活函数
├─ 经典 / 饱和型
│   ├─ Sigmoid    — 早期、概率输出
│   └─ Tanh       — RNN/LSTM 内核
│
├─ ReLU 家族（非饱和正区间）
│   ├─ ReLU       — 现代默认
│   ├─ Leaky ReLU — 死神经元修复
│   ├─ PReLU      — 学习斜率
│   ├─ ELU        — 负区间平滑
│   └─ SELU       — 自归一化
│
├─ 现代平滑型
│   ├─ GELU       — Transformer 默认
│   ├─ Swish/SiLU — EfficientNet
│   └─ Mish       — 部分 YOLO
│
├─ 输出层专用
│   ├─ Sigmoid    — 二分类 / 多标签
│   └─ Softmax    — 多分类（互斥）
│
└─ 门控 / 组合
    ├─ GLU        — 语言模型
    ├─ SwiGLU     — LLaMA / PaLM
    └─ GeGLU      — T5
```

## 1. 经典饱和型

### 1.1 Sigmoid

$$
\sigma(x) = \frac{1}{1 + e^{-x}},\qquad \sigma'(x) = \sigma(x)\,(1 - \sigma(x))
$$

- 输出范围 (0, 1)，天然适合"概率"解释；
- **致命缺点**：
  - 梯度上界仅 0.25（`σ' = σ(1-σ) ≤ 0.25`），深网络反传 N 次 → `0.25^N` 极速消失；
  - 输出**非零均值**（恒正），下层梯度方向同号，**zig-zag 收敛**；
  - 含 `exp`，比 ReLU 慢；
- **现代用途**：
  - 二分类**输出层**；
  - LSTM / GRU 的**门控**（输出 ∈ (0,1) 当成"开多大门"）；
  - 隐藏层基本退役。

### 1.2 Tanh

$$
\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}},\qquad \tanh'(x) = 1 - \tanh^2(x)
$$

- 输出 (-1, 1)，**零均值**——比 sigmoid 收敛快；
- 梯度上界 1（在 x=0 处），但两端仍饱和 → 深网络也有梯度消失；
- **现代用途**：RNN / LSTM 的细胞状态变换；现代 CNN/Transformer 隐藏层基本不用。

---

## 2. ReLU 家族（深度学习的中流砥柱）

### 2.1 ReLU

$$
\text{ReLU}(x) = \max(0, x),\qquad \text{ReLU}'(x) = \mathbf{1}\{x > 0\}
$$

- 正区间梯度恒为 1，**不饱和、不消失**——这是 2012 年 AlexNet 之后深度网络能训起来的关键；
- 计算极简，仅一次比较；
- **致命缺点：死神经元 (Dying ReLU)**
  - 一旦某神经元的输入恒 ≤ 0，梯度恒为 0 → 参数永远不再更新 → 神经元永久"死亡"；
  - 学习率过大、初始化不当、某些类别的偏置漂移都会触发；
- **缓解**：
  - 用 He 初始化（专为 ReLU 设计，`std = √(2/fan_in)`）；
  - 适度学习率；
  - BatchNorm；
  - 改用 Leaky / PReLU / ELU。

### 2.2 Leaky ReLU

$$
\text{LeakyReLU}(x) = \begin{cases} x, & x \ge 0 \\ \alpha x, & x < 0 \end{cases},\quad \alpha = 0.01
$$

- 负区间给一个小斜率 α，**死神经元不再 100% 死**；
- 几乎零额外成本；α 是超参；
- 现代 GAN（DCGAN、StyleGAN）的 D 网络爱用。

### 2.3 PReLU（Parametric ReLU）

- Leaky ReLU 的"可学习版"：α 是**模型参数**，由反向传播学到；
- 每通道一个 α，参数量增加忽略不计；
- He 在《Delving Deep into Rectifiers》里提出，对小数据集易过拟合。

### 2.4 ELU

$$
\text{ELU}(x) = \begin{cases} x, & x \ge 0 \\ \alpha(e^x - 1), & x < 0 \end{cases}
$$

- 负区间平滑收敛到 -α，**输出均值更接近 0**，缓解 bias shift；
- 包含 `exp`，比 ReLU 慢约 30%；
- 实测对收敛速度有帮助，但已被现代 GELU/Swish 取代。

### 2.5 SELU（Self-Normalizing）

$$
\text{SELU}(x) = \lambda\,\text{ELU}(x; \alpha)
$$

- 选定特殊的 `λ ≈ 1.0507, α ≈ 1.6733`，配合 **AlphaDropout + LeCun 初始化**，能让前传时**每层激活自动维持零均值单位方差**，理论上免去 BatchNorm；
- 实战中由于约束苛刻（必须用全连接 + 无残差），现代很少独立使用。

### 2.6 ReLU 家族对比

| 激活 | 负区间 | 死神经元 | 计算成本 | 推荐 |
|---|---|---|---|---|
| ReLU | 0 | 易死 | 最低 | 现代 CNN 默认 |
| LeakyReLU | αx | 不死 | 极低 | 轻量改进 |
| PReLU | αx (学) | 不死 | 极低 | 大数据集 |
| ELU | α(eˣ-1) | 不死 | exp 较慢 | 已退潮 |
| SELU | 自归一 | 不死 | 中 | 实验性 |

## 3. 现代平滑型（Transformer 时代）

### 3.1 GELU（Gaussian Error Linear Unit）

$$
\text{GELU}(x) = x \cdot \Phi(x) \approx 0.5x\left(1 + \tanh\!\left[\sqrt{\tfrac{2}{\pi}}\,(x + 0.044715 x^3)\right]\right)
$$

其中 Φ 是标准正态 CDF。直觉：**用"该输入大于 0 的概率"作为输入的权重**——比 ReLU 的硬阈值平滑。

- **特点**：
  - 处处可导（含负区间，且负区间不是恒 0，有少量梯度）；
  - 在 x 大时 ≈ x（像 ReLU），x 小时 ≈ 0；
  - 比 ReLU 训练略稳，收敛略优；
- **使用**：BERT、GPT-2/3、ViT 等 **Transformer 的默认激活**；
- **PyTorch**：`nn.GELU()`，可选 `approximate='tanh'` 用近似式（速度略快）。

### 3.2 Swish / SiLU

$$
\text{Swish}(x) = x \cdot \sigma(x) = \frac{x}{1 + e^{-x}}
$$

- Google Brain 2017 NAS 搜索出来的；
- 形态与 GELU 极相似（实际数值差异 <2%），但**只用一个 sigmoid，比 GELU 略快**；
- 处处可导，**非单调**（在 x ≈ -1.28 有轻微下凹），允许少量负输出；
- **使用**：EfficientNet、MobileNetV3、部分 YOLO 系列；
- **PyTorch**：`nn.SiLU()`（SiLU = Sigmoid Linear Unit = Swish）。

### 3.3 Mish

$$
\text{Mish}(x) = x \cdot \tanh(\text{softplus}(x)) = x \cdot \tanh(\ln(1 + e^x))
$$

- 形态与 Swish 类似，负区间下凹更深、过渡更平滑；
- 在部分 CV 任务（YOLOv4 backbone）效果略优于 Swish；
- 计算成本更高（含 log + tanh）；
- **PyTorch**：`nn.Mish()`。

### 3.4 三者数值对比（x = -2)

| 激活 | 值 | 一阶导 |
|---|---|---|
| ReLU(-2) | 0 | 0 |
| GELU(-2) | -0.0455 | -0.085 |
| Swish(-2) | -0.238 | -0.090 |
| Mish(-2) | -0.252 | -0.106 |

负区间不再恒 0 → 死神经元问题被根除，但代价是计算量翻倍。

### 3.5 选哪个？

| 任务 | 推荐 |
|---|---|
| Transformer / NLP | **GELU**（生态默认） |
| 高效 CNN | **Swish / SiLU** |
| YOLO v4 backbone 风格 | **Mish** |
| 移动端 / 极致速度 | **ReLU** 或 hard-Swish（用 `x * ReLU6(x+3)/6` 近似） |

## 4. 输出层专用

### 4.1 Sigmoid（输出层版）

- 二分类：单个 logit → 概率；
- 多标签：每个 logit 独立 → 各自概率；
- **务必搭配 `BCEWithLogitsLoss`，不要手动 sigmoid 再 BCE**（数值稳定性）。

### 4.2 Softmax

$$
\text{softmax}(z)_c = \frac{e^{z_c}}{\sum_j e^{z_j}}
$$

- 输出归一化为离散概率分布，所有维度之和 = 1；
- 多分类**互斥**时使用（图像分类、token 预测）；
- **务必搭配 `CrossEntropyLoss`，输入 logits，框架内部 log-sum-exp**；
- **温度**：`softmax(z / T)`，T<1 锐化，T>1 软化——蒸馏、采样的关键超参；
- **陷阱**：多标签任务用 softmax 会强制类别互斥，把"猫和狗都在图里"压成"五五开"，错配语义。

### 4.3 回归输出层

- 不要加激活！让最后一层线性输出实数（可正可负）；
- 若目标在 [0, 1]，可加 sigmoid；
- 若目标在 [-1, 1]，可加 tanh；
- 若目标非负，可加 softplus 或 ReLU（避免 0 端死神经元）。

## 5. 门控类激活（FFN 增强）

### 5.1 GLU

$$
\text{GLU}(x) = (xW_1 + b_1) \otimes \sigma(xW_2 + b_2)
$$

- 用 sigmoid 输出一个"门"，决定多少信息透过；
- 一层 GLU 用了**两套权重**，参数翻倍但表达力强。

### 5.2 SwiGLU / GeGLU（现代 LLM 默认）

把 GLU 里的 sigmoid 换成 Swish / GELU：

$$
\text{SwiGLU}(x) = \text{Swish}(xW_1) \otimes (xW_2)
$$

- LLaMA、PaLM、Mistral 的 FFN 使用 **SwiGLU**；
- T5 使用 **GeGLU**；
- 实验显示同参数预算下，SwiGLU FFN 比标准 `Linear-GELU-Linear` 效果更好；
- 工程注意：为保持参数量相当，FFN 内维通常调小到 `(2/3) · 4d`（LLaMA 做法）。

## 6. 全局选型指南

```
位置在哪里？
├─ 隐藏层
│   ├─ CNN
│   │   ├─ 通用 / 默认 ──────→ ReLU + He init + BN
│   │   ├─ 想要小提升 ───────→ Swish / Mish
│   │   └─ 移动端 ──────────→ ReLU6 / Hard-Swish
│   ├─ Transformer
│   │   ├─ FFN ─────────────→ GELU（标准） / SwiGLU（LLM）
│   │   └─ 输出归一化前 ─────→ 不加（用 LayerNorm 替代）
│   ├─ RNN / LSTM / GRU ────→ Tanh + Sigmoid（门控） 已是内核
│   └─ GAN
│       ├─ G 中间层 ────────→ ReLU
│       └─ D 中间层 ────────→ LeakyReLU(0.2)
│
└─ 输出层（看损失函数）
    ├─ 二分类 / 多标签 ──→ Sigmoid（或不加 + BCEWithLogits）
    ├─ 多分类互斥 ──────→ Softmax（或不加 + CrossEntropyLoss）
    ├─ 回归 ───────────→ 不加（线性输出）
    └─ 概率密度 (β/μ) ──→ Softplus 保正
```

## 7. 实战陷阱清单

### 7.1 死神经元自查

训练日志中加一行：
```python
dead_ratio = (activations <= 0).float().mean().item()
```
某层超过 50% 神经元长期为 0，就该改激活 / 调初始化 / 加 BN。

### 7.2 输出层别"叠加 softmax"

```python
# ❌ 不要这样
loss = F.cross_entropy(F.softmax(logits, dim=-1), targets)   # 双重 softmax，错!

# ✅ 直接传 logits
loss = F.cross_entropy(logits, targets)
```

### 7.3 多标签别用 softmax

多标签是"每个标签独立 yes/no"，必须 sigmoid + BCE。用 softmax 会让模型在多个对的标签之间相互"抢概率"。

### 7.4 RNN 千万别在状态间用 ReLU

RNN 沿时间反复传播，ReLU 会让状态爆炸（无饱和）或全死。**Tanh 仍是 RNN/LSTM/GRU 的内核激活**，这是有数值理由的。

### 7.5 残差网络里的激活顺序

经典 ResNet 用 `conv → BN → ReLU → conv → BN → (+) → ReLU`；
Pre-Norm（Transformer 现代写法）是 `LayerNorm → Attention → (+)`，**残差通路不要插非线性激活**，否则恒等映射学不出来。

### 7.6 GELU / Swish 在低精度下

FP16 / BF16 训练时，GELU 的 tanh 近似版本数值精度更稳；纯 erf 版本可能在小值附近抖动。

---

## ✅ 一句话总结

> 隐藏层默认 **ReLU**，Transformer/LLM 默认 **GELU/SwiGLU**，移动端默认 **ReLU/Hard-Swish**；
> 输出层看损失：二分类/多标签 sigmoid，多分类 softmax，回归不加；
> RNN 内核留给 Tanh + Sigmoid。
> **永远不要把激活和损失分两步算，永远不要在残差通路上加激活。**
