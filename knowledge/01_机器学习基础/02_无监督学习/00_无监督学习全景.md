# 无监督学习全景：分类与选型

## 核心定义

> 无监督学习：**从无标签数据中发现隐藏的结构、模式或分布**。没有"正确答案"，模型必须自行发现数据的内在规律。

与监督学习的根本区别：
- 监督学习：有 `y`（标签），目标是学 `f(x) → y`
- 无监督学习：只有 `x`（数据），目标是发现 `x` 中的隐藏结构

---

## 四类核心任务

```
无监督学习
├── 1. 聚类 (Clustering)
│     ├── KMeans：球形簇、快、需指定 K
│     ├── DBSCAN：任意形状、天然识别噪声、不用指定 K
│     ├── 层次聚类：树状图可视化、小数据
│     └── GMM：软分配（概率归属）、椭圆形簇
│
├── 2. 降维 (Dimensionality Reduction)
│     ├── PCA：线性降维、方差最大化
│     ├── t-SNE：高维 → 2D/3D 可视化专用
│     ├── UMAP：t-SNE 的升级版、更快、保留更多全局结构
│     └── 自编码器：非线性降维、神经网络实现
│
├── 3. 关联规则 (Association Rules)
│     ├── Apriori：频繁项集挖掘
│     └── FP-Growth：Apriori 的优化版
│
└── 4. 异常检测 (Anomaly Detection)
      ├── Isolation Forest：随机森林式隔离异常点
      ├── One-Class SVM：学习"正常"的边界
      └── LOF (Local Outlier Factor)：密度比异常检测
```

---

## 聚类 vs 降维：本质区别

| 维度 | 聚类 | 降维 |
|------|------|------|
| 目标 | 把样本分成若干组 | 把特征压缩到更少维度 |
| 输出 | 每个样本的簇标签 | 每个样本的低维表示 |
| 典型问题 | "这些客户能分几类？" | "100 维数据如何可视化？" |
| 关系 | 聚类前常先降维（去除噪声、加速） | 降维后数据可做聚类 |

## 选型决策树

```
需要分组（样本归类）？
  ├─ 已知分成几组？
  │   ├─ 球形簇 → KMeans
  │   └─ 非球形 → KMeans++ 多次初始化 或 GMM
  ├─ 不知道分几组？
  │   ├─ 含噪声点 → DBSCAN
  │   └─ 小数据需可视化 → 层次聚类
  └─ 需要软分配（每个样本属于每类概率）→ GMM

需要压缩维度（特征处理）？
  ├─ 可解释性重要 → PCA（线性组合可解释）
  ├─ 纯可视化 → t-SNE / UMAP
  └─ 非线性复杂数据 → 自编码器

需要发现关联？
  └─ 购物篮分析 → Apriori / FP-Growth

需要找异常？
  └─ 高维数据 → Isolation Forest
```

## 常见误区

1. **KMeans 是监督学习** → 错，它不需要标签，是无监督聚类
2. **PCA 是特征选择** → 错，PCA 是特征变换（新特征是原始特征的线性组合）
3. **t-SNE 可以做特征压缩后建模** → 不推荐，t-SNE 是随机算法，输出不稳定，专用于可视化
4. **DBSCAN 不用调参** → eps 和 min_samples 需要调，只是不用调 K 而已
5. **降维后聚类一定更好** → 不一定，降维可能丢失聚类关键信息
