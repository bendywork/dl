# DBSCAN 密度聚类

## 一、核心问题

> KMeans 假设簇是球形的、需要预先指定 K 值、对异常值敏感。**DBSCAN 基于密度定义簇——把高密度区域连成一片，自动发现任意形状的簇，并天然识别噪声点。**

---

## 二、核心概念（两个参数）

| 参数 | 含义 | 直觉 |
|------|------|------|
| **eps (ε)** | 邻域半径 | "多近算邻居？" |
| **min_samples** | 最小邻居数 | "至少几个邻居才算密集区？" |

三个点的定义：

```
核心点 (Core Point)：
  以它为圆心、eps 为半径的圆内 ≥ min_samples 个点
  → 它处于"密集区"

边界点 (Border Point)：
  圆内邻居 < min_samples，但它自己在某个核心点的邻域内
  → 它处于"密集区边缘"

噪声点 (Noise Point)：
  既不是核心点也不是边界点
  → 它是"离群点"
```

---

## 三、算法流程

```
1. 标记所有点为核心点/边界点/噪声点
2. 随机选一个未访问的核心点 → 新建一个簇
3. 找出该核心点密度可达的所有点 → 全部加入该簇
4. 重复 2-3，直到所有核心点都被访问
5. 噪声点不归入任何簇（label = -1）
```

---

## 四、DBSCAN vs KMeans

| 维度 | KMeans | DBSCAN |
|------|--------|--------|
| 簇形状 | 只认球形 | 任意形状 |
| K 值 | 必须预先指定 | 不需要（自动发现） |
| 异常值 | 强制分到某个簇 | 天然标记为噪声（label=-1） |
| 参数 | K | eps + min_samples |
| 大数据 | 快 O(n) | 慢 O(n log n)，邻域查询开销大 |
| 密度不均 | 勉强能用 | 一个 eps 难兼顾不同密度区域 |

---

## 五、核心局限

| 问题 | 说明 | 解决方案 |
|------|------|---------|
| **密度不均匀** | 一个全局 eps 无法兼顾稀疏区和密集区 | HDBSCAN（自适应 eps） |
| **高维失效** | 高维空间距离都差不多，密度概念坍塌 | 先降维再用 DBSCAN |
| **参数敏感** | eps 稍微变化结果差异大 | 用 k-distance 图辅助选 eps |

## 六、层次聚类（补充）

与 DBSCAN/KMeans 思路完全不同——**不预先分簇，而是构建一棵"聚类树"**：

```
自底向上（凝聚，Agglomerative）：
  每个点自己是一个簇 → 反复合并最近的簇 → 直到只剩一个簇

自顶向下（分裂，Divisive）：
  所有点是一个大簇 → 反复分裂 → 直到每个点独立成簇

输出：树状图（Dendrogram）→ 在任意高度"切一刀"得到对应簇数
```

优势：不需要预设 K，树状图可视化直观。劣势：O(n³) 复杂度，大数据不可用。

---

## 七、无监督学习算法选型速查

| 场景 | 推荐算法 |
|------|---------|
| 数据量很大、球形簇、已知 K | KMeans（快） |
| 任意形状、含噪声、K 未知 | DBSCAN |
| 需要树状可视化、小数据 | 层次聚类 |
| 需要软分配（概率归属） | GMM（高斯混合模型） |
| 高维数据可视化 | t-SNE / UMAP |
| 降维压缩 | PCA |
| 非线性降维 | Kernel PCA / 自编码器 |
