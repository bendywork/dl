# PCA 主成分分析详解

## 一、核心问题

> 高维数据难以可视化、计算量大、含冗余信息。**PCA 的核心思想：找到数据方差最大的方向（主成分），将数据投影到少数几个主成分上，实现降维同时尽可能保留原始信息。**

降维的本质：原始数据可能用 100 维表示，但其实 95% 的信息集中在某 2-3 个方向上。PCA 就是找到这些方向。

---

## 二、直观理解

```
二维数据 → 一维的例子：

    y ↑     ···
      |   ·······    ← 数据沿某个倾斜方向散布最广
      | ·········
      |··  ·········
      └──────────────────→ x

    → PCA 找到散布最广的方向（第一主成分 PC1）
    → 把数据投影到 PC1 上 → 二维 → 一维 → 信息损失最小
```

> 类比：你给一栋房子拍照片。从正面拍 → 看到门、窗、楼层（信息量大）。从正上方拍 → 只看到屋顶（信息量小）。PCA 就是找到"信息量最大"的拍摄角度。

---

## 三、数学推导

### 3.1 核心公式

$$\text{目标：找到投影方向 } w \text{，使得投影后数据的方差最大}$$

$$w_1 = \arg\max_{\|w\|=1} \text{Var}(Xw) = \arg\max_{\|w\|=1} w^T \Sigma w$$

其中 $\Sigma = \frac{1}{n}X^T X$ 是协方差矩阵。这个优化问题的解：**$w_1$ 是 $\Sigma$ 最大特征值对应的特征向量**。

推广：前 k 个主成分 = 协方差矩阵前 k 大特征值对应的特征向量。

### 3.2 五步算法流程

```
输入：数据矩阵 X [n_samples × n_features]

1. 标准化：每列减去均值，除以标准差（量纲统一）
   X_std = (X - mean) / std

2. 计算协方差矩阵：
   Σ = (1/n) · X_std^T · X_std   [n_features × n_features]

3. 特征分解：
   求 Σ 的特征值 λ 和特征向量 v
   λ 从大到小排序：λ₁ ≥ λ₂ ≥ ... ≥ λ_d

4. 选择前 k 个主成分：
   k 可以是固定值，也可以使累积方差比 ≥ 阈值（如 95%）
   P = [v₁, v₂, ..., v_k]   [n_features × k]

5. 投影降维：
   X_new = X_std · P        [n_samples × k]
```

### 3.3 方差解释率

$$\text{第 i 主成分解释的方差比} = \frac{\lambda_i}{\sum_{j=1}^{d} \lambda_j}$$

这是衡量"降维损失多少信息"的核心指标：累积到 95% → 保留 95% 信息，丢弃 5% 噪声。

---

## 四、为什么必须先标准化？

```
原始特征：年龄(20-80) vs 年收入(2万-200万)

不标准化：
  年收入的方差 >> 年龄的方差
  → 协方差矩阵被年收入主导
  → PC1 几乎等价于"年收入"，PC2 = "年龄"
  → 主成分被量纲绑架，不是真正的数据结构

标准化后（均值为0, 标准差为1）：
  所有特征平权
  → 主成分反映特征之间的真实相关结构
```

---

## 五、核心局限

| 局限 | 说明 | 替代方案 |
|------|------|---------|
| **线性假设** | 只能捕捉线性关系 | Kernel PCA, 自编码器 |
| **高斯假设** | 隐含假设数据符合高斯分布 | ICA（独立成分分析） |
| **可解释性差** | 主成分是原始特征的线性组合，难以解释 | 特征选择（保留原始特征） |
| **对异常值敏感** | 方差受极端值影响大 | Robust PCA |

---

## 六、思考链路

```
原始数据 → 标准化（必须！）
  → 协方差矩阵 → 特征分解
  → 看累积方差解释率 → 选 k
  → fit_transform → 降维后的数据
  → 可视化（2D/3D 散点图）或输入下游模型
```

## 七、应用场景

- **数据可视化**：高维 → 2D/3D 散点图
- **去噪**：丢弃小特征值对应的成分（通常 = 噪声）
- **特征压缩**：减少维度 → 加速训练 → 缓解维度灾难
- **多重共线性处理**：主成分互不相关 → 替代原始特征进回归模型
