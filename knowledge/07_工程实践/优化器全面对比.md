# 优化器全面对比：从 SGD 到 AdamW

## 一、演化全景

```
SGD → SGD+Momentum → NAG → AdaGrad → RMSprop → Adam → AdamW → RAdam
 │         │          │        │         │        │        │
 基础      加惯性     先看一步  自适应lr  平滑动量  一阶+二阶  解耦衰减  修正启动
```

## 二、各优化器详解

### 1. SGD（随机梯度下降）

```
W = W - lr * ∇W
```
- 最基础，无状态
- 优点：泛化能力最好（尤其 CV 任务最终 fine-tune 常用）
- 缺点：学习率难设，鞍点慢，震荡

### 2. SGD + Momentum（动量）

```
v = β * v + ∇W           ← 积累历史梯度方向，β≈0.9
W = W - lr * v
```
- 类比：球滚下山，惯性让它在平坦区不下滑、震荡区被平滑
- β=0.9 大约记住过去 10 步的方向

### 3. NAG（Nesterov 加速梯度）

```
W_lookahead = W - lr * β * v    ← 先"试探性"看一步
v = β * v + ∇W(W_lookahead)     ← 在试探位置算梯度
W = W - lr * v
```
- Momentum 的改进：先走惯性，再看梯度 → 有预见性，减少震荡

### 4. AdaGrad（自适应学习率）

```
G = G + ∇W²                 ← 累积历史梯度平方和
W = W - lr * ∇W / √(G + ε)
```
- 频繁更新的参数 → G 大 → 自动降学习率
- 稀疏特征受益最大（NLP 中稀有词）
- **致命缺陷**：G 单调递增 → 学习率终将趋近 0 → 训练过早停止

### 5. RMSprop

```
G = β * G + (1-β) * ∇W²    ← 指数移动平均替代累加，β≈0.9
W = W - lr * ∇W / √(G + ε)
```
- 解决了 AdaGrad 学习率单调递减问题
- 只记得最近 ~10 步的梯度平方，旧的会遗忘

### 6. Adam（Momentum + RMSprop）

```
m = β₁ * m + (1-β₁) * ∇W        ← 一阶矩（动量）     β₁=0.9
v = β₂ * v + (1-β₂) * ∇W²       ← 二阶矩（自适应lr）  β₂=0.999
m̂ = m / (1-β₁^t)                 ← 偏差修正（前几步 m/v 太小）
v̂ = v / (1-β₂^t)
W = W - lr * m̂ / (√v̂ + ε)        ε=1e-8
```
- 默认超参几乎不用调，**目前最常用的优化器**
- 偏差修正解决初始几步 m/v 偏向 0 的问题

### 7. AdamW（Adam + Weight Decay 解耦）

Adam 的 L2 正则问题：`∇W' = ∇W + λW` 进入 Adam 后，λW 被 v 缩放 → 实际衰减不均匀。

AdamW 把 weight decay 直接加在权重上：
```
W = W - lr * m̂ / (√v̂ + ε) - lr * λ * W
                          ↑ Adam 更新      ↑ 独立衰减
```
- **LLaMA/BERT/GPT 训练标配**
- 每个参数以相同倍率衰减，正则化更均匀

### 8. RAdam（Rectified Adam）

Adam 在训练初期 v 方差大 → 学习率不稳定 → 可能收敛到坏方向。RAdam 在前几步用 SGD 过渡，等 v 稳定后再切换到 Adam。

## 三、对比速查表

| 优化器 | 有动量？ | 自适应lr？ | 需要调参 | 适用场景 |
|--------|---------|-----------|---------|---------|
| SGD | ❌ | ❌ | 学习率难设 | CV 终调 |
| SGD+Momentum | ✅ | ❌ | β + lr | 通用基线 |
| AdaGrad | ❌ | ✅ | 几乎不用 | 稀疏特征/NLP |
| RMSprop | ❌ | ✅ | β + lr | RNN/序列 |
| Adam | ✅ | ✅ | 几乎不用 | **默认首选** |
| AdamW | ✅ | ✅ | + weight_decay | **LLM 标配** |
| RAdam | ✅ | ✅ | 同 Adam | 训练不稳定时 |

## 四、NLP 场景选型指南

| 场景 | 推荐 | 原因 |
|------|------|------|
| 文本分类（RNN/LSTM） | Adam | 简单有效 |
| Seq2Seq（LSTM） | Adam / RMSprop | RNN 类对学习率敏感 |
| Transformer 小规模 | Adam | 默认够用 |
| Transformer 预训练 | **AdamW** | weight decay 解耦，正则化更好 |
| BERT/GPT 微调 | **AdamW** | 标准配置 |
| 最终模型 fine-tune | SGD+Momentum | 泛化能力可能更好 |

## 五、学习率调度（LR Schedule）

光有好优化器不够，学习率要动态衰减：

| 调度 | 做法 | 适用 |
|------|------|------|
| Step Decay | 每 N 步 lr × 0.1 | 简单任务 |
| Cosine Decay | 按余弦曲线从 lr → 0 | **Transformer/LLM 标配** |
| Linear Decay | 线性降到 0 | HuggingFace 默认 |
| Warmup | 前 5-10% 步线性增加 lr | **Transformer 必加**，防早期震荡 |

### Warmup 为什么重要
训练初期参数随机，Adam 的 v 方差大 → 学习率方向不稳定 → 可能把模型带偏。先在少量步数内从小 lr 线性增长到目标 lr → 等参数稳定后再全力训练。

## 六、底层伪代码（统一视角）

```python
class Optimizer:
    def __init__(self, params, lr):
        self.param_groups = [{'params': params, 'lr': lr}]  # 存引用，不是复制

    def zero_grad(self):
        for p in self.param_groups[0]['params']:
            p.grad = None                                     # 清空，默认累加

    def step(self):                                           # 子类实现
        raise NotImplementedError

class SGD(Optimizer):
    def step(self):
        for group in self.param_groups:
            for p in group['params']:
                p.data = p.data - group['lr'] * p.grad.data  # W -= lr * grad

class Adam(Optimizer):
    def __init__(self, params, lr, betas=(0.9, 0.999), eps=1e-8):
        super().__init__(params, lr)
        self.betas = betas
        self.eps = eps
        self.state = {}                                       # 存 m, v, t

    def step(self):
        for group in self.param_groups:
            for p in group['params']:
                state = self.state.setdefault(p, {'m': 0, 'v': 0, 't': 0})
                state['t'] += 1
                g = p.grad.data
                state['m'] = self.betas[0]*state['m'] + (1-self.betas[0])*g
                state['v'] = self.betas[1]*state['v'] + (1-self.betas[1])*g**2
                m_hat = state['m'] / (1 - self.betas[0]**state['t'])
                v_hat = state['v'] / (1 - self.betas[1]**state['t'])
                p.data = p.data - group['lr'] * m_hat / (v_hat**0.5 + self.eps)
```

**关键细节**：
- `optimizer.step()` 改 `p.data`（绕过计算图），不触发 `requires_grad`
- `.grad` 是累加的 → `zero_grad()` 必须每轮调
- `state` 字典存动量 m/v，不同优化器的 state 不同
