# 爬虫工程链路

## 逻辑链

```
HTTP 请求 → HTML 解析 → 数据提取 → 反爬对抗 → 分布式调度
```

## 技术栈

```
requests/httpx(请求) → BeautifulSoup/lxml(解析) → XPath/CSS选择器(提取)
    → Scrapy(框架) → Crawlee(Python版) → Playwright(JS渲染)
    → 代理池 + 指纹伪装 + 验证码(反爬)
```
