# 文本表示演进链路

## 逻辑链

```
One-Hot(稀疏,无语义) → BoW/TF-IDF(统计特征) → N-gram(局部上下文)
    → 共现矩阵/PMI(全局统计) → SVD降维/LSA(稠密向量)
    → Word2Vec(浅层神经网络) → GloVe(统计+学习融合)
    → ELMo(上下文相关,双向LSTM) → BERT/GPT(Transformer时代)
```

## 核心演进逻辑

每一代升级都解决上一代的缺陷：

| 方法 | 解决的问题 | 遗留缺陷 |
|------|----------|---------|
| One-Hot | 数字表示 | 维度灾难，无语义 |
| TF-IDF | 词的重要性 | 词序丢失 |
| N-gram | 局部词序 | 维度爆炸，稀疏 |
| 共现矩阵→SVD | 全局统计 | 静态词向量 |
| Word2Vec/GloVe | 稠密语义 | 一词一义，无上下文 |
| ELMo | 上下文相关 | 仍是特征提取，非端到端 |
| BERT/GPT | 端到端预训练 | ~ |
