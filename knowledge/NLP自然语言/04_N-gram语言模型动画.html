语言模型核心：句子概率 = 各词的条件概率连乘。Bigram 近似：P(wi | wi-1)，只看前一个词。

数据稀疏问题：如果某个 N-gram 组合从未在训练语料中出现，其计数为 0，导致整句概率为 0！
训练语料（假设只有2句话）：
"我 爱 北京 天安门"
"天安门 上 太阳 升"
测试句子："我 爱 太阳"
💀 整句概率 = 0
"爱" → "太阳" 这个 Bigram 从未出现过 → 条件概率 = 0
一个为 0 → 整个连乘积为 0
即使其他词对完全合理，整句也被判定为"不可能"
拉普拉斯平滑（加一平滑）：每个 N-gram 计数加 1，分母加词表大小 |V|，确保所有概率 > 0。

❌ 原始 MLE（最大似然）

P(wj|wi) = C(wi,wj) / C(wi)
未见 N-gram → 概率直接为 0

✅ 拉普拉斯平滑（+1）

P(wj|wi) = (C(wi,wj)+1) / (C(wi)+|V|)
所有概率 > 0，不再为零 ✅
点击「展示平滑」查看计算过程
困惑度（Perplexity）：衡量语言模型对文本的"困惑程度"，越低越好。相当于模型平均对每个词有多少种选择。
公式：
PPL(W) = P(w₁w₂...wₙ)^(-1/N)
= 每个词概率的几何平均数的倒数
—
点击下方模型查看困惑度
如何理解困惑度？
PPL = 100 → 模型平均对每个词有 100 种"困惑"的选择
PPL = 20 → 平均只在 20 个词中选，模型更"有把握"
PPL = 1 → 完美预测每个词（实际不可能）
GPT-3 在 Penn Treebank 数据集上：PPL ≈ 20
Unigram 模型：PPL ≈ 1000+
