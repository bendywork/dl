② WordPiece 分词动画
BERT 使用 WordPiece 分词算法将词语拆分为子词（subword）。 这种方式能处理词表外（OOV）词汇，用 ## 前缀标识非词首子词。
WordPiece 分词过程
图例说明
词根（词首子词）
## 延续子词（非词首）
处理策略：
• 常见词 → 整词保留（如 cats → cats）
• 长词/罕见词 → 按字符频率拆分（如 unaffordable → un + ##afford + ##able）
• 未见词 → 逐字符切分（如 XQ9 → X + ##Q + ##9）
③ MLM — 遮蔽语言模型预训练
MLM 随机遮蔽输入 15% 的 token，让模型根据双向上下文预测被遮蔽的词。 被选中的 token 按 80/10/10 规则处理。
MLM 掩码策略演示
80% → 替换为 [MASK]
10% → 随机替换为其他词
10% → 保持不变

⑥ BERT vs GPT vs ELMo 对比
三种模型代表了预训练语言模型的三种架构思路。点击表格行高亮该模型，并在下方查看其注意力模式。
模型 架构 注意力方向 上下文 预训练任务 参数量
BERT Transformer Encoder 🔄 双向 完全双向 MLM + NSP 110M / 340M
GPT Transformer Decoder ➡️ 单向（左→右） 自回归（因果） LM（下一词预测） 117M / 345M
ELMo 双向 LSTM ↔️ 浅层双向 两个单向拼接 LM（双向各自） ~93M
点击上方表格行，查看注意力模式动画
核心差异解析
BERT： 用 Transformer Encoder + 双向注意力 Mask，同时看左右上下文。适合理解任务（分类、NER、QA）。
GPT： 用 Transformer Decoder + 因果 Mask，只能看左边。适合生成任务（文本生成、对话）。
ELMo： 用两个独立的单向 LSTM（一个正向、一个反向），再把表示拼接——这是"浅层"双向， 而 BERT 的双向是在每一层都能互相注意。
