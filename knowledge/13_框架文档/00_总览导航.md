# 深度学习知识逻辑链路 · 总览导航

> 目标：从宏观串联所有知识点，形成可自查的完整链路。
> 学习顺序：按文件编号顺序阅读，每个文件末尾有自查清单。

---

## 整体逻辑链路

```
数学 + Python 基础
        ↓
    机器学习核心
    （损失函数 / 梯度下降 / 模型评估）
        ↓
    深度学习基础
    （神经网络 / 反向传播 / 激活函数）
        ↓
    序列模型演进
    （RNN → LSTM/GRU → Seq2Seq）
        ↓
    注意力机制
    （Attention → Self-Attention → Multi-Head）
        ↓
    Transformer
    （Encoder / Decoder / 位置编码）
        ↓
    NLP 演进全景
    （词袋 → Word2Vec → ELMo → BERT → GPT）
```

## 如何使用

1. 每个文件末尾都有 **自查清单**，用 `[ ]` 标记
2. 能用自己的话解释清楚 → 打勾 `[x]`
3. 说不清楚 → 回到对应目录的代码/笔记复习
4. 所有清单打完勾 → 可以开始学 Transformer 代码实现
