torch.masked · 掩码 Tensor

torch.masked provides masked tensor semantics — operations respect a boolean mask, ignoring masked-out values. This is safer and more expressive than using NaN/sentinel values.

torch.masked 提供掩码 tensor 语义 —— 操作遵循布尔掩码，忽略被屏蔽的值。这比使用 NaN/哨兵值更安全且更富表现力。

x = torch.arange(1., 6.)
mask = torch.tensor([True, True, False, True, False])
mx = torch.masked.masked_tensor(x, mask)  # 只有 index 0,1,3 参与计算
mx.sum()  # 1+2+4=7.0 — 忽略位置 2,4

torch.nested · 嵌套 Tensor

torch.nested allows tensors where dimensions can vary per sample — e.g., a batch of sequences with different lengths without padding. More memory efficient than padded tensors.

torch.nested 允许维度按样本变化的 tensor —— 例如一批不同长度的序列无需 padding。比填充 tensor 更省内存。

nt = torch.nested.nested_tensor([
    torch.randn(3, 64),    # 3 tokens
    torch.randn(5, 64),    # 5 tokens (无需 padding!)
    torch.randn(2, 64),    # 2 tokens
])  # shape = nested_tensor(3,jagged,64)

Complex Numbers · 复数

PyTorch supports complex tensors with torch.complex64 and torch.complex128. Creation: torch.tensor(1+2j) or torch.view_as_complex(torch.stack([real, imag], dim=-1)). Most math ops support complex inputs.

PyTorch 支持复数 tensor（torch.complex64、torch.complex128）。创建：torch.tensor(1+2j) 或 torch.view_as_complex。大多数数学运算支持复数输入。
