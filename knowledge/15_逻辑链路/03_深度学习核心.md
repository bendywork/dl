# 深度学习核心自查

---

## 一、从机器学习到深度学习

```
机器学习：人工设计特征 → 模型学权重
深度学习：模型自动学特征 + 学权重（端到端）
```

深度学习的本质：**多层非线性变换，自动提取层次化特征。**

---

## 二、神经网络基本结构

```
输入层 → 隐藏层1 → 隐藏层2 → ... → 输出层

每一层做的事：
  输入 x
    ↓
  线性变换：z = W @ x + b
    ↓
  激活函数：a = f(z)
    ↓
  输出 a 作为下一层输入
```

**为什么需要激活函数：**
没有激活函数，多层线性变换等价于一层线性变换，深度没有意义。
激活函数引入非线性，让网络能拟合复杂函数。

---

## 三、激活函数自查

- [ ] **Sigmoid**：`1/(1+e^-x)`，输出(0,1)，存在梯度消失问题，现在主要用于二分类输出层
- [ ] **Tanh**：输出(-1,1)，比 Sigmoid 好但仍有梯度消失
- [ ] **ReLU**：`max(0,x)`，计算简单，缓解梯度消失，目前隐藏层默认选择
- [ ] **Softmax**：多分类输出层，把 logits 转为概率分布
- [ ] **梯度消失原因**：sigmoid/tanh 在饱和区导数趋近0，链式法则连乘后梯度消失

---

## 四、反向传播自查

- [ ] **前向传播**：输入 → 逐层计算 → 输出预测值和 loss
- [ ] **反向传播**：从 loss 出发，链式法则逐层求每个参数的梯度
- [ ] **链式法则**：`∂L/∂w = ∂L/∂y * ∂y/∂z * ∂z/∂w`，从后往前连乘
- [ ] **计算图**：PyTorch 在前向传播时自动构建，`loss.backward()` 沿计算图反向传播
- [ ] **梯度累积**：`loss.backward()` 是把梯度加到 `.grad` 上，必须先 `zero_grad()` 清零
- [ ] **梯度爆炸**：链路长时梯度连乘大于1的数，指数级增大，用梯度裁剪解决
- [ ] **梯度消失**：链路长时梯度连乘小于1的数，趋近0，用 LSTM/ReLU/残差连接缓解

## 五、PyTorch 训练流程自查

```python
# 标准训练循环
for epoch in range(num_epochs):
    for x, y in dataloader:          # 取一个 batch
        optimizer.zero_grad()         # 1. 清零梯度
        pred = model(x)               # 2. 前向传播
        loss = loss_fn(pred, y)       # 3. 计算损失
        loss.backward()               # 4. 反向传播，计算梯度
        optimizer.step()              # 5. 更新参数
```

## 六、常用层自查

- [ ] **nn.Linear(in, out)**：全连接层，`y = x @ W^T + b`，W shape 是 `[out, in]`
- [ ] **nn.Embedding(vocab, dim)**：词嵌入层，本质是一个查找表
- [ ] **nn.LSTM**：state 输出是元组 `(h_n, c_n)`，双向时第0维是 `num_layers * 2`
- [ ] **nn.Dropout(p)**：训练时随机置零，推理时关闭
- [ ] **nn.LayerNorm**：对每个样本的特征维度归一化，Transformer 中常用
- [ ] **nn.Sequential**：顺序容器，按顺序执行每个子模块
