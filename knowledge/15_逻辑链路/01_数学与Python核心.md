# 数学与 Python 核心自查

---

## 一、线性代数核心

### 为什么重要
神经网络的每一层本质都是矩阵乘法，理解 shape 变换必须依赖线代。

### 核心概念自查

- [ ] **向量**：一组数，有方向和大小，神经网络里每个样本/特征都是向量
- [ ] **矩阵乘法**：`[m,k] @ [k,n] = [m,n]`，k 必须相等，结果维度是外侧两个
- [ ] **转置**：行列互换，`W^T`，Linear 层计算是 `x @ W^T`
- [ ] **点积**：两个向量对应元素相乘再求和，结果是标量，Attention 里用来算相似度
- [ ] **矩阵的几何意义**：矩阵乘法 = 对向量做线性变换（旋转/缩放/投影）
- [ ] **内存视图**：高维张量在内存中是一维连续存储，shape 只是读取规则
- [ ] **reshape vs permute**：reshape 改切分规则，permute 改 stride，都不复制内存
- [ ] **contiguous**：显式调用才真正申请新内存重排数据

## 二、微积分核心

### 为什么重要
反向传播的本质就是链式求导，不懂导数就不懂梯度更新。

### 核心概念自查

- [ ] **导数**：函数在某点的斜率，表示该点函数值对输入的变化率
- [ ] **偏导数**：多变量函数对某一个变量求导，其他变量视为常数
- [ ] **链式法则**：`dy/dx = dy/du * du/dx`，复合函数求导，BP 的数学基础
- [ ] **梯度**：多变量函数所有偏导数组成的向量，指向函数值增长最快的方向
- [ ] **梯度下降**：沿梯度反方向更新参数，`w = w - lr * grad`
- [ ] **sigmoid 导数**：`σ'(x) = σ(x) * (1 - σ(x))`，代码里反复出现
- [ ] **tanh 导数**：`tanh'(x) = 1 - tanh²(x)`

## 三、概率与统计核心

### 为什么重要
损失函数、模型输出的概率分布、正则化都依赖概率统计。

### 核心概念自查

- [ ] **概率分布**：描述随机变量取各个值的可能性
- [ ] **softmax**：把一组数转换为概率分布，所有值加和为1，用于多分类输出层
- [ ] **交叉熵损失**：`L = -Σ y * log(ŷ)`，衡量预测分布和真实分布的差距
- [ ] **最大似然估计**：找让训练数据出现概率最大的参数，交叉熵最小化等价于最大似然
- [ ] **正态分布**：权重初始化常用，`torch.randn` 生成标准正态分布随机数
- [ ] **过拟合/欠拟合**：模型在训练集好但测试集差 vs 训练集也差

## 四、Python 核心自查

### 核心概念自查

- [ ] **列表推导式**：`[f(x) for x in lst if cond]`
- [ ] **zip/enumerate**：同时遍历多个序列 / 带索引遍历
- [ ] **\*args / \*\*kwargs**：可变位置参数 / 可变关键字参数
- [ ] **装饰器**：`@decorator`，函数包装，PyTorch 里 `@torch.no_grad()` 是装饰器
- [ ] **类与继承**：`nn.Module` 子类必须实现 `__init__` 和 `forward`
- [ ] **numpy 基础**：`ndarray`、广播机制、`reshape`、`axis` 参数含义
- [ ] **torch 张量**：与 numpy 的区别是支持 GPU 和自动求导
- [ ] **requires_grad**：设为 True 的张量会被 PyTorch 追踪计算图用于反向传播
