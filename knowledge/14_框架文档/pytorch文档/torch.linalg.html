torch.linalg · 线性代数

Common linear algebra operations on the last 1-2 dimensions with NumPy-like API.

在最后 1-2 维上执行常见线性代数操作，API 类似 NumPy。

torch.fft · 快速傅里叶变换

Discrete Fourier Transform functions. Supports real and complex FFT, IFFT, RFFT, IRFFT.

离散傅里叶变换函数。支持实数/复数 FFT、IFFT、RFFT、IRFFT。

x = torch.randn(1024)
X = torch.fft.fft(x)           # 1D FFT → complex tensor
x_rec = torch.fft.ifft(X)      # inverse FFT (recover original)

torch.signal · 信号处理

Signal processing window functions: windows.blackman(), windows.hamming(), windows.hann(), windows.kaiser(), windows.bartlett(). Used before FFT to reduce spectral leakage.

信号处理窗函数：windows.blackman()、windows.hamming()、windows.hann()、windows.kaiser()、windows.bartlett()。FFT 前使用以减少频谱泄漏。

torch.special · 特殊数学函数

Special math functions: entr(), erf(), erfc(), erfinv(), expit(), logit(), i0(), i0e(), i1(), i1e(), ndtr(), ndtri(), gammaln(), polygamma(), digamma(), psi(), zeta(), multigammaln(), softplus(), log_softmax().

特殊函数：误差函数 erf/erfc、逆误差函数 erfinv、sigmoid 的别名 expit、其逆 logit、Bessel 函数 i0/i1、高斯 CDF ndtr、其逆 ndtri、Gamma 对数 gammaln、digamma/polygamma 函数、Riemann zeta zeta 等。

torch.distributions · 概率分布

Probability distributions for stochastic policies and VAE reparameterization: Normal, Bernoulli, Categorical, Uniform, MultivariateNormal, OneHotCategorical, RelaxedBernoulli, Beta, Gamma, Dirichlet, Poisson. Each has .sample(), .log_prob(), .entropy() methods.

概率分布（用于随机策略和 VAE 重参数化）：Normal（正态）、Bernoulli（伯努利）、Categorical（类别）、Uniform（均匀）、MultivariateNormal（多元正态）、Beta/Gamma/Dirichlet/Poisson。每个分布有 .sample()（采样）、.log_prob()（对数概率）、.entropy()（熵）。

torch.func · 函数变换 (JAX 式 API)

Function transforms for per-sample gradients, vectorization, etc. torch.func.vmap(f)(x) auto-vectorizes f. torch.func.grad(f)(x) computes gradient. torch.func.vjp(f, x) computes vector-Jacobian product.

函数变换（JAX 式 API）：vmap(f)(x) 自动向量化、grad(f)(x) 计算梯度、vjp(f, x) 向量-雅可比乘积、jacrev/jacfwd 雅可比矩阵。

# vmap: batch gradient without for-loop
batch_grads = torch.func.vmap(torch.func.grad(loss_fn))(inputs)
