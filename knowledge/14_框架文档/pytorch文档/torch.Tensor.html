torch.Tensor — Tensor 类与内置方法

Overview · 概述

torch.Tensor is a multi-dimensional array with a single data type. There are 10+ tensor types for CPU (float32, float64, int32, int64, etc.) and GPU (CUDA) variants.

torch.Tensor 是具有单一数据类型的多维数组。有 10+ 种 CPU tensor 类型（float32、float64、int32、int64 等）和 GPU（CUDA）变体。

Construction · 构造

torch.Tensor(2, 3)           # 未初始化的 2x3 tensor
torch.tensor([1,2,3])        # 从 list 创建（常用）
torch.tensor([1,2,3], dtype=torch.float32, device='cuda')

Indexing · 索引

x[0, :]           # 第一行
x[:, 1:3]         # 第 1-2 列
x[..., None]      # 最后加一维
x[x > 0]          # 布尔索引
x[[0, 2, 3]]      # 整数数组索引

In-place Ops · 原地操作 (后缀 _)

x.add_(1)         # x += 1
x.mul_(2)         # x *= 2
x.zero_()         # x = 0

In-place ops save memory but are discouraged by autograd — they make gradient tracking harder.

原地操作节省内存但 autograd 不推荐 —— 它们使梯度追踪更困难。
