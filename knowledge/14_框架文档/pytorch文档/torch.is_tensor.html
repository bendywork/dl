torch.is_tensor — PyTorch 2.12

Signature · 签名

torch.is_tensor(obj, /)
torch.is_tensor(obj, /)

/ 表示 obj 是一个仅限位置参数（positional-only）。

Description · 描述

Returns True if obj is a PyTorch tensor.

如果 obj 是一个 PyTorch tensor，则返回 True。

Parameters · 参数

  • obj (object) — Object to test
  • obj（object）— 要检测的对象

Return Type · 返回类型

TypeIs[Tensor]

TypeIs[Tensor] — 类型守卫（type guard），用于类型窄化。如果返回 True，类型检查器将把 obj 视为 Tensor。

Example · 示例

>>> x = torch.tensor([1, 2, 3])
>>> torch.is_tensor(x)
True

创建一个 tensor 然后用 is_tensor 检测：

>>> x = torch.tensor([1, 2, 3])
>>> torch.is_tensor(x)
True
