torch — Tensor 创建、操作与数学函数

Overview · 概述

The torch package contains data structures for multi-dimensional tensors and defines mathematical operations over them. It provides tensor creation, indexing, slicing, joining, mutating, and math operations.

torch 包包含多维 tensor 的数据结构并定义了其上的数学运算。它提供 tensor 创建、索引、切片、拼接、变形和数学操作。

Indexing & Slicing · 索引与切片

Standard Python indexing/slicing, plus advanced: torch.index_select(), torch.masked_select(), torch.take(), torch.gather(), torch.scatter().

支持标准 Python 索引/切片，以及高级操作：index_select（按索引选取）、masked_select（按布尔掩码选取）、take（按展平索引取）、gather（沿指定轴按索引收集）、scatter（沿指定轴按索引写入）。
