torch.amp · 自动混合精度

Automatic Mixed Precision — use fp16/bf16 for compute, fp32 for critical ops, saving memory and boosting speed. with torch.amp.autocast('cuda'): output = model(input). Pair with GradScaler for fp16 stability.

自动混合精度 —— fp16/bf16 做计算，fp32 保存关键操作，节省显存并加速。with torch.amp.autocast('cuda'): 上下文触发自动精度切换。配合 GradScaler 解决 fp16 梯度下溢问题。

torch.profiler · 性能分析

Unified profiler for CPU/GPU. torch.profiler.profile(activities=[...]) captures trace. .key_averages().table() prints summary. Export to Chrome trace for visualization.

CPU/GPU 统一性能分析器。profile() 捕获追踪、.key_averages().table() 打印摘要、导出 Chrome trace 可视化。

torch.monitor · 系统监控

Monitor system metrics (CPU, GPU, memory) during training. TensorboardEventHandler integrates with TensorBoard.

训练期间监控系统指标（CPU、GPU、内存）。TensorboardEventHandler 与 TensorBoard 集成。

torch.overrides · 重载机制

__torch_function__ protocol — allows custom tensor-like objects to override PyTorch functions. Basis for libraries like functorch, masked tensors.

__torch_function__ 协议 —— 允许自定义 tensor 式对象重载 PyTorch 函数。functorch、masked tensors 等库的基础。

torch.futures · Future 对象

Asynchronous result placeholder. Used in distributed RPC and autograd engine.

异步结果占位符。用于分布式 RPC 和 autograd 引擎。

torch.testing · 测试工具

assert_close(actual, expected) for numerical comparison with tolerance. make_tensor() for generating test inputs.

assert_close（数值容差比较）、make_tensor（生成测试输入）。

nativert · 原生运行时

Native Runtime for executing models without Python overhead.

原生运行时，无需 Python 开销即可执行模型。

Quantization · 量化

torch.ao.quantization — int8 quantization for model compression and faster inference. PTQ (Post-Training) and QAT (Quantization-Aware Training) workflows.

torch.ao.quantization —— 模型 int8 量化（压缩 + 加速推理）。PTQ（训练后量化）和 QAT（量化感知训练）两种流程。

Type Info · 类型信息

torch.iinfo(type) — integer type limits (min, max, bits). torch.finfo(type) — float type info (eps, max, min, tiny). Useful for numerical stability checks.

torch.iinfo(type) 整数类型信息（min、max、bits）。torch.finfo(type) 浮点类型信息（eps、max、min、tiny）。数值稳定性检查必备。

Named Tensors · 命名张量

Assign names to tensor dimensions for readability and safety. tensor.refine_names('batch', 'channel', 'H', 'W'). Operations align by name instead of position.

为张量维度命名以提高可读性和安全性。操作按名称对齐而非位置。已合并到主分支但使用有限。

Config & Env Vars · 配置

torch.__config__: show build configuration (CUDA, MKL, cuDNN versions).
torch.__future__: enable/disable upcoming defaults.
torch._logging: control internal PyTorch log verbosity.
Environment Variables: TORCH_HOME (cache dir), TORCH_CUDA_ARCH_LIST (GPU arch), TORCHINDUCTOR_CACHE_DIR, TORCH_LOGS, TORCH_COMPILE_DEBUG — dozens of flags for controlling PyTorch behavior.

torch.__config__：显示构建配置（CUDA、MKL、cuDNN 版本）。
torch.__future__：启用/禁用未来默认行为。
torch._logging：控制 PyTorch 内部日志详细度。
环境变量：TORCH_HOME（缓存目录）、TORCH_CUDA_ARCH_LIST（GPU 架构）、TORCHINDUCTOR_CACHE_DIR（Inductor 缓存）、TORCH_LOGS（日志级别）、TORCH_COMPILE_DEBUG（编译调试）等数十个控制 PyTorch 行为的环境变量。
