表示 torch.Tensor 的数据类型。PyTorch 有 12 种不同的数据类型。

torch.device · 设备

Represents the device a Tensor is on. torch.device('cuda'), torch.device('cpu'), torch.device('mps').

表示 Tensor 所在的设备。torch.device('cuda')（GPU）、torch.device('cpu')（CPU）、torch.device('mps')（Apple 芯片）。

x = torch.tensor([1.0, 2.0], device='cuda:0')  # 第 0 块 GPU
x = x.to('cpu')                                 # 移回 CPU

torch.layout · 内存布局

Represents memory layout of a Tensor. torch.strided (default, dense), torch.sparse_coo (sparse COO), torch.sparse_csr (sparse CSR).

表示 Tensor 的内存布局：torch.strided（默认，稠密）、torch.sparse_coo（稀疏 COO 格式）、torch.sparse_csr（稀疏 CSR 格式）。
