Tensor Views — view, reshape, transpose 与内存共享

Core Concept · 核心概念

A view of a tensor shares the same underlying data. Modifying the view will change the original tensor. This is different from creating a copy.

tensor 的 view（视图）共享相同的底层数据。修改 view 会改变原始 tensor。这与创建 copy（副本）不同。

x = torch.randn(3, 4)
y = x.view(12)          # view: 共享数据
y[0] = 999
print(x[0,0])           # 999 — 原始也被改了！

z = x.clone()           # copy: 独立数据，修改 z 不影响 x

Contiguity Trap · 连续性陷阱

transpose() creates a non-contiguous view. Calling .view() on it will fail:

transpose() 产生非连续 view，在其上调用 .view() 会失败：

x = torch.randn(3, 4)
y = x.transpose(0, 1)    # [4, 3] — 非连续 view
# y.view(12)              # RuntimeError!
y.contiguous().view(12)   # 正确：先转连续再 view

.reshape() avoids this problem by falling back to a copy when needed. Safer for general use.

.reshape() 在必要时回退到复制，日常使用更安全。

Autograd Warning · 自动梯度警告

Warning: In-place modification of views can cause autograd errors. The autograd engine tracks tensor versions — if a tensor saved for backward is modified via a view, backward will raise an error.
警告：对 view 的原地修改可能导致 autograd 错误。autograd 引擎追踪 tensor 版本 —— 如果为 backward 保存的 tensor 通过 view 被修改，backward 将报错。
