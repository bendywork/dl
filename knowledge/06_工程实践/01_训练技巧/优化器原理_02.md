# 优化器原理：SGD → Adam → AdamW

## 📌 核心问题
> 为什么深度学习不用普通 SGD，Adam 解决了什么问题，AdamW 又为什么更好？

## 🌱 根源与动机

梯度下降的核心问题：
- **SGD**：学习率难设，不同参数需要不同步长，鞍点收敛慢
- **Momentum**：加速但震荡
- **AdaGrad**：自适应学习率，但学习率单调递减会过早停止
- **Adam**：一阶矩（动量）+ 二阶矩（自适应学习率），目前最常用

## 📐 理论推导

### Adam

```
m_t = β₁·m_{t-1} + (1-β₁)·g_t        ← 一阶矩（动量）
v_t = β₂·v_{t-1} + (1-β₂)·g_t²       ← 二阶矩（梯度方差）

m̂_t = m_t / (1-β₁ᵗ)                  ← 偏差修正
v̂_t = v_t / (1-β₂ᵗ)

θ_t = θ_{t-1} - α · m̂_t / (√v̂_t + ε)
```

默认超参：`β₁=0.9, β₂=0.999, ε=1e-8`

### AdamW（Adam + Weight Decay 解耦）

**问题**：Adam 中 L2 正则 = weight decay 的等价关系在自适应优化器中被破坏。

Adam 的 L2 正则实际上：
```
g_t' = g_t + λθ   → 进入 Adam 后被 v_t 缩放，实际 decay 力度不均匀
```

AdamW 的做法：**把 weight decay 从梯度中剥离，直接作用于权重**：
```
θ_t = θ_{t-1} - α · m̂_t / (√v̂_t + ε) - α·λ·θ_{t-1}
```

效果：每个参数以相同倍率衰减，正则化更均匀有效。

### 学习率调度（LR Schedule）

```
Warmup：前 N 步线性增加 LR（稳定训练初期）
Cosine Decay：LR 按余弦曲线降低
Linear Decay：线性降低
```

## 💡 关键理解

- **Adam 收敛快**，但泛化不如 SGD（尤其 CV 任务）
- **AdamW 是 LLM 训练标配**（LLaMA/BERT 都用 AdamW + Warmup + Cosine）
- **学习率是最重要的超参**：过大震荡，过小收敛慢；Warmup 帮助前期稳定
- **二阶矩记录历史梯度平方**，频繁更新的参数自动降低学习率（适合 sparse 梯度）

## ⚠️ 易错点与常见误解

1. **Adam ≠ AdamW**：PyTorch `Adam` 不等于 `AdamW`，微调 BERT/LLM 要用 `AdamW`
2. **ε 不要设太大**：ε 作用是防止除零，设太大相当于用 SGD
3. **β₁/β₂ 很少需要调**：几乎所有任务 `0.9/0.999` 就够
4. **Warmup 步数**：通常设为总步数的 5%~10%，不要太长
