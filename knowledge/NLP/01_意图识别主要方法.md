# 意图识别主要方法

## 📌 核心问题
> 意图识别解决的是：给定用户输入（通常是短文本/对话），判断用户想要做什么（属于哪个意图类别）。
> 本质是一个文本分类问题，但在对话系统/NLU中有其特殊性与NER紧密耦合。

## 🌱 根源与动机
对话系统的核心流程：ASR(语音转文字) → NLU(自然语言理解) → DM(对话管理) → NLG(自然语言生成) → TTS(文字转语音)

NLU层需要完成两个任务：
1. **意图识别(Intent Detection)**：用户想做什么？→ 分类问题
2. **槽位填充(Slot Filling/NER)**：关键实体是什么？→ 序列标注问题

两者天然耦合，共同定义了用户请求的完整语义。

例如："帮我订一张明天去北京的机票"
- 意图：订机票 (BookTicket)
- 槽位：时间=明天，目的地=北京

## 📐 理论推导

### 方法一：基于规则的方法

**关键词匹配**
- 维护意图-关键词词典，命中则判定
- 例：{"订票": ["订票","买票","预订"], "查天气": ["天气","气温"]}

**正则表达式/模板**
- 用正则定义句式模式
- 例：`帮我(订|买).*票` → 订票意图

**优缺点**：
- ✅ 简单直接，无需训练数据
- ❌ 无法泛化（"想飞北京"匹配不到"订票"），维护成本随意图数爆炸

### 方法二：传统机器学习方法

将意图识别转化为文本分类问题：
1. 特征提取：BOW / TF-IDF / n-gram / 手工特征（词性、句法）
2. 分类器：SVM / 朴素贝叶斯 / 最大熵模型 / 随机森林

**SVM（最经典）**
- 核心思想：在高维特征空间中找到最优分类超平面
- 对短文本分类效果良好，曾是工业界主流方案
- 特征：TF-IDF向量 + 词性特征 + 语义特征

**朴素贝叶斯**
- 核心思想：假设特征独立，用贝叶斯定理计算后验概率
- P(意图|文本) ∝ P(文本|意图) × P(意图)
- 速度快，适合意图数多的场景

**优缺点**：
- ✅ 可解释性强，推理快
- ❌ 特征工程繁琐，无法捕捉深层语义，对同义表达泛化差

### 方法三：深度学习方法

**TextCNN（2014, Kim）**
- 核心思想：用多种尺寸的1D卷积核提取n-gram特征，再max-pooling取最重要特征
- 结构：Embedding → Multi-filter Conv1D → Max-Pooling → FC → Softmax
- 优势：训练快，适合短文本
- 局限：丢失位置信息，无法理解长距离依赖

**BiLSTM + Attention**
- 核心思想：双向LSTM编码上下文，Attention聚焦关键词
- 结构：Embedding → BiLSTM → Attention → FC → Softmax
- Attention权重可解释：哪些词对意图判断最重要
- 优势：捕捉上下文和长距离依赖
- 局限：训练慢于CNN，需要更多数据

**Self-Attentive / 多头注意力**
- 用自注意力替代RNN，并行化程度高
- 为后续Transformer/BERT方案铺路

**优缺点**：
- ✅ 自动学习特征，端到端训练，语义理解能力强
- ❌ 需要大量标注数据，小数据集易过拟合

### 方法四：预训练语言模型方法

**BERT fine-tune（当前工业主流）**
- 核心思想：BERT在大语料上预训练获得语言理解能力，微调适配意图分类
- 做法：取[CLS]token的输出 → FC → Softmax
- 优势：少量标注数据即可达到很好效果（few-shot能力）
- 典型效果：几十到几百条样本即可超过传统方法数千条的效果

**BERT变体**
- RoBERTa：更大数据更长训练
- ALBERT：参数共享，轻量部署
- DistilBERT：知识蒸馏，推理加速
- ELECTRA：替换检测预训练，更高效

**优缺点**：
- ✅ 效果最优，少量数据即可微调
- ❌ 推理成本高，模型大，延迟高

### 方法五：联合学习方法（意图+槽位联合）

**为什么需要联合？**
- 意图和槽位共享语义信息，互相增强
- 例："去北京"中"北京"是槽位(目的地)，同时也暗示意图(出行/订票)
- 联合学习让两个任务共享底层表征，互相提供信号

**经典架构**
1. **BiLSTM + CRF（序列标注）+ Intent FC**：共享BiLSTM编码，CRF做槽位，FC做意图
2. **BERT + CRF**：BERT编码，CRF做槽位标注，[CLS]做意图分类
3. **Slot-Gated Model（2018）**：用槽位注意力门控意图表示，显式建模交互
4. **Joint BERT（2019）**：BERT联合微调，多任务损失 = L_intent + L_slot

**联合损失函数**
L = α·L_intent + β·L_slot
- α, β为超参数，平衡两个任务的权重
- 通常两任务互相促进，很少出现负迁移

**优缺点**：
- ✅ 两个任务互相增强，效果优于独立训练
- ❌ 模型更复杂，训练调参更困难

### 方法六：少样本/零样本方法

**Prompt-based Learning**
- 将分类任务转化为填空任务
- 例："这条信息的意图是[MASK]" → BERT预测[MASK]对应的意图词
- 优势：极大减少所需标注量

**LLM In-context Learning**
- 用GPT/Claude等大模型，给几个示例直接推理
- 优势：无需训练，快速适配新意图
- 局限：延迟高、成本高、输出可控性差

**优缺点**：
- ✅ 标注数据需求极低，灵活适配新意图
- ❌ 推理成本高，可控性和稳定性不足

## 💡 关键理解

1. **意图识别本质是分类，但与NER天然耦合**——实际系统中几乎不存在单独做意图识别的，都是联合模型
2. **方法演进逻辑**：规则(人工知识) → ML(手工特征+统计学习) → DL(自动特征+端到端) → PLM(预训练+微调) → 联合/少样本(更少数据更强效果)
3. **工业选择**：小数据快速上线用规则/ML；有标注数据用BERT fine-tune；追求极致效果用联合模型；快速适配新意图用Prompt/LLM
4. **关键瓶颈不是模型，是数据**——意图定义的一致性、标注质量、长尾意图处理，才是工程落地真正的难题

## 🔧 代码实现

```python
import torch
import torch.nn as nn
from transformers import BertModel, BertTokenizer

# ============ 方法1: TextCNN 意图识别 ============
class TextCNNForIntent(nn.Module):
    def __init__(self, vocab_size, embed_dim=128, num_filters=100,
                 filter_sizes=[2,3,4], num_intents=10, dropout=0.5):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        self.convs = nn.ModuleList([
            nn.Conv1d(embed_dim, num_filters, fs) for fs in filter_sizes
        ])
        self.dropout = nn.Dropout(dropout)
        self.fc = nn.Linear(num_filters * len(filter_sizes), num_intents)

    def forward(self, x):
        # x: [batch, seq_len]
        x = self.embedding(x)           # [batch, seq_len, embed_dim]
        x = x.permute(0, 2, 1)         # [batch, embed_dim, seq_len]
        x = [torch.relu(conv(x)) for conv in self.convs]  # 各卷积
        x = [torch.max(pool, dim=2)[0] for pool in x]     # max-pooling
        x = torch.cat(x, dim=1)        # [batch, num_filters * len(filter_sizes)]
        x = self.dropout(x)
        return self.fc(x)               # [batch, num_intents]

# ============ 方法2: BiLSTM + Attention 意图识别 ============
class BiLSTMAttentionForIntent(nn.Module):
    def __init__(self, vocab_size, embed_dim=128, hidden_dim=128,
                 num_intents=10, dropout=0.5):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        self.lstm = nn.LSTM(embed_dim, hidden_dim, batch_first=True,
                           bidirectional=True)
        self.attention = nn.Linear(hidden_dim * 2, 1)
        self.dropout = nn.Dropout(dropout)
        self.fc = nn.Linear(hidden_dim * 2, num_intents)

    def forward(self, x):
        # x: [batch, seq_len]
        x = self.embedding(x)                  # [batch, seq_len, embed_dim]
        lstm_out, _ = self.lstm(x)             # [batch, seq_len, hidden*2]
        attn_weights = torch.softmax(
            self.attention(lstm_out), dim=1     # [batch, seq_len, 1]
        )
        context = torch.sum(attn_weights * lstm_out, dim=1)  # [batch, hidden*2]
        context = self.dropout(context)
        return self.fc(context)                # [batch, num_intents]

# ============ 方法3: BERT fine-tune 意图识别（工业主流）============
class BertForIntent(nn.Module):
    def __init__(self, pretrained='bert-base-chinese', num_intents=10, dropout=0.1):
        super().__init__()
        self.bert = BertModel.from_pretrained(pretrained)
        self.dropout = nn.Dropout(dropout)
        self.fc = nn.Linear(self.bert.config.hidden_size, num_intents)

    def forward(self, input_ids, attention_mask):
        outputs = self.bert(input_ids=input_ids, attention_mask=attention_mask)
        cls_output = outputs.last_hidden_state[:, 0, :]  # [CLS] token
        cls_output = self.dropout(cls_output)
        return self.fc(cls_output)              # [batch, num_intents]

# ============ 使用示例 ============
if __name__ == "__main__":
    # BERT意图识别快速示例
    tokenizer = BertTokenizer.from_pretrained('bert-base-chinese')
    model = BertForIntent(num_intents=5)

    text = "帮我订一张去北京的机票"
    inputs = tokenizer(text, return_tensors='pt', padding=True, truncation=True)

    with torch.no_grad():
        logits = model(inputs['input_ids'], inputs['attention_mask'])
        intent_id = torch.argmax(logits, dim=1).item()

    intent_labels = ["订票", "查天气", "问路", "闲聊", "其他"]
    print(f"输入: {text}")
    print(f"预测意图: {intent_labels[intent_id]}")
```

## ⚠️ 易错点与常见误解

1. **混淆意图识别和情感分析**：意图是"用户想做什么"（动作），情感是"用户感受如何"（态度），两者目标完全不同
2. **认为意图识别可以独立于NER**：实际系统中意图和槽位必须联合建模，否则会丢失关键的语义信号
3. **忽视意图定义的歧义性**：同一句话可能有多个意图（"天冷了"→调温度？关窗？聊天？），需要对话上下文消歧
4. **过度依赖模型忽视数据质量**：意图定义不一致、标注噪声、长尾意图数据不足，这些才是工程落地最大瓶颈
5. **以为BERT一定比CNN好**：数据量小且意图简单时，TextCNN训练快推理快可能更合适；BERT的优势在小样本泛化能力
