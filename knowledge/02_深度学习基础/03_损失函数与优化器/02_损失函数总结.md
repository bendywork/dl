# 损失函数总结

## 📌 核心问题
> 模型如何"知道"自己错得有多离谱？——损失函数把"预测 vs 真值"的差距翻译成一个标量，
> 这个标量的梯度就是参数更新的方向。**选错损失函数 = 优化目标错了 = 再好的模型结构也救不回来。**

---

## 🌱 根源与动机

机器学习训练 = `θ* = argmin_θ E_(x,y)[L(f_θ(x), y)]`，其中 `L` 就是损失函数。它要满足：
- **可微**（或几乎处处可微）：才能求梯度反传；
- **凸性 / 良态**：让优化路径不至于陷在病态地方；
- **与任务目标对齐**：分类任务用回归损失 ≈ 拿尺子量体重；
- **对异常值鲁棒**：现实数据噪声大；
- **数值稳定**：`log(0)`、`exp(huge)` 是常见坑。

---

## 🗺️ 损失函数分类树

```
损失函数
├─ 回归类 (输出 ∈ ℝ)
│   ├─ MSE (L²)         — 高斯噪声 MLE，对异常值敏感
│   ├─ MAE (L¹)         — 拉普拉斯噪声 MLE，鲁棒但梯度恒定
│   ├─ Huber / Smooth L1 — MSE+MAE 折中
│   ├─ Log-Cosh         — 平滑版 MAE
│   └─ Quantile / Pinball — 分位数回归
│
├─ 分类类 (输出 ∈ 概率)
│   ├─ BCE              — 二分类 / 多标签
│   ├─ Softmax + CE     — 多分类（互斥）
│   ├─ NLL              — log-softmax 之后用
│   ├─ Hinge            — SVM
│   ├─ Focal Loss       — 解决类别极度不平衡
│   └─ Label Smoothing  — 防过拟合 / 抗噪
│
├─ 度量学习类
│   ├─ Contrastive      — 双塔 / Siamese
│   ├─ Triplet          — anchor / pos / neg
│   ├─ InfoNCE          — 对比学习 (SimCLR / CLIP)
│   └─ Center Loss      — 类内紧凑
│
├─ 目标检测 / 分割
│   ├─ IoU / GIoU / DIoU / CIoU — 框回归
│   ├─ Dice / Tversky    — 分割（前景占比小）
│   └─ Focal + L1        — 组合
│
└─ 生成 / 概率匹配
    ├─ KL 散度           — VAE
    ├─ JS 散度           — 原始 GAN
    ├─ Wasserstein       — WGAN
    ├─ 重建损失 (MSE/BCE) — autoencoder
    └─ 似然 / ELBO       — 概率模型
```

## 1. 回归类损失

### 1.1 MSE / L² Loss（均方误差）

$$
L_{MSE} = \frac{1}{N}\sum_{i=1}^{N}(y_i - \hat{y}_i)^2
$$

- **概率解读**：假设噪声 ε ~ N(0, σ²) 下，MLE 等价于最小化 MSE；
- **梯度**：`∂L/∂ŷ = 2(ŷ - y) / N`，**误差越大梯度越大**——大错误"重重惩罚"；
- **优点**：平滑、凸、解析解（线性回归正规方程）；
- **缺点**：对**异常值极度敏感**（平方放大），一个离群点能拽飞模型；
- **场景**：噪声近高斯、目标尺度稳定的回归（房价、温度）。

### 1.2 MAE / L¹ Loss（平均绝对误差）

$$
L_{MAE} = \frac{1}{N}\sum_{i=1}^{N}|y_i - \hat{y}_i|
$$

- **概率解读**：拉普拉斯噪声 MLE；
- **梯度**：`∂L/∂ŷ = ±1/N`，**梯度恒定**——对所有误差一视同仁，鲁棒抗异常值；
- **缺点**：0 点不可导（次梯度），最优点附近梯度不衰减，收敛末期"抖动"；
- **场景**：含异常值的数据，例如金融、传感器读数。

### 1.3 Huber Loss（MSE + MAE 折中）

$$
L_{\delta}(y, \hat{y}) = \begin{cases}
\tfrac{1}{2}(y - \hat{y})^2 & |y - \hat{y}| \le \delta \\
\delta(|y - \hat{y}| - \tfrac{1}{2}\delta) & \text{其他}
\end{cases}
$$

- 小误差像 MSE（平滑、好收敛），大误差像 MAE（抗噪）；
- δ 是切换阈值，常取 1.0；
- **PyTorch**：`nn.SmoothL1Loss`（δ=1 时等价于 Huber）；目标检测框回归的常客。

### 1.4 Log-Cosh / Quantile（补充）

- **Log-Cosh**：`log(cosh(y-ŷ))`，全局二阶可导的"平滑 MAE"；
- **Quantile Loss（Pinball）**：`L = max(τ(y-ŷ), (τ-1)(y-ŷ))`，τ∈(0,1) 控制分位数——做**预测区间**而非点估计的关键。

### 1.5 速查对照

| 损失 | 异常值敏感 | 0 点可导 | 梯度行为 | 典型场景 |
|---|---|---|---|---|
| MSE | ❌ 很敏感 | ✅ | 误差越大梯度越大 | 干净高斯噪声 |
| MAE | ✅ 鲁棒 | ❌ | 恒定 | 含离群点 |
| Huber | ✅ 鲁棒 | ✅ | 自适应 | 检测框回归 |
| Log-Cosh | ✅ 鲁棒 | ✅ (二阶也可导) | 平滑 | 二阶优化器友好 |

## 2. 分类类损失

> 详细信息论推导见同目录 [01_交叉熵损失函数详解.md](./01_交叉熵损失函数详解.md)。

### 2.1 BCE / Binary Cross-Entropy

$$
L_{BCE} = -\frac{1}{N}\sum_{i=1}^{N}\Big[y_i \log \hat{p}_i + (1-y_i)\log(1-\hat{p}_i)\Big]
$$

- 输出层接 **Sigmoid**，模型每个 logit 输出一个独立的"是 / 否"概率；
- 适用：**二分类**、**多标签**（每个标签彼此独立）；
- **PyTorch 选型**：
  - `nn.BCELoss`：输入要先 sigmoid（数值不稳）；
  - `nn.BCEWithLogitsLoss`：**首选**，内部 log-sum-exp，数值稳定；
- 多标签时无需 softmax——softmax 强制互斥，会错配语义。

### 2.2 Cross-Entropy / Softmax CE（多分类）

设有 C 类，模型输出 logits `z ∈ ℝᶜ`，softmax 后 `p_c = exp(z_c) / Σ_j exp(z_j)`：

$$
L_{CE} = -\sum_{c=1}^{C} y_c \log p_c
\xrightarrow{\text{one-hot}}
-\log p_{c^\star}
$$

- 仅惩罚"对正确类的预测概率"，最大化 `p_{y}`；
- 反传梯度极其干净：`∂L/∂z_c = p_c - y_c`——这是 softmax+CE 组合**梯度不爆炸 / 不消失**的核心；
- **PyTorch 选型**：
  - `nn.CrossEntropyLoss`：**输入 logits**（不要先 softmax），目标是类别 id（int），内部完成 log-softmax + NLL；
  - `nn.NLLLoss`：输入是 `log_softmax(z)`，配合 `F.log_softmax` 使用。

### 2.3 数值稳定：log-sum-exp 技巧

直接 `log(softmax(z))` 在大 logit 下会溢出，标准做法：

$$
\log\sum_j e^{z_j} = m + \log\sum_j e^{z_j - m},\quad m = \max_j z_j
$$

框架内部都这么做——所以**别手撸 softmax + log，用 `cross_entropy` / `log_softmax`**。

### 2.4 Hinge Loss（SVM 风格）

$$
L_{hinge} = \max(0,\ 1 - y \hat{y}),\quad y \in \{-1, +1\}
$$

- 只关心"分类正确且置信度够"——分类正确且 `y·ŷ ≥ 1` 时损失为 0；
- 不输出概率，得到的是**间隔（margin）**最大化解；
- 现代 DL 用得少，但**部分对比学习、ranking** 仍在用 hinge / margin-ranking。

### 2.5 BCE vs Softmax CE 选型

| 情形 | 选谁 |
|---|---|
| 二分类，输出单 logit | BCEWithLogits |
| K 类互斥（图像分类 ImageNet） | CrossEntropyLoss |
| K 类**非互斥**（多标签） | BCEWithLogits（每个 logit 独立） |
| 序列任务（Transformer LM） | CrossEntropyLoss + `ignore_index=pad` |

## 3. 改进分类损失

### 3.1 类别加权 CE（Weighted CE）

$$
L = -\sum_c w_c\, y_c \log p_c
$$

- `w_c` 与类频成反比，让稀有类的损失被放大；
- **PyTorch**：`nn.CrossEntropyLoss(weight=tensor([...]))`；
- 简单粗暴，**类别极度不平衡时第一步**。

### 3.2 Focal Loss（FAIR, RetinaNet）

$$
L_{focal} = -\alpha_t (1 - p_t)^{\gamma} \log p_t
$$

其中 `p_t = p`（正样本时）或 `1-p`（负样本时）。

- `(1-p_t)^γ` 是**调制因子**：模型已经预测对的样本（p_t→1）权重 → 0，模型预测不准（p_t 小）权重保持大；
- 直接结果：**几十万 easy 负样本不再淹没几百 hard 正样本**——目标检测的标配；
- 推荐 `γ=2, α=0.25`（论文设置）；
- 与 weighted CE 互补：α 解决"类别频率"，γ 解决"难易样本"。

### 3.3 Label Smoothing（标签平滑）

把硬标签 `[0, 0, 1, 0]` 替换为：

$$
y'_c = (1-\varepsilon)\,y_c + \frac{\varepsilon}{C}
$$

- 常见 `ε=0.1`；
- **效果**：
  - 防过拟合，让 logit 不会拉到 ±∞；
  - 模型校准更好（输出概率更接近真实置信度）；
  - 抗噪标签（标签错的时候模型不至于 100% 信）；
- **PyTorch ≥1.10**：`nn.CrossEntropyLoss(label_smoothing=0.1)`。

### 3.4 KL 散度（Distillation / Soft Target）

知识蒸馏：让学生模型的 softmax 输出去逼近老师模型的"软分布"：

$$
L_{KD} = T^2 \cdot KL\!\left(p^{teacher}_T\ \big\|\ p^{student}_T\right)
$$

- 温度 T 把分布"软化"（T=1 退化为正常 softmax，T 越大越软）；
- 软目标包含**类间相对相似度信息**（猫和虎的概率差距比猫和飞机小），信息量比硬标签大；
- 常组合 `L = α·KD + (1-α)·CE(hard)`。

### 3.5 Dice / Tversky Loss（分割）

$$
L_{Dice} = 1 - \frac{2|P \cap G|}{|P| + |G|}
$$

- 直接优化 IoU 类指标；前景占比极小（医疗影像）时优于 BCE；
- Tversky 是非对称版（α 加权 FP，β 加权 FN），可调召回 / 精确率偏好；
- 实战常 **Dice + BCE 加和**，互相弥补。

## 4. 度量学习 / 对比学习损失

### 4.1 Contrastive Loss（Siamese）

$$
L = y\cdot d^2 + (1-y)\cdot \max(0,\ m - d)^2
$$

- d 是两样本嵌入距离，m 是 margin；
- 同类（y=1）拉近，异类（y=0）推开到至少 m 远；
- 经典人脸验证。

### 4.2 Triplet Loss

$$
L = \max\!\big(0,\ d(a, p) - d(a, n) + m\big)
$$

- 锚 a、正样本 p、负样本 n；让 a 离 p 近、离 n 远 m 距离；
- **关键**：负样本要"够难"（hard / semi-hard mining），全用 easy 负样本会让 loss 永远是 0；
- 人脸识别 FaceNet 经典。

### 4.3 InfoNCE / NT-Xent（SimCLR、CLIP）

$$
L = -\log\frac{\exp(\text{sim}(q, k^+) / \tau)}{\sum_{k\in\{k^+, k^-_1, \ldots\}}\exp(\text{sim}(q, k)/\tau)}
$$

- 本质：**把"正负配对"当成 K 分类问题**，正样本是正确类，所有负样本是错误类；
- 温度 τ 控制分布锐利度，τ→0 偏置 hardest negative，τ→∞ 等权平均；
- 现代对比学习（SimCLR / MoCo / CLIP）的统一损失形式。

## 5. 目标检测 / 分割回归损失

### 5.1 IoU 系列（框回归）

$$
L_{IoU} = 1 - IoU(B_{pred}, B_{gt})
$$

直接优化检测指标，但 **两框不相交时梯度为 0**——这是改进方向：

| 损失 | 关键改进 | 用在 |
|---|---|---|
| GIoU | 加入"最小包围框"惩罚不相交情况 | YOLO v3 之后常见 |
| DIoU | 直接加入中心点距离 | YOLO v4 |
| CIoU | 中心距离 + 长宽比一致性 | YOLO v4/v5 |
| EIoU / SIoU | 进一步细化角度、边长 | YOLO v6/v7 |

> 现代 YOLO 通常 `分类(BCE/Focal) + obj(BCE) + 框(CIoU)` 三者加权求和。

### 5.2 Smooth L1（Faster R-CNN 时代）

见 §1.3，目标检测早期框回归的默认选择，现已大量被 IoU 系列替代。

## 6. 生成模型 / 概率匹配损失

### 6.1 KL 散度（VAE）

$$
KL(q\|p) = \sum_x q(x)\log\frac{q(x)}{p(x)}
$$

- **非对称**：`KL(q‖p) ≠ KL(p‖q)`；
- VAE 的 **ELBO** = `重建损失 - KL(q(z|x) ‖ p(z))`；
- 对正态后验有闭式解，是 VAE 训练能跑起来的核心。

### 6.2 JS 散度（原始 GAN）

$$
JS(p\|q) = \tfrac{1}{2}KL(p\|M) + \tfrac{1}{2}KL(q\|M),\ M = \tfrac{1}{2}(p+q)
$$

- 对称，有界；
- 但当 p、q 支撑不重叠时梯度消失 → 原始 GAN 训练不稳。

### 6.3 Wasserstein 距离（WGAN）

$$
W(p, q) = \inf_{\gamma}\mathbb{E}_{(x,y)\sim\gamma}\|x-y\|
$$

- 即使分布不重叠也提供有意义梯度；
- 实践用 **Kantorovich-Rubinstein 对偶** + 1-Lipschitz 约束（weight clipping / WGAN-GP）。

### 6.4 重建损失（Autoencoder）

- 像素回归 → MSE；
- 二值图像 / 概率图 → BCE；
- 图像感知质量 → **VGG 感知损失 / LPIPS**（在预训练特征空间算 L²）。

## 7. 选型决策树（实战版）

```
任务类型？
├─ 回归
│   ├─ 数据干净 ─────────────────→ MSE
│   ├─ 含异常值 ─────────────────→ Huber / MAE
│   └─ 需要预测区间 ──────────────→ Quantile
│
├─ 分类
│   ├─ 二分类 / 多标签 ──────────→ BCEWithLogitsLoss
│   ├─ 多分类（互斥） ───────────→ CrossEntropyLoss
│   │   ├─ 类别不平衡 → +class weights / Focal
│   │   ├─ 想抗过拟合 → +label_smoothing=0.1
│   │   └─ 知识蒸馏 → +KL(student‖teacher)
│   └─ 多分类（不互斥）─────────→ BCEWithLogitsLoss
│
├─ 检测
│   └─ 分类(Focal) + 框(CIoU) + obj(BCE)
│
├─ 分割
│   ├─ 平衡 ─────────────────→ BCE / CE
│   └─ 前景占比小 ────────────→ Dice + BCE
│
├─ 度量 / 对比学习
│   ├─ 双塔配对 ──────────────→ Contrastive
│   ├─ 三元组 ───────────────→ Triplet (+ hard mining)
│   └─ 自监督 ───────────────→ InfoNCE / NT-Xent
│
└─ 生成
    ├─ VAE ─────────────────→ 重建 + KL
    ├─ GAN ─────────────────→ BCE / Wasserstein
    └─ Diffusion ───────────→ MSE on noise (ε-prediction)
```

## 8. 数值稳定性与常见坑

### 8.1 千万别手撸 softmax + log

```python
# ❌ 不稳定
p = torch.softmax(logits, dim=-1)
loss = -torch.log(p[range(N), targets]).mean()

# ✅ 直接用
loss = F.cross_entropy(logits, targets)        # logits 输入
# 或
loss = F.binary_cross_entropy_with_logits(logits, targets)
```

### 8.2 log(0) → -inf

- 任何 `log(p)`、`log(1-p)` 都要保证 `p ∈ (0, 1)`，不能是闭区间；
- 实战要么直接用 `*_with_logits` 版本（内部已稳定），要么 clamp：`p = p.clamp(1e-7, 1-1e-7)`。

### 8.3 损失尺度 vs 学习率

- MSE 在归一化前后的损失差几个数量级，学习率往往也要相应调整；
- 多任务 loss 加权 `L = αL₁ + βL₂` 时，确保各项**量纲相近**，否则一项会"吃掉"另一项。

### 8.4 reduction 的坑

```python
loss = F.cross_entropy(logits, targets, reduction='mean')   # 默认
loss = F.cross_entropy(logits, targets, reduction='sum')    # 不除 N
loss = F.cross_entropy(logits, targets, reduction='none')   # 每样本一个值
```

- 多 GPU / 梯度累积时要警惕：`sum` 在不同 batch 大小下数值差异巨大；
- 自定义加权时常用 `reduction='none'` + 手动 `(loss * weights).mean()`。

### 8.5 ignore_index（序列任务必备）

```python
F.cross_entropy(logits, targets, ignore_index=PAD_ID)
```

让 padding 位置不参与 loss 计算和反传——Transformer / Seq2Seq 必加。

### 8.6 NaN / inf 排查清单

| 现象 | 可能原因 |
|---|---|
| 训练第一个 step 就 NaN | 学习率过大 / 初始化 / 输入未归一化 |
| 训到一半突然 NaN | log(0)、除 0、AMP 下溢、梯度爆炸 |
| Loss 不下降但不 NaN | 输出常数 / 数据有问题 / 损失不可导点 |

---

## ✅ 一句话总结

> **损失函数 = 优化目标的数学化身**。
> 回归用 MSE / Huber，分类用 CE / BCE，不平衡加 Focal，过拟合加 LabelSmoothing；
> 检测框用 CIoU，分割小目标用 Dice，对比学习用 InfoNCE。
> **永远用 `*_with_logits` 版本**，永远不要自己 `log(softmax(x))`。
