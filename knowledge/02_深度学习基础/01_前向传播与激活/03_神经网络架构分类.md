# 神经网络架构分类

## 📌 核心问题
> 神经网络不是只有全连接一种，不同结构解决不同类型的问题。理解架构分类是理解整个深度学习领域的地图。

## 🌱 根源与动机
全连接网络（MLP）是最基础的神经网络，但它有三个根本局限：
1. **参数爆炸**：全连接意味着每个神经元和上一层所有神经元相连，输入稍大参数就指数增长
2. **没有记忆**：前馈结构，处理完一个输入就"忘了"，无法处理序列
3. **没有局部/结构先验**：图像有空间结构、文本有顺序结构，全连接全部拉平，丢失了这些信息

不同的架构就是为了解决这些局限而诞生的。

## 📐 理论推导

### 一、前馈网络（Feedforward Networks）

**核心特征**：数据从输入到输出单方向流动，没有回路，没有记忆

#### 1.1 全连接网络（MLP / Fully Connected Network）

```
输入层 → 隐藏层1 → 隐藏层2 → ... → 输出层
每层每个神经元与上一层所有神经元相连
```

- 结构：y = σ(Wx + b)，每个连接一个权重
- 用途：分类、回归的基础模型；作为其他架构的组件（分类头）
- 优点：通用近似定理——足够宽/深可以拟合任何函数
- 缺点：参数量大、无空间/序列先验、容易过拟合

**关键理解**：全连接是最"笨"的网络——它不假设数据有任何结构，全靠数据自己学。所以它无处不在（作为分类头、输出层），但很少单独作为完整模型。

#### 1.2 卷积神经网络（CNN / Convolutional Neural Network）

```
输入 → [Conv → Pool]×N → FC → 输出
```

- 核心思想：**局部连接 + 权值共享**
  - 局部连接：每个神经元只看一个小窗口（感受野），不是全图
  - 权值共享：同一个卷积核扫遍全图，参数量骤降
- 用途：图像分类、目标检测、文本分类（TextCNN）
- 优点：参数少、捕捉局部模式、平移不变性
- 缺点：感受野有限（深层可扩大）、对全局关系建模弱

**关键理解**：CNN假设"重要的模式会出现在局部区域，且在不同位置长得一样"——这对图像天然成立（边缘、纹理、物体部件），对短文本也成立（n-gram特征）。

### 二、循环网络（Recurrent Networks）

**核心特征**：有时间维度的连接，当前状态依赖之前状态——**有记忆**

#### 2.1 基础RNN

```
ht = f(Wx·xt + Wh·ht-1 + b)
```

- 结构：每个时间步接收当前输入xt和上一时刻隐状态ht-1
- 用途：序列标注、文本分类、时序预测
- 缺点：梯度消失/爆炸，长距离依赖捕捉能力差

#### 2.2 LSTM（Long Short-Term Memory）

```
ft = σ(Wf·[ht-1, xt] + bf)   遗忘门：忘掉多少旧信息
it = σ(Wi·[ht-1, xt] + bi)   输入门：写入多少新信息
ot = σ(Wo·[ht-1, xt] + bo)   输出门：输出多少信息
```

- 核心思想：用门控机制控制信息流动，选择性记忆和遗忘
- 用途：序列标注(NER)、意图识别、机器翻译、时序预测
- 优点：缓解梯度消失，能捕捉较长距离依赖
- 缺点：串行计算，训练慢；仍不如Transformer捕捉超长依赖

#### 2.3 GRU（Gated Recurrent Unit）

- LSTM的简化版：合并遗忘门和输入门为更新门，参数更少
- 效果多数场景接近LSTM，训练更快

**关键理解**：RNN/LSTM/GRU的本质区别是"怎么管理记忆"：
- RNN：无选择性，所有信息混在一起传递
- LSTM：精细门控，选择记什么、忘什么、输出什么
- GRU：LSTM的简化取舍，够用就好

**RNN为什么能做序列标注？** 因为每个时间步都输出一个隐状态ht，每个ht接一个FC+Softmax就得到该位置的标签——输入多长输出就多长，一一对应。意图识别只取最后一个ht（或[CLS]），序列标注每个ht都用。

### 三、自编码网络（Autoencoder Networks）

**核心特征**：无监督学习，目标是"输出还原输入"，瓶颈层学到压缩表示

#### 3.1 基础自编码器（Autoencoder）

```
输入 → 编码器(降维) → 瓶颈层(z) → 解码器(还原) → 输出
损失 = ||输入 - 输出||²
```

- 核心思想：如果能用很少的维度还原原始数据，说明瓶颈层z学到了数据最本质的特征
- 用途：降维、特征提取、去噪、异常检测
- 优点：不需要标签，无监督
- 缺点：学到的表示可能无意义（只是记住了输入）

#### 3.2 变分自编码器（VAE / Variational Autoencoder）

- 核心改进：瓶颈层不是学一个确定的向量，而是学一个分布（均值+方差）
- z从分布中采样 → 解码器还原
- 损失 = 重建损失 + KL散度（让学到的分布接近标准正态）
- 用途：图像生成、数据增强、半监督学习
- 优点：可以生成新样本，表示空间有结构
- 缺点：生成质量不如GAN/Diffusion

#### 3.3 去噪自编码器（Denoising AE）

- 输入加噪声 → 编码器 → 解码器 → 还原干净输入
- 强迫模型学到鲁棒的特征表示

**关键理解**：自编码器的哲学是"能压缩就能理解"——如果你能用很少的信息还原原始数据，说明你抓住了本质。这和PCA的思想一脉相承，但非线性、更强大。

### 四、注意力与Transformer网络

**核心特征**：不用循环，用注意力机制直接建模任意两个位置的关系

#### 4.1 Self-Attention / Transformer

```
Attention(Q, K, V) = softmax(QK^T / √d) · V
```

- 核心思想：每个位置同时和所有位置计算相关性（注意力权重），加权聚合信息
- 多头注意力：多组QKV并行计算，捕捉不同类型的关系
- 位置编码：注入顺序信息（因为注意力本身没有位置概念）
- 用途：NLU、NLG、CV（ViT）、多模态、语音
- 优点：并行计算（训练快）、全局建模（任意距离直接连接）
- 缺点：O(n²)复杂度（序列长时计算量大）

#### 4.2 BERT（预训练 + 微调）

- Encoder-only Transformer
- 预训练任务：MLM(掩码语言模型) + NSP(下一句预测)
- 微调：加分类头，少量数据即可适配下游任务
- 用途：文本分类、NER、问答、意图识别

#### 4.3 GPT（自回归生成）

- Decoder-only Transformer
- 预训练任务：预测下一个token
- 用途：文本生成、对话、代码生成、推理

**关键理解**：Transformer的核心突破是"取消循环，用注意力直接连接所有位置"——RNN必须一步一步传递信息（信息走n步），Transformer一步到位（任意两个位置直接交互）。代价是计算量随序列长度平方增长。

### 五、生成网络

**核心特征**：目标是生成逼真的新样本，不是分类或回归

#### 5.1 GAN（Generative Adversarial Network）

```
生成器G：噪声z → 假图片
判别器D：图片 → 真/假
训练：G尽量骗过D，D尽量识破G → 纳什均衡
```

- 用途：图像生成、超分辨率、风格迁移、数据增强
- 优点：生成质量高
- 缺点：训练不稳定（模式崩塌）、没有显式概率模型

#### 5.2 扩散模型（Diffusion Model）

```
前向：原图 → 逐步加噪声 → 纯噪声
反向：纯噪声 → 逐步去噪 → 还原图
```

- 核心思想：学习反向去噪过程，从噪声生成图像
- 用途：图像生成（Stable Diffusion、DALL-E、Midjourney）
- 优点：训练稳定、生成质量极高、可控性强
- 缺点：采样慢（需多步去噪）、计算成本高

**关键理解**：GAN是"对抗博弈"学生成，Diffusion是"学会去噪"来生成。Diffusion取代GAN成为主流，不是因为理论更优美，而是训练更稳定、可控性更强。

### 六、图神经网络（GNN）

**核心特征**：数据是图结构（节点+边），不是网格或序列

```
每个节点：聚合邻居信息 → 更新自身表示 → 重复多层
```

- 核心思想：节点表示 = 聚合邻居表示（消息传递）
- 变体：GCN、GAT、GraphSAGE、GIN
- 用途：社交网络分析、分子性质预测、推荐系统、知识图谱
- 优点：天然处理非欧结构数据
- 缺点：过平滑问题（层数多了所有节点表示趋同）

## 💡 关键理解

1. **所有架构都是在全连接基础上加了某种先验/约束**：CNN加了局部性和权值共享、RNN加了时间连接、Transformer加了全局注意力、GNN加了图结构。全连接是最通用的但也是最低效的。

2. **不同架构不是互相替代，而是各有所长**：CNN擅长局部模式、RNN擅长序列记忆、Transformer擅长全局关系、Autoencoder擅长特征压缩、GAN/Diffusion擅长生成。实际系统经常组合使用。

3. **架构的演进逻辑**：MLP(万能但笨拙) → CNN/RNN(加入领域先验) → Transformer(通用且高效) → 各种变体(针对特定问题优化)

4. **组件复用**：FC层无处不在——CNN最后接FC分类、RNN每步接FC输出、Transformer的FFN也是FC、Autoencoder的编解码器也是FC。全连接不是一种"网络"，而是一种"基本组件"。

5. **监督 vs 无监督**：MLP/CNN/RNN/Transformer通常做监督学习（有标签）；Autoencoder/VAE做无监督学习（无标签）；GAN是半监督的博弈训练；Diffusion的无监督去噪训练。

## 🔧 代码实现

```python
import torch
import torch.nn as nn

# ============ 1. 全连接网络 (MLP) ============
class MLP(nn.Module):
    def __init__(self, input_dim, hidden_dim, output_dim):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(input_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, output_dim)
        )
    def forward(self, x):
        return self.net(x)  # [batch, output_dim]

# ============ 2. CNN ============
class SimpleCNN(nn.Module):
    def __init__(self, num_classes=10):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(1, 32, 3, padding=1),  # 局部连接 + 权值共享
            nn.ReLU(),
            nn.MaxPool2d(2),
            nn.Conv2d(32, 64, 3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2)
        )
        self.classifier = nn.Linear(64 * 7 * 7, num_classes)  # 最后还是FC
    def forward(self, x):
        x = self.features(x)
        x = x.view(x.size(0), -1)
        return self.classifier(x)

# ============ 3. RNN (序列标注) ============
class RNNForTagging(nn.Module):
    def __init__(self, vocab_size, embed_dim, hidden_dim, num_tags):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        self.rnn = nn.LSTM(embed_dim, hidden_dim, batch_first=True, bidirectional=True)
        self.fc = nn.Linear(hidden_dim * 2, num_tags)  # 每个时间步都接FC
    def forward(self, x):
        x = self.embedding(x)           # [batch, seq_len, embed_dim]
        x, _ = self.rnn(x)             # [batch, seq_len, hidden*2]
        return self.fc(x)              # [batch, seq_len, num_tags] 每个位置都有输出

# ============ 4. 自编码器 ============
class Autoencoder(nn.Module):
    def __init__(self, input_dim, latent_dim):
        super().__init__()
        self.encoder = nn.Sequential(
            nn.Linear(input_dim, 256), nn.ReLU(),
            nn.Linear(256, latent_dim)  # 瓶颈层 — 压缩表示
        )
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, 256), nn.ReLU(),
            nn.Linear(256, input_dim)   # 还原输入
        )
    def forward(self, x):
        z = self.encoder(x)      # 压缩
        x_recon = self.decoder(z) # 还原
        return x_recon, z

# ============ 5. Transformer (简化版) ============
class SimpleTransformer(nn.Module):
    def __init__(self, d_model=128, nhead=4, num_layers=2, num_classes=10):
        super().__init__()
        self.pos_encoding = nn.Parameter(torch.randn(1, 512, d_model) * 0.1)
        encoder_layer = nn.TransformerEncoderLayer(d_model, nhead, d_model*4, batch_first=True)
        self.transformer = nn.TransformerEncoder(encoder_layer, num_layers)
        self.fc = nn.Linear(d_model, num_classes)  # 还是FC做分类头
    def forward(self, x):
        seq_len = x.size(1)
        x = x + self.pos_encoding[:, :seq_len, :]  # 加位置编码
        x = self.transformer(x)
        x = x.mean(dim=1)  # 全局池化
        return self.fc(x)

# ============ 演示各架构的输入输出差异 ============
if __name__ == "__main__":
    batch = 4

    # MLP: 任意向量 → 分类
    mlp = MLP(input_dim=784, hidden_dim=256, output_dim=10)
    x_flat = torch.randn(batch, 784)
    print(f"MLP:        输入{x_flat.shape} → 输出{mlp(x_flat).shape}")

    # CNN: 图像 → 分类
    cnn = SimpleCNN(num_classes=10)
    x_img = torch.randn(batch, 1, 28, 28)
    print(f"CNN:        输入{x_img.shape} → 输出{cnn(x_img).shape}")

    # RNN: 序列 → 每个位置分类(序列标注)
    rnn = RNNForTagging(vocab_size=5000, embed_dim=64, hidden_dim=128, num_tags=5)
    x_seq = torch.randint(0, 5000, (batch, 20))
    print(f"RNN(序列标注): 输入{x_seq.shape} → 输出{rnn(x_seq).shape}")

    # Autoencoder: 向量 → 压缩 → 还原
    ae = Autoencoder(input_dim=784, latent_dim=32)
    x_ae = torch.randn(batch, 784)
    recon, z = ae(x_ae)
    print(f"Autoencoder: 输入{x_ae.shape} → 瓶颈{z.shape} → 还原{recon.shape}")

    # Transformer: 序列 → 分类
    tf = SimpleTransformer(d_model=64, nhead=4, num_layers=2, num_classes=10)
    x_tf = torch.randn(batch, 15, 64)
    print(f"Transformer: 输入{x_tf.shape} → 输出{tf(x_tf).shape}")
```

## ⚠️ 易错点与常见误解

1. **"RNN/LSTM就是全连接网络"**：内部确实用全连接层，但跨时间步有循环连接(h_{t-1}→h_t)，这是本质区别。没有循环连接就不是RNN
2. **"CNN只能处理图像"**：TextCNN用1D卷积处理文本，GraphCNN处理图结构——CNN的核心是"局部连接+权值共享"，不限于2D图像
3. **"自编码器没用，输出等于输入"**：价值在瓶颈层z——它能用很少的维度还原输入，说明学到了数据的本质特征，用于降维/特征提取/异常检测
4. **"Transformer完全取代了RNN"**：在大多数NLP任务确实如此，但在流式处理（必须逐步处理不能等全部输入）、资源受限场景（嵌入式设备），RNN/LSTM仍有优势
5. **"全连接层是一种网络"**：更准确说FC是一种"组件"，几乎所有网络最后都接FC做分类/回归。它是最基本的积木，不是一种独立的架构范式
