# 为什么每层线性变换后需要激活函数

## 📌 核心问题
> BP网络中，为什么每一层线性变换（Wx+b）之后都要接一个sigmoid，而不是只在最后一层加？

## 🌱 根源与动机

如果没有激活函数，多层线性网络会**塌缩成一层**。

数学证明：

```
第一层: h = W1·x + b1
第二层: y = W2·h + b2 = W2·(W1·x + b1) + b2 = (W2·W1)·x + (W2·b1 + b2)
                                                      ↑
                                              这还是 W'·x + b'
                                              等价于一个线性层！
```

不管堆多少层纯线性变换，最终等价于**一个线性变换**。深度网络就失去了意义。

同样道理——如果只在最后一层加sigmoid，中间层全是线性的，它们会合并成一个线性变换，等价于没有隐藏层。

## 📐 理论推导

### sigmoid的三重作用

**1. 引入非线性（根本原因）**

线性变换只能拟合线性关系。加了sigmoid后：
```
h = σ(W·x + b)
```
每个神经元变成一个非线性映射，多层堆叠后可以拟合任意复杂函数（通用近似定理）。

没有非线性激活 → 多层=一层 → 永远只能拟合线性函数（连XOR都学不了）。

**2. 压缩输出到(0,1)**

```
σ(z) = 1 / (1 + e^(-z))
```
- 当 z → +∞，σ(z) → 1
- 当 z → -∞，σ(z) → 0
- 当 z = 0，σ(z) = 0.5

隐藏层输出被约束在有限范围，数值稳定，不会爆炸。

**3. 处处可导（BP的前提）**

sigmoid的导数有一个优美性质：
```
σ'(z) = σ(z) · (1 - σ(z))
```
BP反向传播需要链式求导，sigmoid导数恰好可以用自身输出表示，计算高效。

代码中的体现（04.BP过程推导与理解.py 第93行）：
```python
gd_net_o1 = (out_o1 - y(1)) * out_o1 * (1 - out_o1)
#                         ↑ 这里就是 σ'(z) = σ(z)(1-σ(z))
```

### 对应代码结构

```python
# 每一层都是：线性变换 → sigmoid激活
net_h1 = w(1) * x(1) + w(2) * x(2) + b(1)   # 线性变换
out_h1 = sigmoid(net_h1)                       # 非线性激活

net_o1 = out_h1 * w(7) + out_h2 * w(9) + b(2) # 线性变换
out_o1 = sigmoid(net_o1)                        # 非线性激活
```

如果去掉隐藏层的sigmoid，只剩下：
```
net_h1 = W·x + b       (线性)
net_o1 = W'·net_h + b' (线性) → 等价于 W''·x + b''
out_o1 = sigmoid(net_o1) (仅最后一层有非线性)
```
整个网络退化为：sigmoid(W''·x + b'')，跟没有隐藏层一样。

## 💡 关键理解

类比：线性变换像"旋转+缩放+平移"，不管做多少次旋转缩放，结果还是旋转缩放。sigmoid像"弯曲折叠"，每做一次线性变换后弯曲一次，空间就被扭曲一次，多次扭曲后就能逼近任意形状。

一句话：**线性是"平的"，激活函数让空间"弯起来"，弯得越多，能表达的形状越复杂。**

## ⚠️ 易错点与常见误解

1. **"现代网络还用sigmoid吗？"** — 隐藏层基本不用了，主流是ReLU（max(0, x)）。sigmoid有**梯度消失问题**：当输出接近0或1时，σ'(z) = σ(z)(1-σ(z)) 接近0，梯度传不动。ReLU没有这个问题（正区间导数恒为1）。

2. **"为什么输出层也加sigmoid？"** — 因为目标值y在(0,1)范围内，sigmoid把输出映射到同样范围，配合MSE损失才能合理优化。如果y的范围不在(0,1)，输出层就该换别的激活或不用激活。

3. **"激活函数必须是非线性的吗？"** — 是的。线性激活函数（如h(z)=2z）本质上还是线性的，起不到引入非线性的作用。

4. **"sigmoid和softmax什么关系？"** — sigmoid是二分类输出层的激活，softmax是多分类输出层的推广。隐藏层激活则首选ReLU。

## 🔗 知识延伸

- 通用近似定理：单隐藏层+非线性激活可以逼近任意连续函数
- ReLU及其变体（LeakyReLU、GELU）：解决梯度消失的现代激活函数
- 梯度消失/梯度爆炸：深层网络反向传播中梯度逐层衰减或放大的问题
- 残差连接（ResNet）：另一种缓解梯度消失的方案
