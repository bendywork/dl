# 05_BP梯度推导详解

## 📌 核心问题
> BP反向传播中，每个权重的梯度是怎么一步步算出来的？为什么代码里有的梯度长有的梯度短？

## 🌱 根源与动机

BP的本质是链式法则——从损失函数出发，沿着网络反向，逐层求偏导，得到每个权重的梯度。梯度告诉这个权重"往哪调能让损失变小"。

## 📐 网络结构

```
        w1        w7
x(1) ──────→ h1 ──────→ o1
        w2   ↓   w8
x(2) ──────→    ──────→ o2

        w3        w9
x(1) ──────→ h2 ──────→ o1
        w4   ↓   w10
x(2) ──────→    ──────→ o2

        w5        w11
x(1) ──────→ h3 ──────→ o1
        w6   ↓   w12
x(2) ──────→    ──────→ o2
```

前向计算：
```python
# 隐藏层
net_h1 = w1*x(1) + w2*x(2) + b1
out_h1 = sigmoid(net_h1)
# ... h2, h3 同理

# 输出层
net_o1 = out_h1*w7 + out_h2*w9 + out_h3*w11 + b2
out_o1 = sigmoid(net_o1)
# ... o2 同理

# 损失
loss = 0.5*(out_o1 - y1)^2 + 0.5*(out_o2 - y2)^2
```

## 📐 输出层权重梯度（以w7为例）

w7 只在 h1→o1 这一条路径上，链式法则三步连乘：

```
dL/dw7 = dL/d_out_o1 × d_out_o1/d_net_o1 × d_net_o1/dw7
```

**第一步：损失对输出的导数**
```
loss1 = 0.5 * (out_o1 - y1)^2
dL/d_out_o1 = out_o1 - y1
```

**第二步：输出对净输入的导数（sigmoid导数）**
```
out_o1 = sigmoid(net_o1)
d_out_o1/d_net_o1 = out_o1 * (1 - out_o1)
```

**第三步：净输入对w7的导数**
```
net_o1 = out_h1*w7 + out_h2*w9 + out_h3*w11 + b2
d_net_o1/dw7 = out_h1     ← 其余项对w7求导都是0
```

**合起来：**
```
dL/dw7 = (out_o1 - y1) × out_o1*(1-out_o1) × out_h1
```

### 严谨写法 vs 原代码写法

原代码直接把三步揉成一个表达式：
```python
gd_net_o1 = (out_o1 - y(1)) * out_o1 * (1 - out_o1)
```
看不出每步求的是什么，初学者容易迷糊。

**严谨写法应拆开每步：**
```python
# 第一步：损失对输出的导数
d_loss_d_out_o1 = out_o1 - y(1)

# 第二步：输出对净输入的导数（sigmoid导数）
d_out_o1_d_net_o1 = out_o1 * (1 - out_o1)

# 第三步：链式相乘得到净输入的梯度
gd_net_o1 = d_loss_d_out_o1 * d_out_o1_d_net_o1

# 第四步：乘以输入，得到w7的梯度
gd_w7 = gd_net_o1 * out_h1
```

这样每步对应链式法则的一环，逻辑清晰。

同理，w8~w12 的梯度：
```python
gd_w7  = gd_net_o1 * out_h1   # h1→o1
gd_w8  = gd_net_o2 * out_h1   # h1→o2
gd_w9  = gd_net_o1 * out_h2   # h2→o1
gd_w10 = gd_net_o2 * out_h2   # h2→o2
gd_w11 = gd_net_o1 * out_h3   # h3→o1
gd_w12 = gd_net_o2 * out_h3   # h3→o2
```

规律：**输出层权重梯度 = 上游梯度 × 本层输入**，一对一，不分支。

## 📐 隐藏层权重梯度（以w1为例）

w1 在 h1 的路径上，而 h1 同时影响 o1 和 o2，**两条路的梯度要汇合**：

```
dL/dw1 = dL/d_out_h1 × d_out_h1/d_net_h1 × d_net_h1/dw1
```

**难点在第一步：dL/d_out_h1 怎么求？**

h1 通过 w7 影响 o1，通过 w8 影响 o2，两条路都要算：

```
dL/d_out_h1 = dL/d_net_o1 × d_net_o1/d_out_h1  +  dL/d_net_o2 × d_net_o2/d_out_h1
            = gd_net_o1  ×  w(7)                +  gd_net_o2  ×  w(8)
              ↑ o1那路                               ↑ o2那路
```

因为 `net_o1 = out_h1*w7 + ...`，对 out_h1 求导就是 w(7)。同理 o2 那路对 out_h1 求导是 w(8)。

**第二步和第三步：**
```
d_out_h1/d_net_h1 = out_h1 * (1 - out_h1)   # sigmoid导数
d_net_h1/dw1 = x(1)                          # net_h1 = w1*x(1) + w2*x(2) + b1
```

**合起来：**
```
dL/dw1 = (gd_net_o1*w(7) + gd_net_o2*w(8)) × out_h1*(1-out_h1) × x(1)
```

### 严谨写法

```python
# 第一步：损失对隐藏层输出的导数（两条路汇合）
d_loss_d_out_h1 = gd_net_o1 * w(7) + gd_net_o2 * w(8)

# 第二步：隐藏层输出对净输入的导数（sigmoid导数）
d_out_h1_d_net_h1 = out_h1 * (1 - out_h1)

# 第三步：净输入对w1的导数
d_net_h1_d_w1 = x(1)

# 第四步：链式相乘
gd_w1 = d_loss_d_out_h1 * d_out_h1_d_net_h1 * d_net_h1_d_w1
```

同理 w2~w6：
```python
gd_w2 = (gd_net_o1*w(7) + gd_net_o2*w(8)) * out_h1*(1-out_h1) * x(2)
gd_w3 = (gd_net_o1*w(9) + gd_net_o2*w(10)) * out_h2*(1-out_h2) * x(1)
gd_w4 = (gd_net_o1*w(9) + gd_net_o2*w(10)) * out_h2*(1-out_h2) * x(2)
gd_w5 = (gd_net_o1*w(11) + gd_net_o2*w(12)) * out_h3*(1-out_h3) * x(1)
gd_w6 = (gd_net_o1*w(11) + gd_net_o2*w(12)) * out_h3*(1-out_h3) * x(2)
```

## 💡 关键理解

### 三因子 vs 两因子

| 层 | 梯度结构 | 因子数 |
|----|---------|--------|
| 隐藏层 w1~w6 | (上游汇合) × sigmoid导数 × 输入 | 3 |
| 输出层 w7~w12 | 上游梯度 × 输入 | 2 |

隐藏层多了一个"上游汇合"步骤，因为隐藏神经元同时影响多个输出，梯度要从多条路汇合。输出层权重只连一个神经元，不涉及汇合。

### 三个因子各管什么

| 因子 | 含义 | 链式法则的哪一步 |
|------|------|-----------------|
| `gd_net_o1*w(k) + gd_net_o2*w(k+1)` | 上游两条路的梯度汇合 | dL/d_out_h |
| `out_h * (1 - out_h)` | sigmoid的导数 | d_out_h/d_net_h |
| `x(i)` | 输入值 | d_net_h/dw |

### gd_list 的含义

```python
gd_list = [dL/dw1, dL/dw2, dL/dw3, dL/dw4, dL/dw5, dL/dw6,   # 隐藏层
           dL/dw7, dL/dw8, dL/dw9, dL/dw10, dL/dw11, dL/dw12]  # 输出层
```

每个值就是"这个权重对损失有多大影响"：
- **正数** → 增大w会增大损失 → 应减小w
- **负数** → 增大w会减小损失 → 应增大w

更新公式：`w = w - lr * gd`（顺着梯度的反方向调）

写成列表是为了循环更新：
```python
for i in range(1, 13):
    update_w(i, gd_list[i - 1])
```

## ⚠️ 易错点与常见误解

1. **"原代码把三步揉一起看不懂"** — 是的，应该拆开写。`gd_net_o1 = (out_o1 - y1) * out_o1 * (1 - out_o1)` 实际上是前两步链式相乘的结果，但代码没有体现这个结构，应该分别写出每步导数再相乘。

2. **"w1和w2的梯度为什么只差最后一个因子"** — 因为 `net_h1 = w1*x(1) + w2*x(2) + b1`，对w1求导得x(1)，对w2求导得x(2)，其余步骤完全一样。

3. **"隐藏层梯度为什么要加两路"** — 因为h1同时连着o1和o2，改变w1会同时影响两个输出，两边的梯度都要算进来。如果只算一路，就漏掉了另一条路径的影响。

## 🔗 知识延伸

- 自动微分（Autograd）：PyTorch自动完成链式法则，不需要手写梯度
- 计算图：前向构建图，反向沿图传梯度，本质就是这段代码的通用化
- 梯度消失：sigmoid导数最大0.25，多层相乘后梯度趋近0，这是ReLU替代sigmoid的核心原因
