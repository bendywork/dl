# 深度学习分类网络训练完整流程

## 📌 核心问题
> 如何从零搭建一个完整的深度学习分类网络并训练它？

## 🌱 根源与动机

深度学习训练流程由两个完全独立的部分组成：
- **网络结构**：定义数据怎么流动（forward）
- **训练驱动**：定义网络怎么学习（training 函数）

两者职责分离，是 PyTorch 的核心设计哲学。

## 📐 完整流程

### 第一步：数据加载（独立函数，不在网络类里）
```python
def data_load():
    x, y = make_circles(n_samples=1000, factor=0.5, noise=0.06, random_state=0)
    x_train, x_test, y_train, y_test = train_test_split(x, y, test_size=0.2, random_state=24)
    return x_train, x_test, y_train, y_test
```

### 第二步：网络结构定义
```python
class DeepLearning_Classify(nn.Module):
    def __init__(self, in_features, num_classes):
        super().__init__()
        self.features = nn.Sequential(
            nn.Linear(in_features, 8),
            nn.ReLU(),
            nn.Linear(8, 8),
            nn.ReLU()
        )
        self.classify = nn.Linear(8, num_classes)

    def forward(self, x):
        features = self.features(x)
        score = self.classify(features)
        if self.training:
            return score          # 训练：返回 raw logits
        return score.argmax(dim=1)  # 推理：返回预测类别
```

### 第三步：训练函数完整结构
```python
def training():
    # 1. 加载数据
    x_train, x_test, y_train, y_test = data_load()

    # 2. 创建网络（in_features 和 num_classes 从数据自动推断）
    net = DeepLearning_Classify(
        in_features=x_train.shape[1],
        num_classes=len(np.unique(y_train))
    )

    # 3. 损失函数 + 优化器
    loss_fn = nn.CrossEntropyLoss()
    opt = optim.SGD(params=net.parameters(), lr=0.01)

    # 4. 超参数
    total_epoch = 100
    batch_size = 8
    total_train_batch = len(x_train) // batch_size
    total_test_batch = len(x_test) // batch_size

    for epoch in range(total_epoch):
        # 5. 训练循环
        net.train()
        for batch_idx in range(total_train_batch):
            si = batch_idx * batch_size
            ei = (batch_idx + 1) * batch_size
            x_batch = torch.tensor(x_train[si:ei], dtype=torch.float32)
            y_batch = torch.tensor(y_train[si:ei], dtype=torch.int64)

            score = net(x_batch)           # 前向
            loss = loss_fn(score, y_batch) # 计算loss
            opt.zero_grad()                # 清空梯度
            loss.backward()               # 反向传播
            opt.step()                    # 更新参数

        # 6. 评估循环
        net.eval()
        with torch.no_grad():
            for batch_idx in range(total_test_batch):
                si = batch_idx * batch_size
                ei = (batch_idx + 1) * batch_size
                x_batch = torch.tensor(x_test[si:ei], dtype=torch.float32)
                y_batch = torch.tensor(y_test[si:ei], dtype=torch.int64)
                pred = net(x_batch)
                acc = (pred == y_batch).float().mean().item()
                print(f"Epoch {epoch} Batch {batch_idx} Acc:{acc:.3f}")

        print(f"Epoch {epoch} Loss:{loss.item():.3f}")
```

## 💡 关键理解

| 概念 | 说明 |
|------|------|
| `in_features` | 每个样本的特征数，对应 x_train.shape[1] |
| `num_classes` | 分类类别数，对应 len(np.unique(y)) |
| `net.train()` | 递归切换所有子模块为训练模式 |
| `net.eval()` | 递归切换所有子模块为推理模式 |
| `CrossEntropyLoss` | 内部已包含 softmax，forward 只需返回 raw logits |
| `torch.no_grad()` | 关闭梯度计算，评估时节省显存 |

## ⚠️ 易错点

1. **`data_load` 不应写进网络类里**：网络不应该管数据怎么来，放外部独立函数
2. **评估循环位置**：`net.eval()` 和 `with torch.no_grad()` 在训练内层循环外，在 epoch 循环内
3. **`total_test_batch` 不要放在 epoch 循环里**：每轮都重复计算，应放在循环外
4. **`with torch.no_grad()` 包裹整个评估 for 循环**，不是每个 batch 套一次
5. **`net.eval()` 要在 `with torch.no_grad()` 之前调用**，两者都不能少
