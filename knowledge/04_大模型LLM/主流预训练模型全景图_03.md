# 主流预训练模型全景图

> 企业级开发中常用的预训练模型一览，按架构分类，附 HuggingFace / ModelScope 地址。

---

## 一、模型架构谱系

```
Transformer (Google, 2017 "Attention Is All You Need")
│
├── 🟦 Encoder-only (双向理解) → BERT 路线
│     擅长的任务：文本分类、NER、关系抽取、语义匹配、文本表示
│
├── 🟩 Decoder-only (单向生成) → GPT 路线
│     擅长的任务：对话、代码生成、写作、推理、工具调用
│
├── 🟨 Encoder-Decoder (理解→生成) → T5/BART 路线
│     擅长的任务：翻译、摘要、文本改写
│
└── 🟪 Multimodal (多模态) → CLIP/BLIP 路线
      擅长的任务：图文匹配、图像描述、视觉问答
```

## 二、Encoder-only 模型（BERT 家族）

### 2.1 核心模型

| 模型 | 发布方 | 年份 | 核心创新 | 参数量 |
|------|--------|------|----------|--------|
| **BERT** | Google | 2018 | MLM + NSP，双向预训练开山之作 | 110M / 340M |
| **RoBERTa** | Meta | 2019 | 去 NSP、动态掩码、更大 batch，BERT 的强力改良版 | 125M / 355M |
| **ALBERT** | Google | 2019 | 参数共享 + 分解嵌入，大幅压缩参数量 | 12M / 18M / 235M |
| **DistilBERT** | HuggingFace | 2019 | 知识蒸馏，小 40%、快 60%、保留 97% 效果 | 66M |
| **ELECTRA** | Google | 2020 | 替换 token 检测 (RTD) 替代 MLM，训练效率大幅提升 | 14M / 110M / 335M |
| **DeBERTa v3** | Microsoft | 2021 | 解耦注意力 + RTD，当时的 NLU SOTA | 86M / 184M / 304M |
| **XLNet** | Google/CMU | 2019 | 排列语言模型，结合自回归 + 双向 | 110M / 340M |

## 六、企业选型速查

| 场景 | 推荐模型 | 理由 |
|------|----------|------|
| 中文文本分类 / NER | **RoBERTa-wwm-ext** 或 **StructBERT** | 中文 NLU 老牌基座，稳 |
| 英文文本分类 / NER | **DeBERTa-v3-base** | 效果最强 Encoder 模型 |
| 轻量部署 (Encoder) | **DistilBERT** 或 **ELECTRA-small** | 速度与效果平衡 |
| 中文对话 / Agent | **Qwen 2.5** | 中文开源最强，工具调用好 |
| 低成本 LLM 部署 | **Qwen 2.5 7B** 或 **Gemma 2 9B** | 开源可商用，硬件友好 |
| 端侧 / 移动端 | **MiniCPM** 或 **Gemma 2 2B** | 手机/边缘设备可跑 |
| 翻译 / 摘要 | **mBART** 或 **Flan-T5** | Encoder-Decoder 原生的 seq2seq 优势 |
| RAG 检索增强 | **Command R+** 或 **Qwen 2.5** | 长上下文 + 引用能力强 |
| 图文匹配 / 多模态 | **CLIP** 或 **Qwen-VL** | 文本-图像对齐 |
| 追求极致性价比 | **DeepSeek V3** | MoE，推理成本极低 |

## 七、关键洞察

1. **BERT 系并未过时**：分类、NER、检索、特征提取，Encoder 模型仍然是首选——更快、更省资源
2. **开源 LLM 已追平 GPT-4**：DeepSeek V3 / Qwen 2.5 等在中英文场景不输闭源
3. **小模型逆袭**：Phi-4（14B）、Gemma 2（9B）在合理场景下效果惊人，合成数据训练是关键
4. **MoE 是性价比答案**：DeepSeek V3、Mistral 8x7B 用稀疏激活大幅降低推理成本
5. **选模型先选架构，再选尺寸**：理解任务走 Encoder，生成任务走 Decoder，别用 GPT 做分类头部
