# 爬虫文本清洗与数据提取

## 📌 核心问题
> 爬虫拿到的原始 HTML 如何变成结构化数据？法律法规、股吧帖子等不同文本场景如何清洗？parsel/selectolax/BeautifulSoup 怎么选？

## 🌱 根源与动机

### 从 HTML 到结构化数据的两步走

```
原始 HTML                   结构化字段
┌──────────┐              ┌──────────┐
│ <div>    │   ──解析──→  │ title: "..." │
│ <h1>...  │              │ author: "..." │
│ <p>...   │   ──清洗──→  │ content: "..." │
│ </div>   │              │ date: "..."  │
└──────────┘              └──────────┘
```

- **解析**：从 HTML 中"取出"目标元素的内容（CSS 选择器 / XPath）
- **清洗**：把取出的文本"弄干净"（去空白、去 HTML 标签、去广告、规范化）

## 📐 解析库对比

| 库 | 特点 | 适用场景 | 本项目使用 |
|-----|------|---------|-----------|
| **parsel** | Scrapy 同款，CSS + XPath 双支持 | ⭐ 通用 HTML 解析 | ✅ 主力 |
| **selectolax** | Modest 引擎，比 lxml 快 2-20 倍 | 大文本量场景 | ✅ 备选 |
| **BeautifulSoup** | 最知名，API 友好但慢 | 小规模/容错场景 | ✅ 清洗用 |
| **lxml** | 底层 C 库，极快 | 性能极致要求 | 间接（parsel 底层） |

### 本项目选择 parsel 的原因

```python
from parsel import Selector

sel = Selector(text=html_string)

# CSS 选择器（大多数人更熟悉）
title = sel.css("h1.title::text").get()
links = sel.css("a::attr(href)").getall()

# XPath（复杂条件查询时更强大）
item = sel.xpath("//div[contains(@class, 'item')]/span/text()").get()
```

**parsel 的优势：**
- CSS 选择器和 XPath 可以混用（在同一个 Selector 对象上）
- `::text` 和 `::attr(href)` 伪元素选择器，非常方便
- 与 Scrapy 完全兼容，未来迁移成本低

## 💡 本项目的提取工具

### 字段提取函数（`core/parsers/extractor.py`）

```python
from parsel import Selector

def extract_field(sel: Selector, css: str, default: str = ""):
    """提取单个字段，不存在返回默认值（不抛异常）"""
    val = sel.css(css).get()
    return val.strip() if val else default

def extract_list(sel: Selector, css: str):
    """提取字段列表"""
    return [v.strip() for v in sel.css(css).getall() if v.strip()]
```

使用示例：
```python
item = {
    "url": context.request.loaded_url,
    "title": extract_field(sel, "h1::text"),
    "price": extract_field(sel, ".product_price::text", default="0"),
}
```

## 💡 文本清洗工具（`core/utils/text_cleaner.py`）

这是项目中最完整的文本清洗工具集，从另一个爬虫项目（消防法规）提取并复用：

### 1. HTML 清洗 → 纯文本

```python
class TextCleaner:
    @staticmethod
    def clean_html(html_content: str, preserve_links: bool = False) -> str:
        """从 HTML 中提取纯文本"""
        soup = BeautifulSoup(html_content, "lxml")
        
        # 移除脚本、样式、导航
        for tag_name in ["script", "style", "nav", "footer", "header"]:
            for tag in soup.find_all(tag_name):
                tag.decompose()
        
        # 移除常见非正文区域（广告、侧栏、面包屑...）
        skip_patterns = ["nav", "menu", "sidebar", "footer", 
                        "advertisement", "copyright", "breadcrumb"]
        for pattern in skip_patterns:
            for tag in soup.find_all(class_=re.compile(pattern, re.I)):
                tag.decompose()
        
        text = soup.get_text(separator="\n")
        return TextCleaner.normalize_text(text)
```

### 2. 文本规范化

```python
@staticmethod
def normalize_text(text: str) -> str:
    """统一换行、合并空白行、去除首尾空白"""
    text = re.sub(r"\n{3,}", "\n\n", text)  # 3个以上换行→2个
    lines = [line.strip() for line in text.split("\n")]
    while lines and not lines[0]:   # 去前导空行
        lines.pop(0)
    while lines and not lines[-1]:  # 去尾部空行
        lines.pop()
    return "\n".join(lines)
```

### 3. 日期提取（多种格式兼容）

```python
@staticmethod
def extract_date(text: str) -> Optional[str]:
    """从文本中提取日期 → 'YYYY-MM-DD'"""
    patterns = [
        r"(\d{4})[-/年](\d{1,2})[-/月](\d{1,2})日?",  # 2024年6月12日
        r"(\d{4})(\d{2})(\d{2})",                      # 20240612
    ]
    for pattern in patterns:
        m = re.search(pattern, text)
        if m:
            year, month, day = m.group(1), m.group(2), m.group(3)
            return f"{year}-{int(month):02d}-{int(day):02d}"
    return None
```

### 4. 章节/条款提取（法律法规专用）

```python
@staticmethod
def extract_chapter_info(text: str) -> Optional[dict]:
    """'第一章 总则' → {"number": "一", "title": "总则"}"""
    m = re.match(r"第([一二三四五六七八九十百零\d]+)章\s*(.*)", text.strip())
    if m:
        return {"number": m.group(1), "title": m.group(2).strip()}
    return None

@staticmethod
def extract_article_info(text: str) -> Optional[dict]:
    """'第一条 为了...' → {"number": "一", "content": "为了..."}"""
    m = re.match(r"第([一二三四五六七八九十百零\d]+)条\s*(.*)", text.strip())
    if m:
        return {"number": m.group(1), "content": m.group(2).strip()}
    return None
```

### 5. 内容哈希去重

```python
@staticmethod
def compute_content_hash(text: str) -> str:
    """SHA256 哈希 → 判断同一篇法规/文章是否更新了"""
    return hashlib.sha256(text.encode("utf-8")).hexdigest()
```

### 6. 水印/页眉页脚去除

```python
@staticmethod
def remove_watermark_text(text: str) -> str:
    """去除 '国家标准全文公开系统'、'第X页 共Y页' 等干扰文本"""
    watermarks = [
        r"国家标准全文公开系统",
        r"GB\s*\d+[\.-]\d+",
        r"第\s*\d+\s*页.*共\s*\d+\s*页",
        r"版权所有.*侵权必究",
    ]
    for pat in watermarks:
        text = re.sub(pat, "", text, flags=re.IGNORECASE)
    return TextCleaner.normalize_text(text)
```

## 🔧 实际业务中的清洗案例

### 股吧帖子清洗（`business/sa/guba_service.py`）

```python
def _clean_post(self, data: dict) -> dict:
    # 正文去空白
    if data.get("content"):
        data["content"] = data["content"].strip()
        # 过滤超短正文（<10字的无意义帖子）
        if len(data["content"]) < 10:
            data["content"] = ""
    
    # 过滤广告评论（"加群"、"荐股"、"V信"等）
    cleaned_comments = []
    for c in data.get("comments", []):
        content = c.get("content", "").strip()
        if not content:
            continue
        if any(kw in content for kw in ["加群", "V信", "荐股", "牛股推荐"]):
            continue
        cleaned_comments.append(c)
    
    return data
```

### 阅读数解析（特殊格式处理）

```python
def parse_read_count(text: str) -> int:
    """'2.6万' → 26000, '1234' → 1234"""
    text = text.strip()
    if "万" in text:
        return int(float(text.replace("万", "")) * 10000)
    return int(text) if text.isdigit() else 0
```

## ⚠️ 易错点与常见误解

1. **CSS 选择器结果不判空就 `.strip()`** → 爬虫 99% 的 AttributeError 都因此而来，必须用 `extract_field` 包裹
2. **不区分提取和清洗** → 提取（parsel.css）和清洗（strip/re.sub）应该分层，不要混在一起
3. **广告过滤只放在存储层** → 应该在采集阶段就过滤，减少存储和带宽浪费
4. **用 `re.match` 而不是 `re.search`** → match 只从字符串开头匹配，search 从任意位置匹配，大部分场景应使用 search
5. **忘记处理中文数字** → "第一百二十三章" 不是 `\d+` 能匹配的
6. **HTML 内容多次 `.read()`** → `context.http_response.read()` 返回 bytes 后被消费，需要先存到变量
