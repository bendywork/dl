# 知识图谱（Knowledge Graph）

## 📌 核心问题
> 如何将散乱的文本信息组织成结构化的知识，让机器能做推理和问答？

## 🌱 根源与动机

知识图谱 = **实体 + 关系**构成的有向图：
```
节点：实体（人、地、机构、概念）
边：关系（创立、位于、属于、发布...）
三元组：(Subject, Predicate, Object)
```

**构建流程**：
```
原始文本 → NER → 实体 → RE → 三元组 → 存入图数据库 → 查询/推理
```

## 📐 理论推导

### 图数据库 Neo4j

存储 KG 的标准工具，使用 Cypher 查询语言：

```cypher
-- 创建实体
CREATE (p:Person {name: "马云"})
CREATE (c:Company {name: "阿里巴巴"})

-- 创建关系
MATCH (p:Person {name:"马云"}), (c:Company {name:"阿里巴巴"})
CREATE (p)-[:FOUNDED]->(c)

-- 查询：马云创立的公司
MATCH (p:Person {name:"马云"})-[:FOUNDED]->(c)
RETURN c.name
```

### Python 接入方式

**py2neo**（高层封装）：
```python
from py2neo import Graph, Node, Relationship
graph = Graph("bolt://localhost:7687", auth=("neo4j", "password"))
node = Node("Person", name="马云")
graph.create(node)
```

**neo4j driver**（官方低层驱动）：
```python
from neo4j import GraphDatabase
driver = GraphDatabase.driver("bolt://localhost:7687", auth=("neo4j", "password"))
with driver.session() as session:
    session.run("CREATE (n:Person {name: $name})", name="马云")
```

### 知识图谱嵌入（KGE）

将实体和关系嵌入向量空间，用于链接预测和推理：
- TransE：`h + r ≈ t`（头实体 + 关系 ≈ 尾实体）
- RotatE：关系建模为旋转变换

## 💡 关键理解

- **KG 不只是存数据，核心价值是推理**：从已知三元组推断未知关系
- **KG + LLM**（RAG）：用 KG 给 LLM 提供结构化背景知识，减少幻觉
- CSV 批量导入比逐条创建快 100 倍以上，大规模 KG 必须用批量导入

## ⚠️ 易错点与常见误解

1. **Neo4j 默认只监听 localhost**，远程访问要修改 `neo4j.conf`
2. **Bolt 端口是 7687**，HTTP 端口是 7474（浏览器界面）
3. **py2neo 版本兼容性**：py2neo 2021.x 对应 Neo4j 4.x，版本不匹配会报错
4. **关系没有 MERGE 防重复**：重复 CREATE 会创建重复边，应用 `MERGE` 代替 `CREATE`
