# 自编码神经网络（Autoencoder Neural Network）

## 📌 核心问题

> **自编码器解决了什么问题？**

核心问题：**如何让神经网络无监督地学习数据的压缩表示（潜在特征）？**

在现实场景中，绝大多数数据是没有标签的。监督学习依赖人工标注，成本高昂且难以规模化。自编码器的核心价值在于：

- **无监督特征学习**：不需要标签，仅从数据本身的结构中学习有意义的表示
- **数据降维**：将高维数据压缩到低维潜在空间，保留最关键的信息
- **去噪与重建**：从损坏的输入中恢复原始数据，学习鲁棒的特征
- **生成模型基础**：VAE 等变体为生成式 AI 奠定了理论基础

一句话总结：**自编码器 = 让网络自己学会"压缩再还原"数据，从而捕获数据中最本质的特征。**

---


## 🌱 根源与动机

### 历史背景

自编码器的思想可以追溯到 **1986年**，Hinton 和 Rumelhart 在论文 *"Learning Internal Representations by Error Propagation"* 中提出：如果让一个神经网络学习恒等映射（输入=输出），那么中间层的激活值就是数据的一种内部表示。

### 问题动机

考虑以下场景：

| 问题 | 描述 |
|------|------|
| 高维灾难 | 图像、文本等数据维度极高（一张 28×28 图片 = 784维），直接处理代价巨大 |
| 无标签数据 | 互联网上有海量无标注数据，但监督学习无法利用 |
| 特征工程 | 手工设计特征耗时耗力，且依赖领域专家经验 |
| 噪声干扰 | 真实数据往往含有噪声，影响下游任务性能 |

### 直觉：信息瓶颈

想象你要把一本书的内容用一句话概括，然后再根据这句话尽可能还原原书内容。为了还原得好，你必须提取最核心的信息——这就是自编码器的本质。

```
输入数据（高维）→ 编码器（压缩）→ 潜在表示（低维）→ 解码器（还原）→ 重建数据（高维）
    784维              ↓                32维                ↓               784维
                 提取关键特征                          从特征恢复数据
```

**关键约束**：潜在维度 < 输入维度（欠完备自编码器），迫使网络丢弃冗余信息，只保留最本质的特征。

## 📐 理论推导

### 1. 基本架构

自编码器由两部分组成：

**编码器（Encoder）**：将输入 x 映射到潜在表示 z

$$z = f_\theta(x) = \sigma(W_e \cdot x + b_e)$$

- $x \in \mathbb{R}^d$：输入向量（d 维）
- $W_e \in \mathbb{R}^{m \times d}$：编码器权重矩阵
- $b_e \in \mathbb{R}^m$：编码器偏置
- $z \in \mathbb{R}^m$：潜在表示（m 维，通常 m < d）
- $\sigma$：激活函数（ReLU、Sigmoid 等）

**解码器（Decoder）**：将潜在表示 z 还原为重建输出 x̂

$$\hat{x} = g_\phi(z) = \sigma(W_d \cdot z + b_d)$$

- $W_d \in \mathbb{R}^{d \times m}$：解码器权重矩阵
- $b_d \in \mathbb{R}^d$：解码器偏置
- $\hat{x} \in \mathbb{R}^d$：重建输出

### 2. 损失函数

目标：让重建输出 $\hat{x}$ 尽可能接近原始输入 $x$。

**均方误差（MSE）**——适用于连续值数据：

$$L_{MSE} = \frac{1}{n}\sum_{i=1}^{n}\|x_i - \hat{x}_i\|^2 = \frac{1}{n}\sum_{i=1}^{n}(x_i - \hat{x}_i)^2$$

**交叉熵损失（BCE）**——适用于 [0,1] 范围的数据（如归一化图像）：

$$L_{BCE} = -\frac{1}{n}\sum_{i=1}^{n}[x_i \log(\hat{x}_i) + (1-x_i)\log(1-\hat{x}_i)]$$

### 3. 训练过程

```
训练循环：
1. 前向传播：x → encoder → z → decoder → x̂
2. 计算损失：L = loss(x, x̂)
3. 反向传播：∂L/∂W_e, ∂L/∂W_d, ∂L/∂b_e, ∂L/∂b_d
4. 参数更新：θ = θ - η·∂L/∂θ
5. 重复直到收敛
```

### 4. 为什么欠完备约束有效？

当潜在维度 m < 输入维度 d 时，网络无法简单地将输入复制到输出（恒等映射不可行），**被迫学习数据中最显著的结构**。

数学直觉：$W_e \in \mathbb{R}^{m \times d}$ 且 m < d，这意味着编码是一个**从高维到低维的投影**，信息必然有损失。网络必须学会丢弃"不重要的"信息，保留"关键的"信息。

**与 PCA 的关系**：当编码器和解码器都是线性变换（无激活函数）且使用 MSE 损失时，自编码器学到的潜在表示等价于 PCA 的主成分。非线性自编码器则是 PCA 的非线性推广。

## 💡 关键理解

### 核心洞察 1：自编码器不是在学"复制"，而是在学"理解"

如果潜在维度 ≥ 输入维度（过完备），网络可能学到的只是恒等映射 $x̂ = x$，这毫无意义。因此需要约束：

| 约束方式 | 原理 | 效果 |
|---------|------|------|
| 欠完备（m < d） | 瓶颈层维度小于输入 | 强制压缩，丢弃冗余 |
| 稀疏约束 | 惩罚潜在层激活过多神经元 | 每次只用少量特征 |
| 去噪约束 | 输入加噪声，要求输出干净 | 学习鲁棒表示 |
| 收缩约束 | 惩罚编码器对输入的敏感度 | 学习平滑映射 |

### 核心洞察 2：潜在空间是数据的"灵魂"

潜在向量 z 的每一维可以理解为数据的某个"语义因子"：

- 对人脸图像：某一维可能编码"微笑程度"，另一维编码"年龄"
- 对文本数据：某一维可能编码"情感极性"，另一维编码"主题类别"
- 对语音数据：某一维可能编码"音调高低"，另一维编码"语速快慢"

这些因子是**自动发现**的，不需要人工指定——这正是表示学习的魅力。

### 核心洞察 3：类比记忆宫殿

```
想象你的大脑在记忆一座城市：

原始体验（高维输入）：街道的每个细节、声音、气味、颜色 → 无限维度
压缩编码（潜在表示）：记住几条关键路线和地标 → 低维特征
回忆还原（解码输出）：根据路线和地标重建大致的城市印象 → 重建数据

关键：你不可能记住每个细节，但记住了最关键的结构。
      这就是自编码器做的事。
```

### 核心洞察 4：重建 ≠ 复制

自编码器的目标不是完美还原每一个像素/词，而是还原数据的**语义**。这意味着：

- 允许细节上的偏差（模糊但语义正确）
- 潜在表示捕获的是"数据分布"而非"单个样本"
- 这也是为什么 VAE 引入概率建模——显式地建模数据分布

## 🔄 自编码器变体

### 1. 去噪自编码器（Denoising Autoencoder, DAE）

**核心思想**：不还原原始输入，而是从被噪声污染的输入中还原干净数据。

```
干净数据 x → 加噪声 → 损坏数据 x̃ → 编码器 → z → 解码器 → 重建 x̂
                        ↑                                    ↓
                   随机置零/高斯噪声                    目标：逼近原始 x（非 x̃）
```

**损坏方式**：
- 随机掩码（Masking Noise）：随机将部分输入置零，比例通常 30%-50%
- 高斯噪声：添加 $\mathcal{N}(0, \sigma^2)$ 噪声
- 椒盐噪声：随机将像素设为最大值或最小值

**损失函数**：

$$L_{DAE} = \|x - \hat{x}\|^2 \quad \text{注意：目标仍然是原始 } x, \text{ 而非损坏的 } \tilde{x}$$

**为什么有效**：网络必须学会区分"信号"与"噪声"，这迫使它捕获数据的统计结构而非记住噪声模式。本质上是在学习数据的流形结构。

### 2. 稀疏自编码器（Sparse Autoencoder）

**核心思想**：即使在过完备设置下（m ≥ d），通过稀疏约束防止恒等映射。

**稀疏惩罚**：对潜在层激活值添加约束，使大部分神经元保持"沉默"。

$$L_{Sparse} = L_{recon} + \lambda \sum_{j=1}^{m} KL(\rho \| \hat{\rho}_j)$$

其中：
- $\rho$：目标稀疏度（通常 0.05，即希望每个神经元仅 5% 的时间激活）
- $\hat{\rho}_j$：神经元 j 在训练批次上的平均激活值
- $KL(\rho \| \hat{\rho}_j)$：KL 散度惩罚，当 $\hat{\rho}_j$ 偏离 $\rho$ 时增大

$$KL(\rho \| \hat{\rho}_j) = \rho \log\frac{\rho}{\hat{\rho}_j} + (1-\rho)\log\frac{1-\rho}{1-\hat{\rho}_j}$$

**直觉**：想象一个委员会，每次讨论只让少数专家发言（稀疏激活），而不是所有人一起吵（密集激活）。每个专家被迫学习独特的、不可替代的知识。

### 3. 收缩自编码器（Contractive Autoencoder, CAE）

**核心思想**：惩罚编码器对输入微小变化的敏感度，使映射更平滑。

$$L_{CAE} = L_{recon} + \lambda \left\| \frac{\partial f_\theta(x)}{\partial x} \right\|_F^2$$

其中 $\left\| \cdot \right\|_F^2$ 是 Frobenius 范数，即编码器雅可比矩阵所有元素的平方和。

**直觉**：输入的微小扰动不应导致潜在表示的剧烈变化。这使学到的特征对噪声具有鲁棒性，同时沿数据流形方向仍可变化。

### 4. 深度自编码器（Deep Autoencoder）

**核心思想**：用多层网络替代单层，逐层提取更抽象的特征。

```
输入(784) → 512 → 256 → 128 → 64(瓶颈) → 128 → 256 → 512 → 784(输出)
              ↓      ↓      ↓    ↑          ↑      ↑      ↑
           编码器逐层压缩          解码器逐层还原
```

**训练策略**：
- **逐层预训练**：先训练第一个 RBM/AE，固定参数后再训练下一层，最后整体微调
- **端到端训练**：直接反向传播（现代方法，配合 ReLU + BatchNorm 效果很好）

---


### 5. 变分自编码器（Variational Autoencoder, VAE）⭐

**这是自编码器家族中最重要的变体，是现代生成模型的基础之一。**

#### 核心思想：从确定性编码到概率建模

普通自编码器：$z = f(x)$，确定性映射，一个输入对应一个确定的潜在向量。

VAE：$z \sim q_\phi(z|x)$，**概率性映射**，一个输入对应一个潜在分布，从中采样得到 z。

```
普通AE:  x → encoder → z(确定的向量) → decoder → x̂
VAE:     x → encoder → μ, σ → z = μ + σε ~ N(μ, σ²) → decoder → x̂
                        ↑         ↑
                   均值向量   标准差向量    重参数化技巧
```

#### 数学推导

**编码器输出**：均值 $\mu(x)$ 和对数方差 $\log\sigma^2(x)$

**重参数化技巧（Reparameterization Trick）**：

$$z = \mu + \sigma \odot \epsilon, \quad \epsilon \sim \mathcal{N}(0, I)$$

> ⚠️ 这一步至关重要！直接从 $q(z|x)$ 采样无法反向传播梯度，重参数化将随机性转移到外部变量 ε，使梯度可以流经 μ 和 σ。

**VAE 损失函数（ELBO）**：

$$L_{VAE} = L_{recon} + L_{KL}$$

**重建项**（让解码器尽量还原输入）：

$$L_{recon} = -\mathbb{E}_{q(z|x)}[\log p(x|z)]$$

实践中用 MSE 或 BCE 近似。

**KL 散度项**（让编码分布接近标准正态）：

$$L_{KL} = D_{KL}(q(z|x) \| p(z)) = -\frac{1}{2}\sum_{j=1}^{m}\left(1 + \log\sigma_j^2 - \mu_j^2 - \sigma_j^2\right)$$

其中 $p(z) = \mathcal{N}(0, I)$ 是先验分布。

#### KL 项的直觉解释

| 作用 | 解释 |
|------|------|
| 正则化 | 防止编码器把不同样本映射到潜在空间的不同角落（避免"后验坍缩"） |
| 连续性 | 使潜在空间平滑，相近的 z 对应相似的 x |
| 生成能力 | 采样 $z \sim \mathcal{N}(0, I)$ 即可生成新样本 |
| 完整性 | 潜在空间没有"空洞"，任意位置的 z 解码后都有意义 |

#### VAE vs 普通AE 的本质区别

| 维度 | 普通AE | VAE |
|------|--------|-----|
| 编码方式 | 确定性：z = f(x) | 概率性：z ~ q(z\|x) |
| 潜在空间 | 不规则，有空洞 | 规则，连续，覆盖完整 |
| 生成能力 | 无（随机 z 可能解码出乱码） | 有（从 N(0,I) 采样可生成） |
| 理论基础 | 无 | 变分推断（Variational Inference） |
| 损失函数 | 重建损失 | 重建损失 + KL 散度 |

## 🔧 代码实现

### 1. 基础自编码器（PyTorch）

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torchvision import datasets, transforms
from torch.utils.data import DataLoader

# ============ 基础自编码器 ============
class Autoencoder(nn.Module):
    def __init__(self, input_dim=784, latent_dim=32):
        super().__init__()
        # 编码器：784 → 256 → 128 → 32
        self.encoder = nn.Sequential(
            nn.Linear(input_dim, 256),
            nn.ReLU(),
            nn.Linear(256, 128),
            nn.ReLU(),
            nn.Linear(128, latent_dim),
        )
        # 解码器：32 → 128 → 256 → 784
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, 128),
            nn.ReLU(),
            nn.Linear(128, 256),
            nn.ReLU(),
            nn.Linear(256, input_dim),
            nn.Sigmoid(),  # 输出 [0,1]，配合 BCE 损失
        )

    def forward(self, x):
        z = self.encoder(x)      # 编码到潜在空间
        x_hat = self.decoder(z)  # 从潜在空间解码
        return x_hat, z

    def encode(self, x):
        """仅编码，用于特征提取"""
        return self.encoder(x)

    def decode(self, z):
        """仅解码，用于生成"""
        return self.decoder(z)


# ============ 训练流程 ============
def train_autoencoder():
    # 数据加载（MNIST）
    transform = transforms.Compose([
        transforms.ToTensor(),
        transforms.Lambda(lambda x: x.view(-1)),  # 展平为 784 维
    ])
    dataset = datasets.MNIST('./data', train=True, download=True, transform=transform)
    loader = DataLoader(dataset, batch_size=128, shuffle=True)

    # 模型与优化器
    model = Autoencoder(input_dim=784, latent_dim=32)
    optimizer = optim.Adam(model.parameters(), lr=1e-3)
    criterion = nn.BCELoss()

    # 训练循环
    epochs = 20
    for epoch in range(epochs):
        total_loss = 0
        for batch_x, _ in loader:  # 标签不需要！无监督学习
            x_hat, z = model(batch_x)
            loss = criterion(x_hat, batch_x)

            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
            total_loss += loss.item()

        avg_loss = total_loss / len(loader)
        print(f"Epoch {epoch+1}/{epochs} | Loss: {avg_loss:.4f}")

    return model

# 运行训练
if __name__ == "__main__":
    model = train_autoencoder()

    # 测试：编码 + 解码
    test_img = torch.rand(1, 784)
    z = model.encode(test_img)
    reconstructed = model.decode(z)
    print(f"潜在向量维度: {z.shape}")        # [1, 32]
    print(f"重建输出维度: {reconstructed.shape}")  # [1, 784]
```

### 2. 变分自编码器（VAE）

```python
import torch
import torch.nn as nn
import torch.nn.functional as F


class VAE(nn.Module):
    def __init__(self, input_dim=784, latent_dim=20):
        super().__init__()
        self.latent_dim = latent_dim

        # 编码器
        self.encoder = nn.Sequential(
            nn.Linear(input_dim, 400),
            nn.ReLU(),
        )
        self.fc_mu = nn.Linear(400, latent_dim)       # 均值
        self.fc_logvar = nn.Linear(400, latent_dim)   # 对数方差

        # 解码器
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, 400),
            nn.ReLU(),
            nn.Linear(400, input_dim),
            nn.Sigmoid(),
        )

    def encode(self, x):
        h = self.encoder(x)
        mu = self.fc_mu(h)
        logvar = self.fc_logvar(h)
        return mu, logvar

    def reparameterize(self, mu, logvar):
        """重参数化技巧：z = mu + sigma * epsilon"""
        std = torch.exp(0.5 * logvar)  # sigma = exp(0.5 * log(sigma^2))
        eps = torch.randn_like(std)     # epsilon ~ N(0, I)
        return mu + eps * std           # 梯度可流经 mu 和 logvar

    def decode(self, z):
        return self.decoder(z)

    def forward(self, x):
        mu, logvar = self.encode(x)
        z = self.reparameterize(mu, logvar)
        x_hat = self.decode(z)
        return x_hat, mu, logvar


def vae_loss(x_hat, x, mu, logvar):
    """VAE 损失 = 重建损失 + KL 散度"""
    # 重建损失（BCE）
    recon_loss = F.binary_cross_entropy(x_hat, x, reduction='sum')

    # KL 散度: -0.5 * sum(1 + log(sigma^2) - mu^2 - sigma^2)
    kl_loss = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp())

    return recon_loss + kl_loss


def train_vae():
    from torchvision import datasets, transforms
    from torch.utils.data import DataLoader

    transform = transforms.Compose([
        transforms.ToTensor(),
        transforms.Lambda(lambda x: x.view(-1)),
    ])
    dataset = datasets.MNIST('./data', train=True, download=True, transform=transform)
    loader = DataLoader(dataset, batch_size=128, shuffle=True)

    model = VAE(input_dim=784, latent_dim=20)
    optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)

    for epoch in range(20):
        total_loss = 0
        for x, _ in loader:
            x_hat, mu, logvar = model(x)
            loss = vae_loss(x_hat, x, mu, logvar)

            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
            total_loss += loss.item()

        print(f"Epoch {epoch+1}/20 | Loss: {total_loss/len(loader.dataset):.4f}")

    return model


if __name__ == "__main__":
    model = train_vae()

    # 🔥 生成新图像：从标准正态采样 z，然后解码
    with torch.no_grad():
        z_sample = torch.randn(5, 20)   # 采样 5 个潜在向量
        generated = model.decode(z_sample)
        print(f"生成了 {generated.shape[0]} 张图像，每张 {generated.shape[1]} 维")
```

### 3. 去噪自编码器（DAE）关键代码片段

```python
class DenoisingAutoencoder(nn.Module):
    def __init__(self, input_dim=784, latent_dim=32, noise_factor=0.3):
        super().__init__()
        self.noise_factor = noise_factor

        self.encoder = nn.Sequential(
            nn.Linear(input_dim, 256),
            nn.ReLU(),
            nn.Linear(256, latent_dim),
        )
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, 256),
            nn.ReLU(),
            nn.Linear(256, input_dim),
            nn.Sigmoid(),
        )

    def add_noise(self, x):
        """随机掩码噪声：将部分输入置零"""
        noise_mask = torch.bernoulli(
            torch.ones_like(x) * (1 - self.noise_factor)
        )
        return x * noise_mask  # 约30%的元素被置零

    def forward(self, x):
        x_noisy = self.add_noise(x)   # 加噪
        z = self.encoder(x_noisy)     # 从噪声输入编码
        x_hat = self.decoder(z)       # 解码重建
        return x_hat, x_noisy         # 注意：损失仍用原始 x 计算


# 训练时：loss = criterion(x_hat, x)  ← 目标是原始干净数据 x
```

### 4. 稀疏自编码器关键代码片段

```python
def sparse_loss(model, x, rho=0.05, beta=3e-3):
    """在重建损失基础上添加 KL 散度稀疏惩罚"""
    # 1. 重建损失
    z = model.encoder(x)
    x_hat = model.decoder(z)
    recon = F.mse_loss(x_hat, x)

    # 2. 计算潜在层平均激活值
    rho_hat = torch.mean(z, dim=0)  # 每个神经元的批次平均激活

    # 3. KL 散度惩罚
    kl = rho * torch.log(rho / (rho_hat + 1e-8)) + \
         (1 - rho) * torch.log((1 - rho) / (1 - rho_hat + 1e-8))
    sparse_penalty = beta * torch.sum(kl)

    return recon + sparse_penalty
```

## ⚠️ 易错点与常见误解

### 1. ❌ "自编码器就是压缩算法"
**误解**：把自编码器当通用压缩工具，期望它能压缩任何数据。
**正确理解**：自编码器只对**训练分布内的数据**有效。用 MNIST 训练的自编码器无法压缩人脸图像。它学到的是特定数据分布的结构，而非通用压缩规则。

### 2. ❌ "潜在维度越大越好"
**误解**：增加潜在维度可以获得更好的重建效果。
**正确理解**：过完备（m ≥ d）时，网络可能学到恒等映射 $x̂ = x$，完全没有学到有意义的特征。**瓶颈是特征学习的必要条件**，除非配合其他正则化（稀疏、去噪等）。

### 3. ❌ "普通AE可以用来生成新数据"
**误解**：从潜在空间随机采样 z，送入解码器就能生成。
**正确理解**：普通 AE 的潜在空间是不规则的——两个训练样本的编码之间可能有空洞，采样到的 z 解码后会输出乱码。**只有 VAE 的潜在空间是连续规则的，可以采样生成。**

### 4. ❌ "VAE 的 KL 散度越小越好"
**误解**：想尽办法让 KL 项趋近于零。
**正确理解**：KL = 0 意味着 $q(z|x) = \mathcal{N}(0, I)$，即编码器完全忽略输入 x，所有样本映射到同一个分布——这叫**后验坍缩（Posterior Collapse）**。此时解码器只生成模糊的平均图像。适当的 KL 值才是好的。

### 5. ❌ "重参数化技巧只是数值技巧"
**误解**：认为重参数化只是让采样可微的数值技巧。
**正确理解**：重参数化是 VAE 的**核心理论贡献**。它将随机性从参数中分离出来，使得：
- 梯度可以流经 μ 和 σ（可微分）
- 随机性由外部 ε 承担（不参与求导）
- 这使端到端训练变分推断成为可能

### 6. ❌ "重建损失低 = 好的表示"
**误解**：看到重建误差很小就觉得模型很好。
**正确理解**：重建误差低可能意味着过拟合——网络记住了训练样本而非学到了通用结构。需要检查：
- 潜在表示是否可用于下游任务（分类、聚类）
- 对未见数据的重建效果
- 潜在空间的平滑度和连续性

## 🔗 知识延伸

### 自编码器在 NLP 中的应用

| 应用 | 方法 | 说明 |
|------|------|------|
| 文本表示学习 | AE/VAE 编码句子 | 将句子编码为固定长度向量，用于相似度计算、聚类 |
| 语义哈希 | 稀疏 AE | 将文档映射为二进制码，实现快速检索 |
| 文本去噪 | DAE | 从含噪声文本（拼写错误、乱序）恢复原始文本 |
| 对话生成 | VAE + RNN/Transformer | VAE 的潜在空间提供多样性，RNN 负责序列生成 |
| 语言模型预训练 | Masked AE（BERT） | BERT 本质上是一种去噪自编码器：掩码词 → 预测原始词 |
| 文本风格迁移 | VAE 解耦 | 在潜在空间中分离内容与风格，实现风格控制 |

### 从自编码器到现代生成模型

```
自编码器 (1986)
  │
  ├── 去噪AE → BERT (2018, Masked Language Model)
  │
  ├── VAE (2013) → VQ-VAE (2017) → VQ-VAE-2 (2019)
  │                    │
  │                    └── 与 Transformer 结合 → DALL·E 类模型
  │
  └── 编码器-解码器架构
        │
        ├── Seq2Seq (2014) → Transformer (2017) → GPT/BERT
        │
        └── U-Net (2015) → 扩散模型 (2020-2023)
```

### 与扩散模型的联系

扩散模型可以理解为一种**分层去噪自编码器**：
- 前向过程：逐步加噪声（相当于多层 DAE 的噪声输入）
- 反向过程：逐步去噪（相当于多层 DAE 的重建）
- 损失函数：预测每一步添加的噪声（而非直接预测原始数据）

### 与 BERT 的联系

BERT 的 MLM（Masked Language Model）本质就是去噪自编码器：

```
DAE:   损坏的图像 → 编码器 → 还原原始图像
BERT:  掩码的文本 → Transformer → 预测原始词

都是：从不完整输入恢复完整数据，迫使模型理解数据的内在结构。
```
