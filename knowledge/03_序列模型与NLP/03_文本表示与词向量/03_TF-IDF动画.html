❌ 纯词频的问题
"的/了/是/在/有" 等虚词在所有文档中都高频出现，
但它们对区分文档主题毫无帮助。
需要一个机制来降低常见词权重，提升稀有词权重。
TF（词项频率）= 词在文档中出现次数 / 文档总词数。归一化处理使不同长度文档可比较。
TF(t, d) = count(t in d) / |d|
t = 目标词，d = 文档，|d| = 文档总词数
词频 TF 值（文档1）
IDF（逆文档频率）：一个词越罕见，IDF 越高。出现在所有文档的词 IDF 趋近 0，只在少数文档出现的词 IDF 高。
IDF(t) = log( N / (1 + dft) )
N = 总文档数，dft = 包含词 t 的文档数
IDF 值对比（点击「展示对比」）
TF-IDF = TF × IDF：同时考虑词的本文档频率和全局稀有度，综合得出词的"重要性分数"。
TF-IDF(t, d) = TF(t, d) × IDF(t)
"北京"在文章中频繁出现(TF高) 且 在其他文档不常见(IDF高) → TF-IDF 高 ✅
"的"到处高频出现(TF高) 但 IDF极低 → TF-IDF 低 ✅
