# LSTM 中的 h_t vs c_t：Attention 为什么选 h_t 做 K/V

## 一、h_t 和 c_t 的本质区别

LSTM 每个时刻产出两个向量，但性质完全不同：

```
c_t = f_t * c_{t-1} + i_t * g_t       ← 长期记忆，加法累积，无筛选
h_t = o_t * tanh(c_t)                  ← 输出门从 c_t 中提取的"表达"
```

| | c_t | h_t |
|------|-----|-----|
| 类比 | 内部草稿（什么都有） | 公开发言（筛选过的） |
| 值域 | 无上限，加法越滚越大 | tanh 压到 [-1, 1] |
| 有门控筛选吗 | ❌ 无 | ✅ 输出门 o_t 选择性地暴露 |
| 每时刻都能拿到吗 | ❌ PyTorch 默认只给最后时刻的 c_n | ✅ output 是每个时刻的 h_t |

**关键认知：c_t 里信号和噪声混在一起，h_t 是输出门从 c_t 里"提纯"后的信息。**

## 二、Attention 为什么用 h_t 做 K/V

Attention 的本质是：**decoder 当前状态去查源序列每个位置"说了什么"。**

查的是整理过的表达（h_t），而不是没整理的内部草稿（c_t）。

```
源句："我今天吃了苹果"

c_5: [内部没整理的信息——"苹果"语义、"吃"动作、主语"我"的残留...全混在一起]
h_5: 输出门从中提纯——"苹果位置该表达的语义"

decoder 生成 "apple" 时去查 → 当然查整理过的 h_t，不查没整理的 c_t
```

如果强行用 c_t 做 K/V：没有输出门筛选，噪声大，Attention 权重分布的区分度下降。

## 三、c_t 的正确使用场景

c_t 不适合做 Attention 的 K/V，但适合做**全局语义输出**：

```
LSTM 输出:
  ├── h_t (output) → RNN 继续序列递推 / Attention 的 K&V
  └── c_n (最后时刻) → LayerNorm → 上下文向量给 decoder 初始化
```

c_n 是整条序列累积的长期记忆，天然适合做全局压缩语义。只是需要 LayerNorm 把值域拉回可控区间。

## 四、LayerNorm 是做什么的

**不是激活函数，是归一化层。** 对一个向量的所有维度集体标准化。

```
c_t = [3.2, -27.8, 0.5, 148.3]    ← 同一向量的 4 个维度，量级天差地别

LayerNorm: (每个值 - 均值) / 标准差 → [-0.6, -1.1, -0.6, 2.2]
                                       ↑ 四个值现在可控了
```

| | BatchNorm | LayerNorm |
|------|-----------|-----------|
| 谁跟谁比 | 你 vs 别人（同一维度跨样本） | 你的四门课互相之间（同一样本跨维度） |
| 适合 | CV（图片批次） | NLP（每个 token 的向量独立归一化） |

## 五、底层原理：训练 = 分离信号和噪声

```
信号 → 模型要学的规律（泛化能力）
噪声 → 被忽略的部分（或通过正则化强制忽略）
```

所有深度学习组件本质上干同一件事：

| 组件 | 如何分离信号与噪声 |
|------|-------------------|
| LSTM 门控（遗忘门、输出门） | 遗忘不重要的，暴露重要的 |
| Attention 权重 | 相关性高的位置拿得多，无关的拿得少 |
| LayerNorm | 防某个维度的数值噪声主导梯度 |
| Dropout | 随机屏蔽部分神经元，强迫分散依赖 |
| 正则化（L2、weight decay） | 惩罚过大的权重，不让模型"记住"噪声 |

**有效数据是经过筛选的，筛选就是去掉噪声。整个深度学习就是一套"让信号通过，把噪声挡掉"的体系。**
