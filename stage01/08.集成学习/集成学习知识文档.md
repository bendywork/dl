# 集成学习（Ensemble Learning）

## 📌 核心问题
> 单个模型容易过拟合或欠拟合，如何通过组合多个弱模型得到一个强模型？

## 🌱 根源与动机
- **偏差-方差权衡**：单棵深决策树高方差（过拟合），单棵浅树高偏差（欠拟合）
- 集成的直觉：多数投票比单人决策更稳定
- 统计学基础：N 个独立误差率 p<0.5 的分类器多数投票，误差随 N 增大指数下降

## 📐 三种主流策略

### 1. Bagging（Bootstrap Aggregating）
- 有放回抽样生成 N 个子数据集
- 每个子集训练一棵独立决策树
- 预测：分类取投票，回归取平均
- 代表：**随机森林**（额外在每个节点随机选特征子集）

### 2. Boosting（提升）
- 串行训练，每轮关注上一轮预测错误的样本
- 给错误样本更高权重，迫使下一棵树重点学习难例
- 代表：**AdaBoost、GBDT、XGBoost、LightGBM**

### 3. Stacking（堆叠）
- 第一层：多个异构模型并行训练，输出预测结果
- 第二层：元学习器（Meta-learner）以第一层输出为特征再训练

## 💡 关键理解
| 方法 | 减少什么误差 | 训练方式 | 典型算法 |
|------|------------|---------|---------|
| Bagging | 方差（Variance） | 并行 | 随机森林 |
| Boosting | 偏差（Bias） | 串行 | XGBoost |
| Stacking | 两者都减 | 两阶段 | 竞赛常用 |

## 🔧 随机森林核心公式
特征重要性（基于不纯度下降）：
```
Importance(f) = Σ_t Σ_n [p(n) · ΔImpurity(n, f)]
```

## ⚠️ 易错点与常见误解
1. **Bagging 不能减少偏差**：树再多，如果每棵树都系统性偏移，平均后仍然偏移
2. **随机森林不是 Bagging 的简单叠加**：额外的"随机特征子集"才是关键，保证树之间的多样性
3. **Boosting 容易过拟合**：轮数过多时会记住噪声，需要早停或正则化
4. **特征重要性不等于因果关系**：重要特征只说明预测相关，不代表因果

## 🔗 知识延伸
- 随机森林 → 梯度提升树（GBDT）→ XGBoost → LightGBM（工程优化）
- 集成学习 → 神经网络集成（Dropout 是隐式集成）
- Stacking → 现代深度学习中的 Mixture of Experts（MoE）
