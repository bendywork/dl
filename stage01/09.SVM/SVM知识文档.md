# 支持向量机（Support Vector Machine）

## 📌 核心问题
> 如何找到一条"最宽"的决策边界，使两类样本之间的间隔最大化？

## 🌱 根源与动机
- 感知机找到"一条"可分的超平面，但无数条都能分对
- SVM 的目标：找到**最大间隔**的那条，泛化性最好
- 直觉：两军对峙，中间的无人区越宽越安全

## 📐 理论推导

### 硬间隔 SVM（线性可分）
决策超平面：w·x + b = 0  
两类支持向量到超平面距离之和（间隔）= 2/||w||  
优化目标：最大化 2/||w|| ⟺ 最小化 ½||w||²  
约束：y_i(w·x_i + b) ≥ 1

### 软间隔 SVM（允许误分）
引入松弛变量 ξ_i ≥ 0：  
min ½||w||² + C·Σξ_i  
s.t. y_i(w·x_i + b) ≥ 1 - ξ_i  
C 越大 → 越不允许误分（容易过拟合）

### 核函数（非线性SVM）
把低维不可分数据映射到高维可分：  
K(x_i, x_j) = φ(x_i)·φ(x_j)  
常用核：线性核、多项式核、**RBF（高斯）核**、Sigmoid核

## 💡 关键理解
- **支持向量**：离超平面最近的那些点，决定超平面位置（其他点删掉也不影响）
- **C 参数**：权衡"间隔宽度"vs"误分数量"
- **γ 参数（RBF）**：控制影响范围，γ大→决策边界复杂→过拟合风险

## ⚠️ 易错点
1. SVM 对特征尺度敏感，必须先标准化
2. C 和 γ 需要网格搜索，默认值常常不是最优
3. 核函数不是"越复杂越好"，RBF 不总优于线性核
4. 大数据集上 SVM 训练慢（O(n²~n³)），考虑 LinearSVC

## 🔗 知识延伸
- SVM → 核方法（Kernel Methods）通用框架
- 最大间隔 → 结构风险最小化（VC 理论）
- SVM 回归（SVR）：用 ε-不敏感损失函数
