## 二、统一训练流程（6 步）

```
① 数据加载 → ② 模型定义 → ③ 损失函数&优化器 → ④ 训练循环 → ⑤ 验证/测试 → ⑥ 保存&推理
```

### 1. 数据加载（Dataset + DataLoader）

```python
class MyDataset(Dataset):
    def __init__(self, data, labels): ...
    def __len__(self): return len(self.data)
    def __getitem__(self, idx): return self.data[idx], self.labels[idx]
```

**NLP 关键点**：变长序列需 `collate_fn` + `pad_sequence`；pad 值用 `padding_idx=0` 且 loss 中 `ignore_index=0`。

### 2. 模型定义（继承 nn.Module）

```python
class MyModel(nn.Module):
    def __init__(self, ...):
        super().__init__()
        # 子层定义
    def forward(self, x, ...):
        # 前向计算
```

### 3. 损失函数 & 优化器

| 任务 | Loss | 备注 |
|------|------|------|
| 分类 | `nn.CrossEntropyLoss()` | 输入 logits，不需要 softmax |
| 生成 | `nn.CrossEntropyLoss(ignore_index=0)` | 忽略 pad 位置 |
| 回归 | `nn.MSELoss()` | |

优化器默认 `Adam`，学习率 `1e-3 ~ 1e-4`。

### 4. 训练循环（核心模板）

```python
def train_epoch(model, dataloader, loss_fn, optimizer, device):
    model.train()                                      # 训练模式
    total_loss = 0.0
    for batch in dataloader:
        x, y = batch[0].to(device), batch[-1].to(device)
        optimizer.zero_grad()                          # 梯度清零
        logits = model(x)                              # 前向
        loss = loss_fn(logits, y)                      # 算损失
        loss.backward()                                # 反向传播
        optimizer.step()                               # 更新参数
        total_loss += loss.item()
    return total_loss / len(dataloader)
```

### 5. 验证

```python
@torch.no_grad()
def validate(model, dataloader, loss_fn, device):
    model.eval()                                       # 验证模式
    for batch in dataloader:
        ...
        # 同样的前向 + loss，但不 backward
```

## 三、模型演进路径 + 关键区别

```
FC ──→ RNN ──→ LSTM ──→ GRU ──→ Seq2Seq ──→ +Attention ──→ Transformer
 │       │        │        │         │             │               │
无序列  有序     长序列   高效     编解码    动态查阅      纯Attention
交互    融合    门控     门控     结构     源序列         并行训练
```

### 各模型状态返回结构

| 模型 | `rnn_layer(x)` 返回 | state 结构 |
|------|---------------------|-----------|
| RNN | `(output, h_n)` | `[num_layers, bs, hidden]` |
| LSTM | `(output, (h_n, c_n))` | 二元组 tuple |
| GRU | `(output, h_n)` | `[num_layers, bs, hidden]` |

### Attention -> Transformer 的关键替代

| Seq2Seq+Attention | Transformer |
|---|---|
| 状态传递归走 LSTM 的 h/c | Self-Attention 输出当下一步输入 |
| 训练串行 for 循环逐 token | mask + 一次并行算完所有位置 |
| Q 来自 decoder 状态 | Q/K/V 来自序列自身（经线性投影） |

## 五、常见坑

| 坑 | 现象 | 解决 |
|----|------|------|
| `batch_first` 不一致 | shape 对不上报错 | 所有 RNN 层统一设 `batch_first=True` |
| LSTM state 是 tuple | 直接 `h.squeeze()` 报错 | 先 `if isinstance(state, tuple)` |
| pad 参与 loss 计算 | loss 偏高 | `ignore_index=0` |
| 忘记 `model.train()/eval()` | dropout/batchnorm 行为错 | 训练前 `train()`，验证前 `eval()` |
| `gradient` 累积 | 显存逐渐增大 | 每个 batch 前 `optimizer.zero_grad()` |
| 验证时开 grad | 显存浪费 | `@torch.no_grad()` 装饰器 |
