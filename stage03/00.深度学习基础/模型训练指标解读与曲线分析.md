# 模型训练效果评估：指标解读与曲线分析

## 一、核心指标一览

### 1. Loss（损失值）

| 阶段 | 含义 | 正常趋势 |
|------|------|---------|
| 训练 loss | 模型在训练集上的拟合误差 | 持续下降 |
| 验证 loss | 模型在未见数据上的泛化误差 | 先降后升 = 过拟合 |

**Loss 是训练的核心追踪指标**，直接反映"当前预测和真实值差多远"。

### 2. 准确率（Accuracy）

```
Accuracy = 预测正确数 / 总样本数
```

| 场景 | 可靠？ |
|------|--------|
| 类别均衡 | ✅ 直观 |
| 类别不均衡（正例 5%） | ❌ 模型全猜负例也有 95%，但没用 |

### 3. 混淆矩阵（Confusion Matrix）

```
              预测猫  预测狗
真实猫         85      15      ← 猫被误判为狗 15%
真实狗         10      90      ← 狗被误判为猫 10%
```

一眼看出"哪两类最容易混"。

### 4. 精确率 & 召回率 & F1（正例稀少时必看）

| 指标 | 公式 | 问题 |
|------|------|------|
| Precision（精确率） | TP / (TP + FP) | "判成正的，有多少真对了？" |
| Recall（召回率） | TP / (TP + FN) | "真正的正例，捞回来多少？" |
| F1 | 2×P×R / (P+R) | 精确率和召回率的调和均值 |

> 癌症筛查要 Recall 高（宁可错杀不能漏），垃圾邮件过滤要 Precision 高（宁可漏不能误杀正常邮件）。

### 5. 生成任务指标（Seq2Seq/翻译）

| 指标 | 含义 |
|------|------|
| BLEU | n-gram 重叠率，机器翻译常用 |
| ROUGE | 召回率，摘要常用 |
| Perplexity | 越低越好，衡量模型对文本的"困惑度" |

## 二、训练曲线怎么看（最重要的技能）

### 核心法则：盯住三条关系

```
         train loss  vs  valid loss  →  看泛化
         train acc   vs  valid acc   →  看过拟合
         train loss  vs  train acc   →  看学习状态
```

### 场景 1：完美训练（黄金曲线）

```
loss
 │
 │  train ▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔
 │  valid ▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔   ← 两条线贴合，平稳收敛
 │
 └──────────────────────────── epoch
```
- train/valid loss 同步下降，差距小→ 拟合好，泛化也好
- 判定：可以继续训练，或调大学习率加速

### 场景 2：过拟合（最常见的问题）

```
loss
 │
 │  train ▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔   ← 持续降
 │  valid ▔▔▔▔▔▔▔▔▔╱           ← 先降后拐头往上
 │                  ╱
 │             ← 拐点（最佳停止位）
 └──────────────────────────── epoch
```
- 训练 loss 还在降，验证 loss 反升 → **模型在背答案，不是学规律**
- 拐点就是 **Early Stopping** 的位置

#### 解法（按优先级）

| 优先级 | 方法 | 操作 |
|--------|------|------|
| 1 | 加 Dropout | `nn.Dropout(0.3~0.5)` |
| 2 | 减模型容量 | 缩小 hidden_size / num_layers |
| 3 | 数据增强 | 加噪声 / 回译 / 同义词替换 |
| 4 | 加正则化 | `weight_decay` (L2 正则) |
| 5 | Early Stopping | valid loss 连续 N 轮不降就停 |

### 场景 3：欠拟合

```
loss
 │
 │  train ▔▔▔▔▔▔▔▔___________   ← 降不下来，在高位平了
 │  valid ▔▔▔▔▔▔▔▔___________
 │
 └──────────────────────────── epoch
```
- 两条线都在高位停滞 → 模型太弱，学不动

#### 解法

| 方法 | 操作 |
|------|------|
| 加模型容量 | 增大 hidden_size / num_layers |
| 提学习率 | `lr`: 1e-4 → 1e-3 |
| 换优化器 | SGD → Adam |
| 减正则化 | 关掉 dropout / weight_decay 试试 |

### 场景 4：不收敛 / 震荡

```
loss
 │  ╲  ╱╲  ╱╲  ╱╲
 │   ╲╱  ╲╱  ╲╱  ╲╱        ← 剧烈抖动，不下降
 │
 └──────────────────────────── epoch
```

#### 原因排查

| 排查项 | 检查方式 |
|--------|---------|
| 学习率太大 | 调小 10 倍试试（`lr`: 1e-3 → 1e-4） |
| batch_size 太小 | 增大 batch_size |
| 数据没 shuffle | DataLoader 设 `shuffle=True` |
| 梯度爆炸 | 加 `torch.nn.utils.clip_grad_norm_` |
| 数据有问题 | 抽几个 batch 人工检查 |

### 场景 5：验证好于训练（看似反常）

```
loss
 │  valid ▔▔▔▔▔▔▔▔
 │  train ▔▔▔▔▔▔▔▔         ← 验证比训练还低
 │
 └──────────────────────────── epoch
```

**正常**，原因：
- 训练 loss 含 dropout 噪声 / 是每个 batch 的均值
- 验证关掉 dropout 且在整个验证集上算 → 比训练更"稳"
- 如果差太多（>20%），检查 train/valid 数据集是否来自不同分布

## 三、Accuracy 曲线的辅助判断

**Acc 和 Loss 天然负相关但不完全同步**，结合看更准：

| 情况 | 含义 |
|------|------|
| Loss ↓ + Acc ↑ | 正常，继续训 |
| Loss ↓ + Acc → | 模型在"更自信"，但正确率没变 → 即将过拟合 |
| Loss ↑ + Acc ↑ | 少见，可能标签有问题，排查数据 |

---

## 四、训练效果判定速查表

| 指标现象 | 诊断 | 行动 |
|----------|------|------|
| train loss ↓↓, valid loss ↓↓ | 正常 | 继续训练 |
| train loss ↓↓, valid loss ↑ | 过拟合 | +Dropout / Early Stop |
| 两者都平在高位 | 欠拟合 | 加容量 / 提 lr |
| 剧烈震荡 | lr 太大 | lr ÷ 10 |
| train acc ≈ random | 没学到 | 查数据/模型 |
| valid acc ↓ while train acc → | 严重过拟合 | 立即停止训练 |

## 五、实践案例

### 案例 1：过拟合 vs 正常

训练一个 LSTM 文本分类，`hidden_size=512`，`num_layers=4`，未加 Dropout：

```
Epoch  1: train loss 1.234  acc 0.523 | valid loss 1.198  acc 0.541
Epoch  5: train loss 0.423  acc 0.821 | valid loss 0.567  acc 0.772
Epoch 10: train loss 0.089  acc 0.978 | valid loss 0.892  acc 0.745  ← 过拟合开始
Epoch 15: train loss 0.012  acc 0.997 | valid loss 1.341  acc 0.701  ← 严重过拟合
```

> 训练 loss 从 0.089→0.012（快背下来了），验证 loss 从 0.567→1.341（泛化崩了）。
> 最佳模型在第 5 个 epoch 附近。

**修正**：`hidden_size` 降到 128，`num_layers` 降到 2，加 `Dropout(0.3)`：

```
Epoch 20: train loss 0.234  acc 0.893 | valid loss 0.312  acc 0.881  ← 正常收敛
```

### 案例 2：学习率太大 → 震荡

Seq2Seq 训练，`lr=0.01`：

```
Epoch 1: train loss 5.234  →  Epoch 2: train loss 3.123 → Epoch 3: train loss 4.567 → ...
```
Loss 不降反升 → 学习率太大，跳过最优点。

**修正**：`lr` 改为 `1e-3` → 平稳下降。

## 六、画训练曲线的代码

```python
import matplotlib.pyplot as plt

def plot_training(history):
    """history: {'train_loss': [], 'valid_loss': [], 'train_acc': [], 'valid_acc': []}"""
    fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(12, 4))

    ax1.plot(history['train_loss'], label='train loss')
    ax1.plot(history['valid_loss'], label='valid loss')
    ax1.set_title('Loss')
    ax1.set_xlabel('Epoch')
    ax1.legend()
    ax1.grid(True, alpha=0.3)

    ax2.plot(history['train_acc'], label='train acc')
    ax2.plot(history['valid_acc'], label='valid acc')
    ax2.set_title('Accuracy')
    ax2.set_xlabel('Epoch')
    ax2.legend()
    ax2.grid(True, alpha=0.3)

    plt.tight_layout()
    plt.savefig('training_curve.png', dpi=150)
    plt.show()
```
