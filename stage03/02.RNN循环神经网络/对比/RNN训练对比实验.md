# RNN vs LSTM 语言模型训练对比实验

> 基于 WikiText-2 数据集，对比基础 RNN 与 LSTM 的训练效果

---

## 实验环境

| 项目 | 配置 |
|------|------|
| 数据集 | Salesforce/wikitext (wikitext-2-raw-v1) |
| 模型架构 | 基础 RNN（手写 W_xh + W_hh + tanh） |
| 服务器 | 8核 CPU / 15G 内存 |
| 框架 | PyTorch |

---

## 对比总结

| 指标 | V1 (2 epoch) | V2 (2 epoch) | V2 (100 epoch) |
|------|-------------|-------------|----------------|
| 每 Token Loss | 6.76 | 5.86 | **2.96** |
| Perplexity | 861 | 350 | **19** |
| 训练速度 | 极慢 | 明显更快 | 正常 |
| 模型体积 | 115M | 35M | 35M |

### 各优化项的贡献

| 优化项 | 效果 | 原理 |
|--------|------|------|
| **低频词过滤** | 词表 76K→22K，体积减少 70% | 低频词模型学不到规律，浪费参数 |
| **Adam 优化器** | 收敛速度大幅提升 | 自适应学习率，梯度大方向减速，小方向加速 |
| **梯度裁剪** | 防止训练崩溃 | RNN 梯度容易爆炸，裁剪保证稳定 |
| **增加轮次** | 2→100 epoch，loss 从 5.86→2.96 | 更多训练让参数更优，但后期收益递减 |

## V3：LSTM 版本（门控机制）

| 配置项 | 值 |
|--------|-----|
| 分词方式 | 正则分词 `r'\w+\|[^\w\s]'` |
| 词表大小 | ~22,000（低频词 <5 替换为 `<unk>`） |
| 模型架构 | 手写 LSTM（遗忘门 + 输入门 + 候选记忆 + 输出门） |
| 优化器 | Adam (lr=0.001) |
| 梯度裁剪 | ✅ clip_grad_norm_=0.25 |
| batch_size | 75 |
| seq_len | 20 |
| embedding_dim | 128 |
| hidden_dim | 256 |
| epochs | 100 |
| 训练设备 | Colab T4 GPU |

**LSTM 核心改动：**

```
基础 RNN:  h_t = tanh(W_xh·x_t + W_hh·h_{t-1})           ← 强制覆盖，信息丢失
LSTM:      f = sigmoid(W_xf·x_t + W_hf·h_{t-1})            ← 遗忘门：决定丢掉什么
           i = sigmoid(W_xi·x_t + W_hi·h_{t-1})            ← 输入门：决定存入什么
           g = tanh(W_xg·x_t + W_hg·h_{t-1})               ← 候选记忆：新内容
           o = sigmoid(W_xo·x_t + W_ho·h_{t-1})            ← 输出门：决定暴露什么
           c_t = f * c_{t-1} + i * g                        ← 长期记忆更新
           h_t = o * tanh(c_t)                              ← 短期输出
```

**训练结果：**

| Epoch | 平均 Loss | 每 Token Loss | Perplexity |
|-------|----------|--------------|------------|
| 1 | ~90 | ~4.50 | ~90 |
| 100 | 47.94 | 2.40 | **11.0** |

**模型体积：** ~70M（8个门的线性层 + embedding + output）

## 三版本终极对比

| 指标 | V1 RNN 无优化 (2 epoch) | V2 RNN 优化 (100 epoch) | V3 LSTM (100 epoch) |
|------|------------------------|------------------------|---------------------|
| 每 Token Loss | 6.76 | 2.96 | **2.40** |
| Perplexity | 861 | 19 | **11.0** |
| 训练设备 | CPU | CPU | GPU |
| 总训练耗时 | — | ~33 小时 | **2.1 小时** |
| 模型体积 | 115M | 35M | ~70M |

### LSTM vs RNN 关键差异

| 维度 | 基础 RNN | LSTM |
|------|---------|------|
| 记忆机制 | 强制覆盖 h_t | 门控选择记忆 c_t |
| 梯度传播 | 每步乘 tanh'（≤1），连乘衰减 | 遗忘门可学习到接近1，梯度不衰减 |
| 收敛天花板 | epoch 50 后几乎不动 | epoch 100 还在下降，有提升空间 |
| Perplexity | 19 | **11（↓ 42%）** |

### 为什么 LSTM 比 RNN 强 42%

1. **遗忘门学到保留重要信息**：`f ≈ 1` 时旧记忆完整保留，梯度不衰减
2. **输入门学到过滤噪声**：`i ≈ 0` 时无用信息不写入记忆
3. **输出门学到选择性暴露**：只输出当前需要的信息
4. **长期记忆 c_t 独立于 h_t**：梯度可以沿 c_t 路径无损回传
