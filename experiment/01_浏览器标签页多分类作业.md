
# 作业01：基于浏览器标签页面的多分类模型

## 📌 任务描述

收集自己的浏览器标签页 URL/标题数据，训练一个多分类模型，把标签页自动分类到不同类别（如：学习、娱乐、工具、购物、社交等）。

## 📋 作业分解

### 第一阶段：数据准备
- [ ] 导出浏览器标签页数据（Chrome 可用插件导出为 JSON/CSV）
- [ ] 手动打标签（类别自己定，至少 4 个类别，每类至少 20 条）
- [ ] 数据清洗，输出 x（特征）和 y（类别标签）

### 第二阶段：特征工程
- [ ] 理解问题：URL 和标题是文字，如何转成数字向量？
- [ ] 使用 TF-IDF 把文本转成固定长度向量

### 第三阶段：模型训练
- [ ] 套用今天写的训练模板（11_深度学习代码流程练习.py）
- [ ] 自己设计网络结构（至少两层全连接）
- [ ] in_features 由 TF-IDF 向量维度决定，num_classes 由类别数决定

### 第四阶段：评估
- [ ] 打印每轮 accuracy
- [ ] 测试集 accuracy ≥ 70% 及格，≥ 85% 优秀

## 📦 交付标准
- [ ] 数据文件（CSV 格式）
- [ ] 完整训练代码（基于今天的模板）
- [ ] 最终测试集 accuracy 截图
- [ ] 用 3 句话说明：类别怎么定的、遇到了什么问题

## ⚠️ 难点提示
第二阶段文本转向量是难点，遇到卡点找笨迪引导。
