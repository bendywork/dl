# 模型训练方法

## 一、BART (Meta, 2019)

### 架构

BART = 完整 Transformer（Encoder + Decoder），跟原始 Transformer 论文一样的经典结构。

```
BART 架构：
  Encoder (双向Self-Attention + FFN) × N层
  Decoder (Masked Self-Attention + Cross-Attention + FFN) × N层
```

与 BERT / GPT 的关键区别：

| | BERT | GPT | BART |
|------|------|------|------|
| Encoder | ✅ 双向 | ❌ 无 | ✅ 双向 |
| Decoder | ❌ 无 | ✅ 单向 | ✅ 单向 + Cross-Attention |
| 任务类型 | 理解 | 生成 | 理解后生成 |
| 典型任务 | 分类/NER | 对话/续写 | 摘要/翻译/纠错 |

### 训练方式：Text Infilling + 去噪

```
输入原文:  "人工智能正在改变世界"
加噪声:    "人工__变世界"          (随机删除、打乱、替换)
Encoder:   理解这个损坏的句子
Decoder:   还原 → "人工智能正在改变世界"
```

噪声类型：
- **Token Masking**：随机把词替换成 `[MASK]`
- **Token Deletion**：随机删词
- **Text Infilling**：随机选一个连续片段，替换成单个 `[MASK]`（这是 BART 独有创新）
- **Sentence Permutation**：把句子顺序打乱
- **Document Rotation**：随机选一个位置当开头，把前面部分移到末尾

### BART vs T5

| | BART | T5 |
|------|------|------|
| 架构 | Encoder-Decoder Transformer | Encoder-Decoder Transformer |
| 预训练任务 | 去噪自编码 (还原损坏文本) | Span Corruption (补全被遮片段) |
| 框架理念 | 无，任务归一化 | Text-to-Text 统一框架（分类/翻译/摘要都是 text→text） |
| 适用场景 | 生成类任务（摘要/对话/纠错） | 所有 NLP 任务 |

[BART-base](https://huggingface.co/facebook/bart-base) | [BART-large](https://huggingface.co/facebook/bart-large) | [BART-chinese](https://huggingface.co/fnlp/bart-base-chinese)

## 二、BART 训练原理

### 预训练阶段：降噪自编码

```
原始文本 x
     ↓  加噪声函数 f_noise
损坏文本 x' = f_noise(x)
     ↓  Encoder → 理解损坏上下文
隐藏表示 h
     ↓  Decoder → 自回归生成
重建文本 x̂ (目标是 x̂ ≈ x)
     ↓
Loss = -log P(x | x')
```

关键点：
- Encoder 可以双向看到一个句子中所有词（没有被 mask 的）
- Decoder 是自回归的，生成时只能看到已生成的 token
- Decoder 的 Cross-Attention 可以关注 Encoder 输出的所有位置

### 与 BERT MLM 的区别

| | BERT MLM | BART Text Infilling |
|------|----------|------------|
| 预测方式 | 原地预测被 mask 的 token | 自回归生成整句 |
| 输入 | 含 [MASK] 的句子 | 随机损坏的句子 |
| 输出 | 分类 (哪个 token) | 序列生成 (整个文本) |
| 填一个位置 | 一步完成 | 可能需要多个生成步 |
| 灵活性 | 只能填 | 填、删、改都可以 |

## 三、BART 的关键设计思想

### 为什么必须在 Decoder 中生成

```
"今天天气__想去__公园"
              ↓ Encoder
    h_today, h_天气, h_[M], h_去, h_[M], h_公园
              ↓ Decoder Cross-Attention
    每一步生成时，关注 Encoder 所有位置
              ↓
    "今天天气很好我想去公园"
```

如果只有 Encoder (像 BERT)：
- 每个 [MASK] 位置预测是独立的（无依赖）
- "我想" 在一个 mask 位置、"很好" 在另一个 mask 位置
- 两个预测之间无法建立 "我想去公园" → "我也想去公园" 这种改写关系

有了 Decoder：
- 可以先生成 "我" 再基于 "我" 生成 "想"，有顺序有状态
- Cross-Attention 让 Decoder 每步都看 Encoder 所有输出
- 能处理原文没有的信息（"不想" → "不..." 需要自主补全）

### 降噪自编码 vs 传统自编码

BART 是 "去噪自编码器" 的一种：

```
自编码器 (AutoEncoder):
  压缩维度 → 重建原图（降维 + 重构）

降噪自编码器 (Denoising AE)：
  加噪声 → 压缩 → 重建干净信号（增强鲁棒性）

序列降噪自编码 (BART):
  损坏文本 → Encoder → Decoder → 还原文本
  噪声是词级别的（打断、删除、替换、乱序）
  重建是序列级的（逐 token 生成）
```

**需要关注的核心点**：BART 不只在一个 token 层面重建，而是在 **序列级别** 学习文本的 "连贯性 + 语法性"。需要生成多个 token 才能还原一段文本，这迫使 Decoder 学会真正 "写" 文本。

## 四、BART 在下游任务中的应用

### 微调策略

```
预训练阶段已学会：理解损坏文本 + 生成连续文本

下游任务微调只需调整输入输出格式 -> 训练数据直接接上
```

### 不同任务的输入输出格式

| 任务 | 输入格式 | 输出格式 |
|------|----------|----------|
| **摘要生成** | 原文 | 摘要 |
| **文本分类** | 原文 + [CLS] | Encoder 最后一层 → 分类头 |
| **翻译** | 源语言句子 | 目标语言句子 |
| **问答** | 问题 + [SEP] + 上下文 | 答案文本 |
| **序列标注 (NER)** | 原文 | 每个 token 的标签 |
| **文本纠错** | 含错误的文本 | 纠正后的文本 |

### 训练方法

BART 的训练分为几个阶段：

**1. 预训练 (Pre-training)**
- 数据集：BooksCorpus + Wikipedia (~160GB)
- 文本加噪声 → Encoder → Decoder 自回归解码
- 损失函数：交叉熵（Decoder 生成与原始文本的 token 级匹配）
- 预训练目标：text infilling + sentence shuffling + token deletion 多任务组合
- 训练时间：GPU 1-2 天 (base) / 3-4 天 (large)

**2. 微调 (Fine-tuning)**
- 换输入输出格式（加前缀、分隔符等）
- 端到端训练，比预训练快 (几小时-半天)
- Loss：交叉熵（生成任务）/ 交叉熵 + 标签损失（判别任务）

**3. 推理 (Inference)**
- Beam search 或 Greedy decoding
- 不修改任何参数
- 速度：10-100 tokens/秒（GPU）

### 微调流程

```
预训练模型 ✓

     ↓ + 任务数据（摘要、问答等）

损失函数 = CrossEntropyLoss(生成序列, 目标序列)

梯度反向传播经过所有层（Encoder + Decoder 全部更新）

     ↓

微调完成 → 可部署使用
```

### BART训练时的特殊点

**1. 噪声是训练时的数据增强**
每训练一次，同一篇文章会加不同的噪声：
```
epoch 1: "今天天气很好" → "今天_气很好" → 还原
epoch 2: "今天天气很好" → "[M]天[M]气好" → 还原
```
这在训练环节就在做增强，模型学到多种损坏模式

**2. 文本填充（Text Infilling） ≠ BERT MLM**
```
BERT MLM: 
  "我在吃[MASK]" → 预测每个[MASK]对应的单一token → "苹果"
  
BART Infilling:
  "我[MASK]吃" → Decoder自回归生成span → "在吃苹果"
  一个[MASK]可以对应0到多个token
```

**3. 句子重排（Sentence Permutation）是特殊训练**
```
原文：段落 = [A, B, C]
噪声：随机排列 = [C, A, B]
目标：还原为原始顺序
```
这迫使 Decoder 学习长距离逻辑连接，不仅关乎词汇，还关乎篇章结构

**4. Document Rotation 是另一种全局结构训练**
```
原文："我想去公园，天气很好。今天心情不错。"
旋转后："天气很好。今天心情不错。我想去公园。"
训练目标：找出并还原真正开头
```

**5. 训练时有 Teacher Forcing**
```
Decoder 训练时不看自己的输出，而看 Ground Truth：
  Ground Truth: "我 在 吃 苹果"
  Step 1: 输入"我" → 预测下一token → 目标"在"
  Step 2: 输入"我 在" → 预测下一token → 目标"吃"
  看到的是原始正确文本而非模型自己的预测
推理时没有 Teacher Forcing：只能看自己已生成的
```

## 五、训练范式的演进

### 完整的训练流水线

```
阶段 1: 预训练 (Pre-training)
  数据：TB 级无标注文本
  目标：学会语言的基本规律（语法、常识、推理）
  方法：Next Token Prediction / MLM
  产出：基座模型 (Base Model)

阶段 2: 监督微调 (SFT, Supervised Fine-Tuning)
  数据：高质量指令-回答对
  目标：学会按指令格式输出
  方法：标准交叉熵训练
  产出：指令模型 (Chat Model)

阶段 3: 对齐 (Alignment)
  数据：人类偏好标注（哪个回答更好）
  目标：安全、有用、符合人类价值观
  方法：RLHF / DPO / Constitutional AI
  产出：对齐模型 (Aligned Model)
```

### 关键训练方法对比

| 方法 | 原理 | 提出方 | 年份 |
|------|------|--------|------|
| **SFT** | 在高质量 QA 对上做监督学习 | — | 2022 |
| **RLHF** | 训练奖励模型，再用 PPO 强化学习优化策略 | OpenAI | 2022 |
| **DPO** | 直接从偏好对中优化，无需单独训练奖励模型 | Stanford | 2023 |
| **Constitutional AI** | 用宪法原则让模型自我批评、自我修正 | Anthropic | 2023 |
| **RLVR** | 对可验证任务（数学/代码），用执行结果当奖励信号 | DeepSeek | 2025 |
| **GRPO** | 组内比较代替绝对打分，省掉奖励模型 | DeepSeek | 2025 |

### 核心方法详解

**RLHF (Reinforcement Learning from Human Feedback)**

```
Step 1: 训练奖励模型
  人类标注员：对同一问题比较"回答A vs 回答B"哪个更好
  用这些偏好数据训练出奖励模型 RM（模拟人类判断）

Step 2: PPO 强化学习
  策略模型生成回答 → RM 打分 → PPO 更新参数
  目标：最大化 RM 评分，同时不偏离 SFT 模型太远 (KL 约束)
```

**DPO (Direct Preference Optimization)**

```
不要奖励模型，一步到位：

偏好数据 (好回答, 坏回答)
        ↓
直接优化策略模型 → 提升好回答概率，降低坏回答概率

数学本质：RLHF 的最优解有闭式形式，DPO 直接拟合这个解
优势：不需要训练 RM，训练更稳定，效果与 RLHF 相当
```

**Constitutional AI (Anthropic)**

```
Step 1: 监督阶段
  模型生成回答 → 宪法原则评估 → 生成修正版 → 用修正版训练

Step 2: RL 阶段
  模型生成回答 → 宪法原则打分（替代人类偏好）→ RL 优化
```

**GRPO (Group Relative Policy Optimization, DeepSeek)**

```
不需要奖励模型，不需要人类标注：

同组 N 个答案 → 组内归一化 → 好的加分、差的减分
奖励 = (自己的分数 - 组平均) / 组标准差

优势：奖励模型都不需要，对数学/代码这种有明确对错的任务特别有效
```

## 六、高效微调方法

### LoRA (Low-Rank Adaptation)

核心思想：原始权重不动，在旁边加一个低秩矩阵作为适配器。

```
原始层：h = W·x
LoRA层：h = W·x + B·A·x
        └────┬────┘  └──┬──┘
        冻结不动    只训练这个
                    (尺寸小 100~1000 倍)
```

| 方法 | 训练参数 | 效果 |
|------|----------|------|
| 全量微调 | 100% | 最好 |
| LoRA | ~0.1%-1% | 接近全量 |
| QLoRA | ~0.1%-1% | 接近 + 4bit 量化 |

### 其他高效微调方法

| 方法 | 原理 |
|------|------|
| **Adapter** | 在层之间插入小网络 |
| **Prefix Tuning** | 在输入前加可训练的虚拟 token |
| **Prompt Tuning** | 同上，但只加在输入层 |
| **IA³** | 学习三个缩放向量，参数量极小 |
